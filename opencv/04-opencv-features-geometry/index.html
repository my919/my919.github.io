第四章：特征与几何

发表于 2026-05-01 更新于 2026-10-25 分类于 OpenCV 本文字数： 6.6k 阅读时长 ≈ 6 分钟

第四章：特征与几何

概念基础

  1. 特征 = 图像中可辨识的局部模式：角点、斑点、边缘交点等，在不同光照、尺度、视角下仍能被稳定检测与匹配，是图像配准、拼接、跟踪的基础。
  2. 检测 + 描述两步：先检测关键点位置，再计算描述子（高维向量）表征其邻域；匹配即比较描述子距离。
  3. 几何从像素到世界：单应性（Homography）描述两视图间的平面映射，4 对匹配点即可解出，用于拼接、AR、文档矫正。
  4. 轮廓是连通区域边界：从二值图提取轮廓，可算面积、外接矩形、近似多边形，是传统目标检测与计数的利器。
  5. 本章目标：掌握角点/特征检测与匹配、单应性求解、轮廓分析，理解传统 CV 几何处理的边界与深度模型的分工。

本章承接 第三章：滤波与几何变换。生产级检测/分割多交由 第一章：PyTorch 入门与张量 深度模型，OpenCV 负责几何与前后处理。

一、角点检测：Harris 与 Shi-Tomasi

角点在两方向都有强梯度，是稳定的特征点：

  • Harris：返回角点响应图，需自行阈值化。
  • goodFeaturesToTrack：直接返回前 N 个角点坐标，参数为（最大点数、质量阈值、最小间距）。

1. SIFT（尺度不变）

2. ORB（快速，免费）

ORB 速度远快于 SIFT 且无专利，实时场景首选：

3. 特征匹配

  • NORM_HAMMING：ORB 等二进制描述子用汉明距离；SIFT 等浮点描述子用 NORM_L2。
  • crossCheck=True：双向匹配，过滤误匹配。
  • 比值检验（Lowe’s ratio test）进一步筛优：近邻距离 / 次近邻 < 0.7 才保留。

FLANN 与比值检验实操

大数据集用 FLANN 近似最近邻，配 Lowe ratio test：

选型经验：实时/嵌入式用 ORB + BFMatcher；离线高精度配准用 SIFT + FLANN；AKAZE 介于两者之间且对非线性尺度更鲁棒。

二·补充、霍夫变换：直线与圆

霍夫变换把「图像空间的点共线/共圆」转成「参数空间的投票峰值」，是从边缘图提取几何基元的标准方法：

  • HoughLinesP（概率版）比标准版 HoughLines 实用：直接给线段而不是无穷直线方程。
  • HoughCircles 对噪声敏感，param2（累加阈值）越大越严格；前置中值/高斯模糊几乎必须。
  • 应用：车道线、文档边框、仪表盘指针读数、圆形工件检测。

三、单应性矩阵与图像拼接

由 4 对以上匹配点解 3×3 单应性矩阵，把一幅图「贴」到另一幅的平面：

应用：全景拼接、AR 平面贴合、文档/车牌矫正（第三章透视变换的进阶）。

单应性要求场景中存在平面（或纯旋转相机），非平面场景会有视差错位。

四、轮廓检测与分析

  • RETR_EXTERNAL：只取最外层轮廓；RETR_TREE 取全部层级。
  • CHAIN_APPROX_SIMPLE：压缩水平/垂直/对角冗余点，省内存。
  • 形状识别：approxPolyDP 顶点数 → 三角形 3、矩形 4、圆 >8。

轮廓层级与形状描述子

hierarchy 数组表达嵌套关系（外轮廓含孔洞时），常用作「只保留有孔的外轮廓」这类筛选；RETR_CCOMP 两层结构对文字检测够用。

形状量化常用三招：

Hu 矩（cv2.HuMoments）提供旋转/尺度/平移不变的形状签名，cv2.matchShapes 直接比较两轮廓相似度——「找图中与模板形状相似的物体」不必上深度模型。

凸包与缺陷检测

经典应用：手势识别——手部轮廓凸包的「凹点」即指缝，数凸顶点得张开手指数。

四·补充、相机标定入门（calib3d）

摄像头镜头有畸变，精确测量（尺寸/三维）前必须标定。标准流程用棋盘格：

  • K：3×3 内参（焦距 fx/fy、主点 cx/cy）；dist：径向/切向畸变系数。
  • 标定板需多姿态多角度 15+ 张，覆盖画面边缘（畸变最大处）；ret 是重投影误差，<0.5 像素为佳。
  • 去畸变后 findHomography/测量才有几何意义；鱼眼镜头改用 cv2.fisheye 系列 API。

六、传统 CV 与深度模型的分工

任务 传统（本章） 深度模型
图像配准/拼接 SIFT/ORB + 单应性 优势 少用
物体检测 模板匹配（仅平移）/轮廓 YOLO/DETR 优势
语义分割 阈值/分水岭 U-Net/Mask R-CNN 优势
几何测量 轮廓面积/周长 优势 —
实时跟踪 KCF/光流 Siamese 等深度跟踪

经验：几何与配准用传统 CV，识别与分割用深度模型，二者常组合——深度模型出框，OpenCV 做几何后处理。

七、常见陷阱

陷阱 说明
Harris 输入未转 float32 cornerHarris 需 float32 灰度，uint8 报错
ORB 用 L2 距离 ORB 二进制描述子须用 NORM_HAMMING
无比值检验误匹配多 只取最近邻会有大量误匹配，加 Lowe ratio test
单应性点不足 需 ≥4 对点，且不能共线，否则解不稳
轮廓忘过滤小面积 不滤噪点轮廓会画出一片碎点
模板匹配遇旋转 matchTemplate 不抗旋转缩放，需改特征匹配
findContours 改原图 该函数会修改输入图，传副本

本章小结

要点 结论
角点 Harris 响应图、Shi-Tomasi 直接出点（goodFeaturesToTrack）
特征 SIFT 鲁棒、ORB 快且免费；检测+描述两步
匹配 BFMatcher/FLANN；二进制用汉明距离、浮点用 L2；加比值检验
霍夫 HoughLinesP 出直线段、HoughCircles 出圆，需先边缘/模糊
单应性 4+ 对点 RANSAC 解 3×3，全景拼接/AR/矫正
轮廓 findContours + 面积/外接矩形/多边形近似；圆度/长宽比/Hu 矩量化形状；凸包缺陷做手势
标定 棋盘格 15+ 张 → calibrateCamera 得 K/dist → undistort 去畸变
模板匹配 仅平移有效，旋转缩放失效
分工 几何配准用传统，识别分割用深度（见第五章）
