第五讲：转换、置换、向量空间R

发表于 2025-03-08 更新于 2026-10-10 分类于 线性代数 本文字数： 2k 阅读时长 ≈ 2 分钟

第五讲：转换、置换、向量空间R

置换矩阵（Permutation Matrix）

$P$为置换矩阵，对任意可逆矩阵$A$有：

$PA=LU$

$n$阶方阵的置换矩阵$P$有$\binom{n}{1}=n!$个

对置换矩阵$P$，有$P^TP = I$

即 $P^T = P^{-1}$。

转置矩阵（Transpose Matrix）

$(A^T)_{ij} = (A)_{ji}$

对称矩阵（Symmetric Matrix）

$A^T$ = $A$

对任意矩阵$R$有$R^TR$为对称矩阵：

$$
(R^TR)^T = (R)^T(R^T)^T = R^TR
$$
即 $(R^TR)^T = R^TR$。

向量空间（Vector Space）

所有向量空间都必须包含原点（Origin）；

向量空间中任意向量的数乘、求和运算得到的向量也在该空间中。
即向量空间要满足加法封闭和数乘封闭。

本讲要点

  • 置换矩阵 $P$ 左乘矩阵即可对行做重排，它的每行、每列都恰有一个 $1$；置换矩阵是正交矩阵，$P^{-1}=P^T$，即 $P^TP=I$。
  • 转置使乘积顺序反转：$(AB)^T=B^TA^T$；对称矩阵满足 $A=A^T$，而对任意形状的矩阵 $R$，$R^TR$ 恒为对称矩阵（$n\times n$）。
  • 向量空间必须对向量加法和数乘都封闭；由 $0\cdot v=0$ 可知，任何向量空间或子空间都必须包含零向量。
  • 过原点的直线、平面是 $\mathbb{R}^n$ 的子空间；平行平移后不过原点的直线、平面（如 $x+y=1$）不是子空间。

易错点辨析

易混/易错 正确理解
把不过原点的平面当成子空间 $x+y=1$ 不含零向量，且两个成员相加后不在集合内，只是仿射平面
$(AB)^T$ 仍写成 $A^TB^T$ 转置与求逆一样反序：$(AB)^T=B^TA^T$
求 $P^{-1}$ 还要再消元 置换矩阵正交，$P^{-1}=P^T$，直接转置即得逆矩阵
认为 $R^TR$ 不一定对称 $(R^TR)^T=R^T(R^T)^T=R^TR$ 恒对称；注意它是 $n\times n$，与 $m\times m$ 的 $RR^T$ 区分

典型例题

题目：构造交换第 1、3 行的 $3\times3$ 置换矩阵 $P$，验证 $P^TP=I$ 且 $P^T(PA)=A$；验证随机矩阵 $R$ 的 $R^TR$ 对称；用代码判断 $\{(x,y):x+y=1\}$ 与 $\{(x,y):x+y=0\}$ 是否为子空间。

解答：交换第 1、3 行的置换矩阵为 $P=\begin{bmatrix}0&0&1\\0&1&0\\1&0&0\end{bmatrix}$。由于 $P^T=P^{-1}$，故 $P^TP=I$，且 $P^T(PA)=(P^TP)A=A$——先置换再逆置换，矩阵原样返回。对随机矩阵 $R$，$(R^TR)^T=R^T(R^T)^T=R^TR$，转置后不变。集合 $x+y=1$ 不含原点 $(0,0)$，且 $(1,0)$ 与 $(0,1)$ 都在集合内、和 $(1,1)$ 却不满足方程，加法不封闭，故不是子空间；$x+y=0$ 含原点且对加法、数乘封闭，是子空间。

运行结果：前三行依次输出 True、True、True，验证了 $P^TP=I$、$P^T(PA)=A$ 与 $R^TR$ 对称；末两行输出 False False 与 True True，说明 $x+y=1$ 不是子空间而 $x+y=0$ 是。
