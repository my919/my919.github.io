16. 常见误用与陷阱

坑 现象 解法
makemigrations 报 “No changes detected” 改了模型却生成不出迁移 app 未加入 INSTALLED_APPS，或 models.py 未 import 模型；确认 app 名与 AppConfig.default_auto_field 配置正确
fields = "__all__" 泄露敏感字段 password / is_superuser 等暴露给 API 用 fields = ["name", "email"] 显式列举；含敏感模型用 extra_kwargs = {"password": {"write_only": True}}
DRF 默认权限 AllowAny 生产接口裸奔、无认证 settings.py 设 REST_FRAMEWORK = {"DEFAULT_PERMISSION_CLASSES": ["rest_framework.permissions.IsAuthenticated"]}
序列化器访问外键致 N+1 list 接口每条记录多一次查询 ViewSet 重写 get_queryset 用 select_related("fk")（外键）/ prefetch_related("m2m")（多对多）
USE_TZ=True 存 naive datetime RuntimeWarning: DateTimeField received a naive datetime / 时间错乱 一律用 django.utils.timezone.now()；插入数据不要用 datetime.now()
Celery 任务在测试里异步卡住 单测 .delay() 后断言失败（任务还没跑） 测试 settings 设 CELERY_TASK_ALWAYS_EAGER = True + CELERY_TASK_EAGER_PROPAGATES = True，任务同步执行并抛异常
