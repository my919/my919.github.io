1. 概念说明

Python 是解释型、动态类型、多范式语言：语法简洁、生态庞大（AI、数据分析、Web、自动化都是主场）。

动态类型 vs 静态类型：变量不声明类型，运行时推断；配合类型注解（Python 3.5+）可获静态检查能力，生产项目强烈建议使用。

执行模型：GIL（全局解释器锁）限制同一进程多线程并行计算；CPU 密集用多进程/原生库，IO 密集用 asyncio 协程。

2. 环境准备（uv 一键管理）

uv 为什么是首选：替代 pip+venv+poetry，单工具完成解释器管理、依赖解析、虚拟环境、打包发布，速度比 pip 快 10-100 倍。

10. 常见误用与陷阱

坑 现象 解法
可变默认参数 def f(x, items=[]) 多次调用共享同一个列表，结果”串号” 默认值用 None 哨兵，函数体内再初始化
GIL 误解 CPU 计算开一堆多线程，速度不升反降 CPU 密集用多进程/C 扩展；只有 IO 密集才用线程或 asyncio
闭包晚绑定 循环里造的 lambda 全部取到循环终值 用默认参数立即捕获：lambda i=i: i
裸 except except: 把 KeyboardInterrupt、SystemExit 一起吞掉 捕获具体异常，至少 except Exception 并记录
pip 全局环境污染 sudo pip install 改系统 Python，项目间依赖互相打架 uv/venv 每项目一个隔离环境，不碰全局解释器
遍历中改集合 循环 dict/list 时直接删除元素，RuntimeError 先 list(d.items()) 物化再删，或用推导式过滤
