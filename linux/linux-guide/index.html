1. 概念说明

Linux 是开源操作系统内核，服务器端事实标准。一切皆文件：硬件设备、进程信息都以文件形式暴露（/dev、/proc）。

目录结构速记：

目录 作用
/etc 系统与软件配置
/var 日志（/var/log）、缓存
/home 用户目录
/opt 第三方软件
/tmp 临时文件
/usr 系统程序与库
/proc 运行时内核信息（伪文件）

Shell 是命令解释器：你输入命令，内核执行。学习路径：命令 → 组合管道 → 脚本自动化。

3. 入门速览（细节见命令手册）

以下内容只给最小心智模型，完整命令与参数见 Linux 运维常用命令手册：

  • 连接服务器：ssh user@server-ip；生产推荐公钥免密（ssh-keygen + ssh-copy-id），进阶配置见第五章。
  • 文件与权限：ls -lah 看列表；权限 rwx 数字法（755/644/600），chmod/chown 管理。
  • 进程与系统：ps aux | grep、top、kill（先 SIGTERM 再 SIGKILL）；df -h/free -h/uptime 看资源。
  • 网络：ss -tlnp 看端口、curl -v 调 HTTP、ping 测连通；防火墙用 ufw。
  • 包管理：apt update && apt install -y <pkg>。
  • vim：i 插入、Esc 返回、:wq 保存退出、/keyword 搜索。
  • systemd：写 [Unit]/[Service]/[Install] 三段注册服务，systemctl enable --now 启动，journalctl -u <svc> -f 看日志；深入见第五章。
  • cron：crontab -e，语法「分 时 日 月 周 命令」；与 systemd timer 的取舍见第五章。
  • Shell 脚本：开头必写 set -e；部署脚本骨架「下载 → 备份 → 原子替换 + 重启 → 健康检查（失败回滚）」，工程化细节见第三章。

4. 实战：CasOS —— 构建在 Kubernetes 之上的云操作系统

CasOS 把 Kubernetes 控制面嵌进单个可执行文件，一条命令即可在笔记本或服务器拉起真实 K8s 集群，附带 Web UI、应用商店、私有 AI（Ollama + Open WebUI）与 AI Agent（MCP）接入能力。与 k3s 的差别是”集群之上的完整体验”，与 CasaOS/Coolify 的差别是底层为真实 K8s 且可多节点扩容。

踩坑要点：Windows 节点依赖 WSL2；多机扩容需节点间 SSH 互通与端口放行；私有 AI 按显存自动选模型，多卡注意分布；单文件集群适合个人/边缘/开发场景，生产仍需多节点 + 控制面高可用；装完第一件事改掉默认密码 admin/123。

5. 常见误用与陷阱

坑 现象/后果 解法
rm -rf $DIR/* 变量为空 展开成 rm -rf /*，整盘被删 变量加引号并判空：[ -n "$DIR" ] && rm -rf "$DIR"/*
chmod -R 777 /var/www 全目录可写；SSH 私钥因权限过开放被拒登 目录 755 / 文件 644 / 密钥 600，按需 chown 解决访问问题
kill -9 代替优雅停止 进程没机会刷缓冲、释放锁，数据损坏 先 kill（SIGTERM），等 30 秒无效再 kill -9
> 与 >> 混淆 > backup.tar 覆盖了昨天的备份 追加一律 >>；覆盖前先 ls -l 确认目标存在与否
管道下游提前退出触发 SIGPIPE `cmd head 令 cmd 被 SIGPIPE 杀掉，set -o pipefail` 的脚本莫名失败
tail -f 跟踪已轮转文件 轮转后文件被改名，tail 盯着旧 inode”日志不动了” 用 tail -F（跟随文件名而非 inode）
rm 正在写入的大日志 df 不腾地、du 与 df 对不上 lsof +L1 找已删除仍被占用文件，重启进程或 truncate -s 0（详见第五章）
