第三章：Bash 脚本编程

概念基础

  1. 脚本 = 运维自动化的最小单元：把第一章的命令按逻辑串起来（变量、分支、循环、函数），批量操作从「人肉重复」变成「一键执行」。
  2. 退出码是通用语言：每个命令都返回 0~255，0 表示成功、非 0 表示失败；&&/||、if、set -e 全部建立在退出码之上。
  3. 文本流是通用接口：脚本的核心工作是「读文本 → 加工 → 写文本」，与 第四章：文本处理三剑客与管道 的 grep/sed/awk 天然配套。
  4. 引号规则决定一切：双引号允许变量展开、单引号完全字面量、不加引号会被空格分词——空格路径事故九成源于此。
  5. 防呆三件套：set -euo pipefail（出错即停、未定义变量报错、管道错误不被吞）+ trap 清理 + ShellCheck 静态检查，是脚本进工程的前提。

本章小结

要点 结论
退出码 0 成功非 0 失败；&&/`
引号规则 双引号展开、单引号字面量；变量一律 "${var}" 包起来
判断 [[ ]] 优先，支持通配与正则；数值用 (( ))
函数 local 防泄漏；返回值靠 $( ) 接输出，return 只表示成败
防呆三件套 set -euo pipefail + trap EXIT 清理 + ShellCheck 静态检查
set -e 豁免 条件/&&/`
trap EXIT 兜底清理、ERR 报行号、INT 体面收尾；同名 trap 只留最后一个
并发安全 临时文件用 mktemp；防重入用 flock；写配置先 tmp 再 mv 原子替换
调试 bash -n 预检 → set -x/PS4 跟踪 → ShellCheck 兜底
批量操作 遍历用 "${arr[@]}"；for f in *.ext 前先 [[ -e ]] 防空目录
