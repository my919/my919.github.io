从 0 到专项突破。DP 核心思想与五步法 · 经典题型（背包/序列/区间）· 状态压缩 · 贪心证明 · 刷题路线。代码带详细注释。

类别 选型 用途

1. 概念说明

**动态规划（DP）**解决”多阶段决策最优化”问题，核心思想：把大问题拆成重叠子问题，用一张表记录子问题答案，避免重复计算。

DP 三要素：

  • 状态定义：dp[i] 表示什么（最常见：以 i 结尾 / 前 i 个）。
  • 状态转移：dp[i] 如何由更小的状态推出（核心方程）。
  • 初始条件：最小的子问题答案。

适用信号：求最值（最大/最小/方案数）、有重叠子问题、无后效性（当前决策只影响未来）。

贪心：每一步做局部最优，期望得到全局最优——只对满足”贪心选择性质”的问题成立（如活动安排、找零），必须证明或验证，不是所有最值都能贪心。

判断口诀：能用 DP 先想 DP；贪心是 DP 的特例（无后效 + 局部最优即全局）。

1. 概念说明

排序与查找是算法的基础功：排序让数据有序（后续查找、去重、统计的前提），查找在数据中定位目标。

必须掌握的复杂度图景：

排序 平均 最坏 空间 稳定
冒泡 O(n²) O(n²) O(1) ✅
选择 O(n²) O(n²) O(1) ❌
插入 O(n²) O(n²) O(1) ✅
希尔 O(n^1.3) O(n²) O(1) ❌
归并 O(n log n) O(n log n) O(n) ✅
快速 O(n log n) O(n²) O(log n) ❌
堆 O(n log n) O(n log n) O(1) ❌
计数/桶/基数 O(n+k) O(n+k) O(n+k) ✅

工程结论：通用排序 Python 用 Timsort（混合插入+归并）、Java 用 Dual-Pivot QuickSort——语言内置即最优；手写排序只出现在面试与特殊场景（如部分有序数据）。

1. 概念说明

大模型应用的核心模式有三种，由浅入深：

  1. Prompt 工程：直接调用模型，靠提示词引导（成本最低）。
  2. RAG（检索增强生成）：先从知识库检索相关资料，再让模型基于资料回答——解决”模型不知道你的私有数据”和”幻觉”问题，是当前落地主流。
  3. Agent（智能体）：模型自主决策：拆解任务 → 调用工具（函数调用）→ 观察结果 → 继续执行。

为什么 RAG 而不是微调：RAG 改知识只需更新向量库，无需重新训练；微调适合改变”行为风格”（如领域话术），不适合注入大量事实。

完整 RAG 流程：文档加载 → 分块 → 向量化 → 存向量库 → 用户提问 → 语义检索 TopK → 拼入 Prompt → 模型生成（附来源）。

1. 概念说明

视频 = 连续图像帧 + 音频，通过**编码（Codec）**压缩存储。三个核心概念：

  • 编码标准：H.264（兼容性最好）、H.265/HEVC（同画质省 50% 码率）、AV1（新一代开源，省更多但编码慢）、VP9。
  • 封装格式（Container）：MP4（通用）、MKV（多轨）、WebM（网页）。编码与封装独立组合：H.264 视频 + AAC 音频 → MP4。
  • 关键参数：分辨率（1080p）、帧率（fps）、码率（bitrate，决定画质与体积）、GOP（关键帧间隔）。

转码为什么重要：源视频（如手机 4K）码率高、格式杂，服务端需统一转成 H.264/AAC + MP4 便于全端播放；按分辨率出多档（1080p/720p/480p）做自适应。
