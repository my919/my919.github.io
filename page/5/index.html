第10章：泛函分析

泛函分析（Functional Analysis）的核心思想只有一句话：把”函数”当作空间中的一个”点”。一个 n 维向量 x = (x₁, …, xₙ) 是 n 个数；一个函数 f: [a,b] → ℝ 可以看成”无穷多个坐标”——每个自变量 x 处都有一个分量 f(x)。一旦接受这个视角，有限维线性代数里熟悉的一切——长度、夹角、正交、投影、基、特征值——都可以在无穷维的”函数空间”里重新定义，而泛函分析就是研究这套推广何时成立、如何成立、以及成立的代价是什么的学科。它是有限维线性代数在无穷维的推广，也是从”会算”走向”会证”的分水岭：微分方程解的存在唯一性、Fourier 级数为什么收敛、量子力学为什么用算子描述可观测量、核方法为什么合法，答案全部藏在本文的定理里。

主线：度量空间（距离与完备）→ 赋范空间（长度）→ 内积空间（角度与正交）→ Hilbert 空间（完备的内积空间，无穷维里”最像 ℝⁿ”的空间）→ 线性算子与泛函 → Riesz 表示 → 谱理论 → 应用（PDE 弱解 / 量子力学 / RKHS 核方法）。案头参照 Bronstein《数学手册》第 12 章。

0. 学习地图

工程师视角的一句话：线性代数告诉你”对称矩阵可正交对角化、最小二乘就是投影”；泛函分析告诉你这两件事在无穷维依然成立——只要空间完备（Hilbert）、算子性质足够好（有界/紧/自伴）。核方法、谱聚类、最小二乘、值迭代收敛，全是这套定理的推论。

2. 度量空间：距离、完备性与压缩映射

2.1 距离三公理与开/闭集

度量空间是最一般的”能谈收敛”的舞台：不要求加法、不要求数乘，只要有距离。这把”收敛”从微积分的实数轴解放出来，可以谈”函数列收敛”、”曲面列收敛”、”测度列收敛”。

2.2 Cauchy 列与完备性

工程直觉：不完备的空间像有漏洞的容器——迭代算法可能收敛到一个”不在定义域里”的答案。所有数值算法的第一步，都是确认自己工作在完备空间里。

2.3 压缩映射原理（Banach 不动点定理）

这是整个应用数学中”构造性存在唯一性证明”的模板：不仅断言解存在，还顺手给出了算法（迭代）和误差估计（qⁿ 几何收敛）。

第4章：积分变换

积分变换的共同思想只有一句话：选一个核函数 K(t, u)，把函数 f(t) 投影到另一组基上，让在时域难做的运算（求导、卷积、解微分方程）在新坐标系里变成简单运算（乘法、查表、代数移项）。对 Laplace 核是 e^{-st}，对 Fourier 核是 e^{-iωt}，对离散序列核是 z^{-n}。

所有积分变换都长着同一张脸：

最值钱的一个事实：指数函数是求导运算的特征函数。

所以一旦把任意函数拆成指数函数的叠加（投影到指数基），求导就整体变成了乘法——这就是 Laplace 与 Fourier 全部威力的来源。本指南按工程师的使用顺序讲：Laplace 解微分方程与控制系统 → Fourier 级数与变换做频谱 → 采样、DFT/FFT 落地到代码 → z 变换统治离散世界，最后给出三大变换对比、Python 实战与 ML/工程对照表。

1.1 定义与收敛域

收敛域（ROC）一句话：使该反常积分（绝对）收敛的 s 全体，对单边变换通常是右半平面 Re(s) > σ₀，σ₀ 称为收敛横坐标。例如 L{e^{3t}} = 1/(s-3) 的收敛域是 Re(s) > 3。

为什么要乘 e^{-σt}？因为现实中大量信号（e^{3t}、阶跃）本身不衰减，直接做 Fourier 变换积分发散；先用 e^{-σt} 强行压住，才能讨论。所以 Laplace 比 Fourier「胃口更好」，这是它统治初值问题的原因。

蝶形运算一句话：把序列按下标奇偶不断拆成两半（分治），两个半序列的 DFT 用形如 X = A + W·B、Y = A − W·B 的「蝶形」单元组合，旋转因子 W = e^{-i2π/N}。N 是 2 的整数次幂时效率最高（基-2 FFT），不足可补零。np.fft.fft、SciPy、MATLAB fft 内部都是它。

5.1 定义

5.2 与 Laplace / Fourier 的关系

5.3 收敛域

稳定性判据（必须背）：离散 LTI 系统稳定 ⟺ 传递函数 H(z) 的全部极点在单位圆内（等价于连续系统「极点在左半平面」）。

第9章：偏微分方程

常微分方程（ODE）只有一个自变量（通常是时间），描述「一个点的命运」；偏微分方程（PDE）有多个自变量（时间 + 空间），描述「一整片场的命运」——温度场、应力场、电磁场、概率密度场。工程师每天打交道的传热仿真、结构 CAE、流体 CFD、图像扩散模型，底层全是 PDE。

PDE 的共同思想只有一句话：未知量是一个多元函数 u(x, t)，方程把 u 对各个自变量的偏导数绑在一起。导数从一元变成多元之后，解不再是「一条曲线」而是「一个曲面/场」，定解也不再只靠几个初值，而要靠边界条件 + 初始条件共同裁剪出唯一解。

本指南对应 Bronstein 数学手册第 9 章 PDE 部分与第 11 章积分方程，按工程师的使用顺序讲：基本概念与适定性 → 二阶方程三分法（椭圆/抛物/双曲）→ 三大典型方程逐个拆 → 特征线法 → 分离变量法完整走一遍 → 积分变换与 Green 函数 → 弱解与有限元的入口 → 积分方程简述 → 有限差分数值求解 → ML/工程对照表 → Python 实战。
