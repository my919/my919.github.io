1. 概念说明

区块链是一个去中心化的分布式账本：数据被打包成区块，通过哈希指针串联成链，由全网节点共同维护，靠共识机制（如 PoS）保证一致，具有不可篡改、公开透明、去信任三大特性。

核心概念：

  • 区块（Block）：包含交易列表、时间戳、前一区块哈希。
  • 哈希（Hash）：SHA-256 等单向函数，内容一变哈希全变，是防篡改的基础。
  • 共识机制：PoW（工作量证明）/ PoS（权益证明），决定谁来打包新区块。
  • 钱包地址：由私钥推导出的公钥哈希，私钥即资产控制权，绝不能泄露。
  • Gas：执行交易的燃料费，单位 gwei（1 ETH = 10⁹ gwei）。
  • 智能合约：运行在链上的程序，部署后地址固定、逻辑不可更改，人人可调用。

1. 概念说明

数字音频是把连续声波采样成离散数字序列。三个核心参数：

  • 采样率（Sample Rate）：每秒采样的次数，单位 Hz。CD 为 44100 Hz，视频通用 48000 Hz。采样率决定可还原的最高频率（奈奎斯特定理：最高频率 = 采样率/2）。
  • 位深（Bit Depth）：每次采样用多少 bit 表示振幅，16 bit（CD）、24 bit（录音室）。位深决定动态范围。
  • 声道（Channels）：单声道（mono）、双声道（stereo）或多声道（5.1）。

常见格式：WAV（无损 PCM）、MP3 / AAC（有损压缩）、FLAC（无损压缩）、M4A / OGG。

核心处理手段：转码（格式/码率转换）、剪辑（截取/拼接）、音量调整（增益/归一化）、降噪（滤波）、提取（音视频分离）、混音（多轨叠加）。

1. 概念说明

REST（Representational State Transfer，表现层状态转移）是一套架构风格而非协议，核心思想是把一切都抽象为资源，用 HTTP 方法表达对资源的操作：

HTTP 方法 语义 幂等
GET 查询资源 ✅
POST 创建资源 ❌
PUT 整体更新 ✅
PATCH 局部更新 ✅
DELETE 删除资源 ✅

RESTful API 设计五原则：资源用名词复数命名（/users 而非 /getUser）、用 HTTP 方法表达动作、无状态（每个请求携带全部信息）、状态码表达结果、版本化管理接口（/v1/users）。

1. 概念说明

人工智能（AI）是让机器具备”智能”的技术总称，包含三个层次：

  • 机器学习（ML）：从数据中自动学习规律，不显式编程。典型任务：回归（预测房价）、分类（识别垃圾邮件）、聚类（用户分群）。

  • 大语言模型（LLM）：基于 Transformer 架构、在海量文本上预训练的超大模型，能理解并生成自然语言，是当前 AI 应用的主流形态。

核心流程：数据收集 → 数据清洗 → 特征工程 → 模型训练 → 模型评估 → 部署上线。本项目将从经典机器学习入手，再到深度学习，最后用 LLM 完成一个可落地的应用。
