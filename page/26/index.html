第一章：Elasticsearch 入门与索引管理

概念基础

  1. 倒排索引是 ES 的心脏：写入时经分词器把文本拆成 term，建立 term → 文档 ID 列表的倒排表；查询时先在 term 字典命中、再扫倒排表取文档。对比 MySQL 的 B+Tree 是「值→行位置」，倒排索引是「词→文档列表」。
  2. 近实时（NRT）不是实时：写入先入 translog + 内存 buffer，默认每 1 秒 refresh 一次生成新 segment 才可搜；写后立刻查可能查不到，要 ?refresh=wait_for 或手动 _refresh。
  3. 集群三件套：节点 / 分片 / 副本：主分片水平拆数据决定容量上限，副本分片做高可用 + 读扩展；节点角色分 master / data / coordinating / ingest，生产建议 master 与 data 分离。
  4. ES ≈ 倒排索引 + 分布式：MySQL 的事务 / 外键 / 强一致 ES 没有；ES 的全文检索 / 聚合 / 打分 MySQL 也弱——选型看场景，不是替代，常组合使用。
  5. ELK 生态：E + L + K 三件套：Filebeat/Logstash 采集 → Elasticsearch 存储 → Kibana 可视化；现代可观测性栈的事实标准之一，后续可观测性系列会展开。
  6. 9.x 关注点：BBQ（Better Binary Quantization）向量量化提速数倍、成向量检索默认；ES|QL 管道查询语法简化分析类查询（第二章提一句）；_type 早已是历史（7 弃用、8 移除），统一走 _doc。

本章是 ES 系列开篇，安装与索引管理是地基；查询与调优在 第二章：Elasticsearch 查询与性能调优 展开。ES 按 9.x（2025+）语法书写。

二、核心概念

Index / Document / Mapping / Analyzer 与 MySQL 对照

ES 概念 MySQL 对照 说明
Index（索引） Table 7+ 去掉 mapping type，一索引即一表
Document（文档） Row JSON 文档，最小可检索单元
Mapping Schema 字段名、类型、是否分词、分词器
Analyzer（分词器） 无 拆词 + 归一化（小写 / 去停用词 / 同义词）

  • 主分片数：单分片建议 10~50GB；过早分多浪费资源，过少后续扩容难。
  • 副本数：读多加副本提升读吞吐；写入压力大时临时降副本（设 0）提速。

倒排索引与段合并

  1. 段（Segment）不可变：refresh 产生新 segment，文档更新/删除只是打标记（.del 文件），旧段不动——这是 ES 写快的根基，也是磁盘膨胀的来源；
  2. 后台 merge：Lucene 定期把小段合并成大段，顺带物理清除带删除标记的文档；merge 吃 IO/CPU，写入高峰期可能拖慢查询；
  3. forcemerge 只用于只读索引：POST /logs-2026.08/_forcemerge?max_num_segments=1 把段合成 1 个，查询提速明显；对仍在写入的索引做 forcemerge 是灾难（刚合完又被打碎）。

写入文档落在哪个分片，由公式决定：

  • 默认按 _id 均匀打散；自定义 routing（如 user_id）可让同用户数据聚在同一分片：

refresh / flush / translog 三段式

机制 默认节奏 管什么
refresh 1s 内存 buffer → 新 segment，文档可被搜到
translog fsync 每 5s（可配 request/async） 崩溃不丢数据的保障
flush translog 满 512MB 或 30min segment 落盘 + 清 translog，真正持久化

记忆法：refresh 管可见、flush 管持久、merge 管快。三者都要花钱，调优就是在这三者之间找业务平衡点。

四、分词器与分析器

分词器 行为 场景
standard 中文逐字、英文按词 兜底默认

ik_smart 智能不重复 查询时（precision 高）

索引 ik_max_word（切得细、多召回）、查询 ik_smart（切得准、少噪音）是中文 ES 的经典组合。

同义词：搜索引擎的「行业词典」

  • 双向同义词（a, b, c）索引期展开，召回最全；单向（a => b）常用于查询期归一化；
  • 9.x 的 synonyms API：PUT /_synonyms/my_set 在线更新同义词、无需重建索引——告别改完词典重启集群的时代。

扩容路径

  1. 纵向：加内存/换 SSD——最省事但有上限；
  2. 横向：加 data 节点，分片自动重平衡（cluster.routing.rebalance.enable 默认开）；
  3. 分片数不够：建新索引 reindex，或对只读索引用 _shrink/_split 调整分片数；
  4. 角色分离：专用 master 不扛数据压力，大集群标配：

扩容的隐性成本是分片迁移：TB 级索引迁移动辄数小时，规划分片数时宁可一步到位，也别指望事后轻松调整。

备份：快照与恢复

发表于 2026-09-02 更新于 2026-10-29 分类于 搜索引擎 本文字数： 18k 阅读时长 ≈ 16 分钟

第二章：Elasticsearch 查询与性能调优

概念基础

  1. Query DSL 是 JSON 化的查询语法：一切查询走 GET /idx/_search { body }，body 由 query / aggregations / sort / size / from 等组成——告别 SQL，拥抱嵌套 JSON。
  2. 精确匹配 vs 全文检索：term 对 keyword / 数值精确匹配（不打分），match 对 text 分词后匹配并打分——用错类型是新手头号坑。
  3. 相关性评分 BM25：ES 7+ 默认 BM25（替代 TF-IDF），核心是「词频饱和 + 文档长度归一」——短文档命中高权重，长文档被稀释。
  4. 聚合 = 分桶 + 算指标：bucket agg（terms / date_histogram / range）分组，metrics agg（avg / sum / cardinality）算值，可嵌套——OLAP 分析能力。
  5. 分页深翻是 ES 的痛：from + size 超过 10000 默认被拒（max_result_window），深翻用 search_after 游标或 scroll——选错方式直接 OOM。

本章承接 第一章：Elasticsearch 入门与索引管理 的索引与 mapping；查询 DSL、聚合、调优在此展开。ES 按 9.x 语法。

  1. 深翻聚合用 composite：terms 只能拿 Top N，全量分组导出用 composite + after_key 逐页拉取：
  1. 近似优先：sampler agg 先抽样再聚合、cardinality 用 HyperLogLog 近似——接受 1% 误差换 10 倍速度。

四、分页与深度翻页

方式 上限 适用 状态
from + size 10000（max_result_window） 浅分页、要跳页 通用
search_after 无上限 深翻、顺序翻（不可跳页） 推荐
scroll 无上限 全量导出、一次性 7.10+ 渐进弃用，优先 search_after

from + size 超过 10000 报错：协调节点要把 from+size 条数据都取到内存再截断，深翻是性能与内存双重压力。导出用 search_after 或 scroll。

五、性能调优

  • 分片数：单分片 30~50GB 为宜；过多分片使聚合 scatter-gather 开销大、元数据重。
  • filter 缓存：精确条件进 filter 上下文，bitset 复用。
  • routing：按维度（如 user_id）路由，查询带 routing 少扫分片。
  • 索引拆分：按时间（logs-2026.09）或业务隔离，缩扫描范围。
  • 避免 wildcard 前缀：*foo 无法走 term 字典跳查，等于全词典扫描——非用不可时建 wildcard 类型字段（为通配查询优化的存储结构）。
  • 只读索引 forcemerge：历史日志索引合并到 1 个 segment，查询提速 + 省句柄（段合并原理见第一章）。
  • ES|QL（9.x）：POST /_query { "query": "FROM order_idx | WHERE amount > 100 | STATS total = SUM(amount) BY status" }——管道语法可读性远好于嵌套 DSL，分析类查询优先尝试；复杂打分与精细控制仍以 DSL 兜底。
硬件项 建议
堆内存 物理内存 50%，剩给 Lucene 文件系统缓存
JVM 不超 31GB（指针压缩阈值），用 G1GC
磁盘 SSD 必备；HDD 只读副本勉强
副本 读 QPS 高加副本；写入期临时归零

八、实战案例：商品搜索索引设计与零停机重建

问题背景：商城商品搜索上线三个月问题集中爆发：中文搜不出结果（分词器没配对）、重建索引要停服、翻页翻到 5000 条就报错、索引一天天变大磁盘告警。

方案：IK 分词 + 精细 mapping（该分词的分词、不该索引的关掉）→ 别名机制支持零停机重建 → search_after 深分页 → 动态 mapping 收紧控制膨胀。

踩坑点：

  • IK 装了但 mapping 里 analyzer 没指到它，或索引/搜索两侧都用 ik_max_word 导致召回过杂——索引用 ik_max_word（细粒度）、搜索用 ik_smart（粗粒度）。
  • 直接改 mapping 字段类型：ES 直接报错，只能重建索引——别名机制必须第一天就上。
  • from+size 翻页过深直接 400：导出/翻页一律 search_after；跳页需求预查总数 + 关键词约束。
  • 动态 mapping 放飞：脏数据把 price 推成 text，聚合全挂——生产索引 dynamic: strict + 显式 mapping。

安全运维与生产加固

概念基础

  1. 最小暴露面：线上系统应只暴露完成业务必需的端口、接口、路径与依赖。能内网访问的不放公网，能用 VPN 的不开公网端口，能关的调试端点一律关闭。暴露面越小，攻击者可试探的入口越少，运维与监控也越聚焦。
  2. 纵深防御：代码层防护之外，还需在网络（防火墙/WAF）、传输（TLS）、存储（加密 Secret）、主机（基线/审计）、容器（镜像扫描/Pod 策略）各层叠加控制。任一层被攻破，下一层仍能拦截，避免”单点失守即全线失守”。
  3. 安全基线：操作系统、中间件、框架都有官方安全配置基线（如 CIS Benchmarks）：禁用 root 登录、关闭无用服务、设文件最小权限、删除默认账号。基线是”已知良好”的起点，新机器上线即套用，定期漂移检测纠正偏离。
  4. 密钥管理：密钥（数据库口令、API Key、证书私钥、加密主密钥）是系统的命门，应做到生成强、存储加密、轮换勤、访问审计、泄露可吊销。禁止硬编码进代码或明文入 Git，应统一由 Vault/KMS/Sealed Secrets 等密钥管理服务托管。
  5. 审计日志：可观测才有响应。关键操作（登录、越权访问、密钥读取、配置变更、特权命令）必须记录谁、何时、做了什么、结果如何，并集中收集、防篡改、设告警。日志是事后取证与实时检测的依据，无审计等于”裸奔”。

第七章：参数估计与假设检验

1、矩估计

**（1）原理：**样本的 $k$ 阶原点矩依概率收敛于总体的 $k$ 阶原点矩.

（2）解题步骤（待估参数为 $k$ 个 $\theta_{1}, \theta_{2}, \cdots, \theta_{k}$）

① 求出总体的 $k$ 阶原点矩 $\mu_{k}=EX^{k}\ (k=1,2,\cdots)$；

② 令样本的 $k$ 阶原点矩 $A_{k}=\dfrac{1}{n}\displaystyle\sum_{i=1}^{n}X_{i}^{k}$ 等于总体的 $k$ 阶原点矩，即令

$$EX^{k}=\frac{1}{n}\sum_{i=1}^{n}X_{i}^{k}\quad(k=1,2,\cdots)$$

③ 解上面的方程方程组，得 $\theta_{j}$ 的矩估计量为 $\hat{\theta}_{j}\left(X_{1}, X_{2}, \cdots, X_{n}\right)$，则 $\theta_{j}$ 的矩估计值为 $\hat{\theta}_{j}\left(x_{1}, x_{2}, \cdots, x_{n}\right)$.

【注】 当待估参数为 1 个时，通常令 $EX=\dfrac{1}{n}\displaystyle\sum_{i=1}^{n}X_{i}$，即可解得 $\theta$ 的矩估计量与相应的矩估计值.

2、最大似然估计法

（1）$X$ 为连续型随机变量

设总体 $X$ 的密度函数为 $f(x;\theta)$，$X_{1}, X_{2}, \cdots, X_{n}$ 为取自 $X$ 的样本，则

$$L\left(x_{1}, x_{2}, \cdots, x_{n} ; \theta\right)=\prod_{i=1}^{n} f\left(x_{i} ; \theta\right)$$

称为似然函数，$L\left(x_{1}, x_{2}, \cdots, x_{n} ; \theta\right)$ 关于 $\theta$ 的最大值点 $\hat{\theta}$，称为 $\theta$ 的最大似然估计.

（2）$X$ 为离散型随机变量

设总体 $X$ 的分布律 $P\left\{X=a_{i}\right\}=p\left(a_{i} ; \theta\right), i=1,2, \cdots$，$X_{1}, X_{2}, \cdots, X_{n}$ 为取自 $X$ 的样本，则 $X_{1}, X_{2}, \cdots, X_{n}$ 的联合分布律

$$L\left(x_{1}, x_{2}, \cdots, x_{n} ; \theta\right)=\prod_{i=1}^{n} p\left(x_{i} ; \theta\right), \quad x_{i} \text{ 为 } a_{i}(i=1,2, \cdots) \text{ 中的某一个数}$$

称为似然函数，$L\left(x_{1}, x_{2}, \cdots, x_{n} ; \theta\right)$ 关于 $\theta$ 的最大值点 $\hat{\theta}$，称为 $\theta$ 的最大似然估计.

【注】 上面（1），（2）中的 $\theta$ 可以是多个待估参数 $\left(\theta_{1}, \theta_{2}, \cdots, \theta_{k}\right)$.

（3）最大似然估计的解题步骤（待估参数为 $k$ 个 $\theta_{1}, \theta_{2}, \cdots, \theta_{k}$）

① 写出似然函数

$$L\left(x_{1}, x_{2}, \cdots, x_{n} ; \theta_{1}, \theta_{2}, \cdots, \theta_{k}\right)=\prod_{i=1}^{n} p\left(x_{i} ; \theta_{1}, \theta_{2}, \cdots, \theta_{k}\right)\quad(\text{离散型})$$

$$L\left(x_{1}, x_{2}, \cdots, x_{n} ; \theta_{1}, \theta_{2}, \cdots, \theta_{k}\right)=\prod_{i=1}^{n} f\left(x_{i} ; \theta_{1}, \theta_{2}, \cdots, \theta_{k}\right)\quad(\text{连续型})$$

② 取对数 $\ln L$；

③ 若 $\ln L$ 对 $\theta_{1}, \theta_{2}, \cdots, \theta_{k}$ 可微，求偏导数 $\dfrac{\partial \ln L}{\partial \theta_{i}}, i=1,2, \cdots, k$；判断方程组 $\dfrac{\partial \ln L}{\partial \theta_{i}}=0$ 是否有解. 若有解，则其解即为所求最大似然估计；若无解则需要考虑极大似然估计的意义（似然函数取得最大值），此时，估计值常在 $\theta_{i}$ 的边界点上达到.

【注】 对于只有一个未知参数只需将步骤③中求偏导变为一元函数求导即可.

3、估计量的无偏性、有效性、一致性（相合性）

（1）无偏性

如果 $\theta$ 的估计量 $\hat{\theta}\left(X_{1}, X_{2}, \cdots, X_{n}\right)$ 的数学期望 $E\hat{\theta}$ 存在，且 $E\hat{\theta}=\theta$ 则称 $\hat{\theta}\left(X_{1}, X_{2}, \cdots, X_{n}\right)$ 是未知参数 $\theta$ 的无偏估计量.

（2）有效性

$\hat{\theta}_{1}\left(X_{1}, X_{2}, \cdots, X_{n}\right)$ 和 $\hat{\theta}_{2}\left(X_{1}, X_{2}, \cdots, X_{n}\right)$ 都是未知参数 $\theta$ 的无偏估计量，若 $D\left(\hat{\theta}_{1}\right) \leq D\left(\hat{\theta}_{2}\right)$，且至少对于某一个 $\theta \in \Theta$ 左式中的不等号成立，则称 $\hat{\theta}_{1}\left(X_{1}, X_{2}, \cdots, X_{n}\right)$ 比 $\hat{\theta}_{2}\left(X_{1}, X_{2}, \cdots, X_{n}\right)$ 更有效.

（3）一致性（相合性）

若对任意 $\varepsilon>0$，有 $\lim\limits_{n \to \infty} P\left\{\left|\hat{\theta}-\theta\right|<\varepsilon\right\}=1$，则称 $\hat{\theta}$ 为 $\theta$ 的一致估计量.

4、区间估计

单正态总体的区间估计

设 $X \sim N\left(\mu, \sigma^{2}\right)$，$X_{1}, X_{2}, \cdots, X_{n}$ 为随机样本，样本均值为 $\bar{X}$，样本方差为 $S^{2}$

未知参数 已知条件 置信度为 $1-\alpha$ 的置信区间
$\mu$ $\sigma^{2}$ 已知 $\left(\bar{X}-U_{\alpha / 2} \dfrac{\sigma}{\sqrt{n}},\ \bar{X}+U_{\alpha / 2} \dfrac{\sigma}{\sqrt{n}}\right)$
$\mu$ $\sigma^{2}$ 未知 $\left(\bar{X}-t_{\alpha / 2}(n-1) \dfrac{S}{\sqrt{n}},\ \bar{X}+t_{\alpha / 2}(n-1) \dfrac{S}{\sqrt{n}}\right)$

5、假设检验

（1）假设检验的两类错误

1）第一类错误（弃真错误）

当 $H_{0}$ 为真时，而样本值却落入了拒绝域，选择拒绝原假设 $H_{0}$，记犯此类错误的概率为 $\alpha$，即

$$P\left\{\text{否定} H_{0} \mid H_{0} \text{为真}\right\}=\alpha .$$

2）第二类错误（纳伪错误）

当 $H_{0}$ 为假时，而样本值不在拒绝域，选择接受原假设 $H_{0}$，记犯此类错误的概率为 $\beta$，即

$$P\left\{\text{接受} H_{0} \mid H_{0} \text{为假}\right\}=\beta .$$

（2）显著性水平为 $\alpha$ 的单正态总体均值和方差的假设检验

原假设 $H_{0}$ 备择假设 $H_{1}$ 已知条件 检验统计量 $H_{0}$ 的拒绝域
$\mu=\mu_{0}$ $\mu \neq \mu_{0}$ $\sigma^{2}$ 已知 $U=\dfrac{\bar{X}-\mu_{0}}{\sigma_{0} / \sqrt{n}} \sim N(0,1)$ $\vert U\vert>u_{\alpha / 2}$
$\mu=\mu_{0}$ $\mu \neq \mu_{0}$ $\sigma^{2}$ 未知 $T=\dfrac{\bar{X}-\mu_{0}}{S / \sqrt{n}} \sim t(n-1)$ $\vert T\vert>t_{\alpha / 2}(n-1)$
$\sigma^{2}=\sigma_{0}^{2}$ $\sigma^{2} \neq \sigma_{0}^{2}$ $\mu$ 已知 $\chi^{2}=\dfrac{1}{\sigma_{0}^{2}} \displaystyle\sum_{i=1}^{n}\left(X_{i}-\mu_{0}\right)^{2} \sim \chi^{2}(n)$ $\chi^{2}>\chi_{\alpha / 2}^{2}(n)$ 或 $\chi^{2}<\chi_{1-\alpha / 2}^{2}(n)$
$\sigma^{2}=\sigma_{0}^{2}$ $\sigma^{2} \neq \sigma_{0}^{2}$ $\mu$ 未知 $\chi^{2}=\dfrac{(n-1) S^{2}}{\sigma_{0}^{2}} \sim \chi^{2}(n-1)$ $\chi^{2}>\chi_{\alpha / 2}^{2}(n-1)$ 或 $\chi^{2}<\chi_{1-\alpha / 2}^{2}(n-1)$

6、矩估计与最大似然估计的要点对比

  • 矩估计：用样本矩 $A_{k}=\dfrac{1}{n}\displaystyle\sum_{i=1}^{n}X_{i}^{k}$ 替换总体矩 $EX^{k}$，解方程组。优点：不依赖分布的具体形式、计算简单；缺点：有时不唯一，且未充分利用分布信息。
  • 最大似然估计：取使样本出现概率（似然函数 $L(\theta)=\prod_{i=1}^{n}f(x_{i};\theta)$）最大的 $\hat{\theta}$。步骤：写似然函数 → 取对数 → 求导找驻点 → 若无驻点（如均匀分布），回到定义在参数边界上讨论。
  • 共性：二者一般都满足一致性（相合性）；最大似然估计具有不变性——若 $\hat{\theta}$ 是 $\theta$ 的最大似然估计，则 $g(\hat{\theta})$ 是 $g(\theta)$ 的最大似然估计。

7、典型例题

例1 设总体 $X\sim U(0,\theta)$，$X_{1},\cdots,X_{n}$ 为样本，求 $\theta$ 的矩估计与最大似然估计.

解：矩估计：由 $EX=\dfrac{\theta}{2}=\bar{X}$ 得 $\hat{\theta}_{M}=2\bar{X}$.

最大似然：$L(\theta)=\dfrac{1}{\theta^{n}}$（要求 $\theta\geq\max x_{i}$），关于 $\theta$ 单调递减，故在边界处取到最大值，$\hat{\theta}_{L}=\max\{X_{1},\cdots,X_{n}\}$.

【注】此例说明最大似然估计未必来自求导驻点；且 $\hat{\theta}_{L}$ 有偏（$E\hat{\theta}_{L}=\dfrac{n}{n+1}\theta$），修正为 $\dfrac{n+1}{n}\max X_{i}$ 才是无偏估计。

例2 设总体 $X\sim N(\mu,\sigma^{2})$，求 $\mu,\sigma^{2}$ 的最大似然估计.

解：对数似然 $\ln L=-\dfrac{n}{2}\ln(2\pi\sigma^{2})-\dfrac{1}{2\sigma^{2}}\displaystyle\sum_{i=1}^{n}(x_{i}-\mu)^{2}$，对 $\mu$ 求导得 $\hat{\mu}=\bar{X}$；对 $\sigma^{2}$ 求导得 $\hat{\sigma}^{2}=\dfrac{1}{n}\displaystyle\sum_{i=1}^{n}(X_{i}-\bar{X})^{2}$.

【注】$\hat{\sigma}^{2}$ 的分母是 $n$ 而不是 $n-1$，故最大似然估计有偏；无偏修正后即为样本方差 $S^{2}$。

例3（假设检验应用）某元件寿命的标准差 $\sigma=100$ 小时，抽 25 件测得均值 $\bar{x}=950$ 小时，在 $\alpha=0.05$ 下检验 $H_{0}:\mu=1000$.

解：$U=\dfrac{950-1000}{100/\sqrt{25}}=-2.5$，$|U|=2.5>u_{0.025}=1.96$，落入拒绝域，拒绝 $H_{0}$，认为平均寿命显著低于 1000 小时。

8、常见混淆点辨析

  • 置信区间 vs 假设检验：双侧检验的”接受域”恰对应置信度 $1-\alpha$ 的置信区间——$\mu_{0}$ 落在区间内 $\Leftrightarrow$ 不拒绝 $H_{0}$，二者是同一套推断的两种表述。
  • 两类错误此消彼长：样本量固定时，减小 $\alpha$ 必然增大 $\beta$；同时控制两类错误的唯一办法是增大样本量。通常只控制 $\alpha$（显著性水平），故称”显著性检验”。
  • “接受 $H_{0}$” ≠ “$H_{0}$ 为真”：只是样本证据不足以拒绝，更严谨的表述是”不拒绝 $H_{0}$”。
  • 无偏性、有效性、一致性互相独立：无偏是对期望的要求，有效性是同为无偏时比较方差，一致性是大样本极限性质，三者不可互相替代。

9、本章小结

  • 点估计两法：矩估计（换矩解方程）、最大似然（写似然、取对数、求驻点或边界）；
  • 评价三标准：无偏、有效、一致；
  • 区间估计套公式：$\sigma^{2}$ 已知用 $U$，未知用 $T$，方差用 $\chi^{2}$；
  • 假设检验四步：设假设、选统计量、定拒绝域、作判断；牢记两类错误的含义与关系。

第六章：数理统计的基本概念

发表于 2026-08-30 更新于 2026-10-25 分类于 高等数学 本文字数： 6.9k 阅读时长 ≈ 6 分钟

第六章：数理统计的基本概念

1、重要统计量

（1）样本均值

$$\bar{X}=\frac{1}{n}\sum_{i=1}^{n} X_{i}, \quad \text{观测值 } \bar{x}=\frac{1}{n}\sum_{i=1}^{n} x_{i}.$$

$$E\bar{X}=\mu, \quad D\bar{X}=\frac{\sigma^{2}}{n}.$$

（2）样本方差

$$S^{2}=\frac{1}{n-1}\sum_{i=1}^{n}\left(X_{i}-\bar{X}\right)^{2}, \quad \text{观测值为 } s^{2}=\frac{1}{n-1}\sum_{i=1}^{n}\left(x_{i}-\bar{x}\right)^{2}.$$

$$ES^{2}=\sigma^{2}.$$

（3）样本标准差

$$S=\sqrt{\frac{1}{n-1}\sum_{i=1}^{n}\left(X_{i}-\bar{X}\right)^{2}}, \quad \text{观测值为 } s=\sqrt{\frac{1}{n-1}\sum_{i=1}^{n}\left(x_{i}-\bar{x}\right)^{2}}.$$

（4）样本 $k$ 阶原点矩

$$A_{k}=\frac{1}{n}\sum_{i=1}^{n} X_{i}^{k}, \quad \text{观测值为 } a_{k}=\frac{1}{n}\sum_{i=1}^{n} x_{i}^{k}, \quad (k=1,2,\cdots).$$

如果总体的 $X$ 的 $k$ 阶原点矩 $EX^{k}=\mu_{k}\ (k=1,2,\cdots)$ 存在，则当 $n\to\infty$ 时有

$$A_{k}=\frac{1}{n}\sum_{i=1}^{n} X_{i}^{k} \xrightarrow{P} EX^{k}, \quad (k=1,2,\cdots).$$

（5）样本 $k$ 阶中心矩

$$B_{k}=\frac{1}{n}\sum_{i=1}^{n}\left(X_{i}-\bar{X}\right)^{k}, \quad \text{观测值为 } b_{k}=\frac{1}{n}\sum_{i=1}^{n}\left(x_{i}-\bar{x}\right)^{k}, \quad (k=2,3,\cdots)$$

（6）顺序统计量

设总体 $X$ 的分布函数为 $F(x)$，$X_{1}, X_{2}, \cdots, X_{n}$ 是来自总体 $X$ 的样本，则统计量 $X_{(n)}=\max(X_{1}, X_{2}, \cdots, X_{n})$ 和 $X_{(1)}=\min(X_{1}, X_{2}, \cdots, X_{n})$ 的分布函数分别为

$$F_{X_{(n)}}(x)=P\{\max(X_{1}, X_{2}, \cdots, X_{n})\leq x\}=[F(x)]^{n},$$

$$F_{X_{(1)}}(x)=P\{\min(X_{1}, X_{2}, \cdots, X_{n})\leq x\}=1-[1-F(x)]^{n}.$$

2、三大分布

（1）$\chi^{2}$ 分布

1）典型模式

设随机变量 $X_{1}, X_{2}, \cdots, X_{n}$ 相互独立，且均服从标准正态分布 $N(0,1)$，则随机变量 $\chi^{2}=X_{1}^{2}+X_{2}^{2}+\cdots+X_{n}^{2}$ 服从自由度为 $n$ 的 $\chi^{2}$ 分布，记作 $\chi^{2}\sim\chi^{2}(n)$.

2）$\chi^{2}$ 分布的性质

设 $X\sim\chi^{2}(n)$，$Y\sim\chi^{2}(m)$，且 $X$ 和 $Y$ 相互独立，则 $X+Y\sim\chi^{2}(n+m)$.

3）$\chi^{2}$ 分布的数字特征

$$E\chi^{2}=n, \quad D\chi^{2}=2n.$$

4）上 $\alpha$ 分位点 $\chi_{\alpha}^{2}(n)$

设 $\chi^{2}\sim\chi^{2}(n)$，对于任给的 $\alpha\ (0<\alpha<1)$，称满足条件 $P\{\chi^{2}>\chi_{\alpha}^{2}(n)\}=\alpha$ 的点 $\chi_{\alpha}^{2}(n)$ 为 $\chi^{2}(n)$ 的上 $\alpha$ 分位点.

（2）$t$ 分布

1）典型模式

设随机变量 $X\sim N(0,1)$，$Y\sim\chi^{2}(n)$，且 $X$ 和 $Y$ 相互独立，则随机变量 $t=\dfrac{X}{\sqrt{Y/n}}$ 服从自由度为 $n$ 的 $t$ 分布，记作 $t\sim t(n)$.

2）性质

$t$ 分布的概率密度 $f(x)$ 是偶函数，且有 $\lim\limits_{x\to\infty} f(x)=\dfrac{1}{\sqrt{2\pi}}e^{-\frac{x^{2}}{2}}$，即当 $n$ 充分大时，$t(n)$ 分布近似于 $N(0,1)$ 分布.

3）上 $\alpha$ 分位点 $t_{\alpha}(n)$

设 $t\sim t(n)$，对于任给的 $\alpha\ (0<\alpha<1)$，称满足条件 $P\{t>t_{\alpha}(n)\}=\alpha$ 的点 $t_{\alpha}(n)$ 为 $t(n)$ 的上 $\alpha$ 分位点.

（3）$F$ 分布

1）典型模式

设随机变量 $X\sim\chi^{2}(m)$，$Y\sim\chi^{2}(n)$，且 $X$ 和 $Y$ 相互独立，则随机变量 $F=\dfrac{X/m}{Y/n}$ 服从自由度为 $(m,n)$ 的 $F$ 分布，记作 $F\sim F(m,n)$.

2）性质

若 $F\sim F(m,n)$，则 $\dfrac{1}{F}\sim F(n,m)$.

3）上 $\alpha$ 分位点 $F_{\alpha}(m,n)$

设 $F\sim F(m,n)$，对于任给的 $\alpha\ (0<\alpha<1)$，称满足条件 $P\{F>F_{\alpha}(m,n)\}=\alpha$ 的点 $F_{\alpha}(m,n)$ 为 $F(m,n)$ 的上 $\alpha$ 分位点.

3、一个正态总体抽样分布的重要结论

设 $X_{1}, X_{2}, \cdots, X_{n}$ 是来自正态总体 $X\sim N(\mu,\sigma^{2})$ 的样本，样本均值为 $\bar{X}$，样本方差为 $S^{2}$，则有

（1）$\bar{X}\sim N\left(\mu,\dfrac{\sigma^{2}}{n}\right)$，$\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}\sim N(0,1)$；

（2）$\bar{X}$ 与 $S^{2}$ 相互独立，且 $\dfrac{(n-1)S^{2}}{\sigma^{2}}\sim\chi^{2}(n-1)$；

（3）$\dfrac{\bar{X}-\mu}{S/\sqrt{n}}\sim t(n-1)$；

（4）$\dfrac{1}{\sigma^{2}}\displaystyle\sum_{i=1}^{n}\left(X_{i}-\mu\right)^{2}\sim\chi^{2}(n)$.

4、两个正态总体的抽样分布

设 $X\sim N(\mu_{1},\sigma_{1}^{2})$，$Y\sim N(\mu_{2},\sigma_{2}^{2})$，$X_{1}, X_{2}, \cdots, X_{n_{1}}$ 和 $Y_{1}, Y_{2}, \cdots, Y_{n_{2}}$ 分别为来自总体 $X$ 和 $Y$ 的样本，且两个样本相互独立，则有

（1）$\dfrac{(\bar{X}-\bar{Y})-(\mu_{1}-\mu_{2})}{\sqrt{\dfrac{\sigma_{1}^{2}}{n_{1}}+\dfrac{\sigma_{2}^{2}}{n_{2}}}}\sim N(0,1)$；

（2）如果 $\sigma_{1}^{2}=\sigma_{2}^{2}$，则 $\dfrac{(\bar{X}-\bar{Y})-(\mu_{1}-\mu_{2})}{S_{w}\sqrt{\dfrac{1}{n_{1}}+\dfrac{1}{n_{2}}}}\sim t(n_{1}+n_{2}-2)$，其中 $S_{w}^{2}=\dfrac{(n_{1}-1)S_{1}^{2}+(n_{2}-1)S_{2}^{2}}{n_{1}+n_{2}-2}$；

（3）$\dfrac{\dfrac{1}{\sigma_{1}^{2}}\displaystyle\sum_{i=1}^{n_{1}}\left(X_{i}-\mu_{1}\right)^{2}/n_{1}}{\dfrac{1}{\sigma_{2}^{2}}\displaystyle\sum_{j=1}^{n_{2}}\left(Y_{j}-\mu_{2}\right)^{2}/n_{2}}\sim F(n_{1}, n_{2})$；

（4）$\dfrac{S_{1}^{2}/\sigma_{1}^{2}}{S_{2}^{2}/\sigma_{2}^{2}}\sim F(n_{1}-1, n_{2}-1)$.

5、三大抽样分布的构造直觉与应用场景

  • $\chi^{2}$ 分布：$n$ 个相互独立标准正态变量的平方和，$\chi^{2}=X_{1}^{2}+\cdots+X_{n}^{2}\sim\chi^{2}(n)$。直觉：衡量”总体波动的大小”，用于方差的区间估计与检验；$E\chi^{2}(n)=n,\ D\chi^{2}(n)=2n$。
  • $t$ 分布：$T=\dfrac{X}{\sqrt{Y/n}}\sim t(n)$，其中 $X\sim N(0,1)$，$Y\sim\chi^{2}(n)$，且 $X$ 与 $Y$ 独立。直觉：把标准化中的 $\sigma$ 换成样本标准差 $S$ 后引入的”额外不确定性”，自由度小时尾部比正态厚；$n\to\infty$ 时趋于 $N(0,1)$。用于 $\sigma$ 未知时关于均值的推断。
  • $F$ 分布：$F=\dfrac{X/m}{Y/n}\sim F(m,n)$，其中 $X\sim\chi^{2}(m)$，$Y\sim\chi^{2}(n)$，且相互独立。直觉：两个方差之比，用于比较两总体方差、回归方程显著性检验；由 $\dfrac{1}{F}\sim F(n,m)$ 可得 $F_{1-\alpha}(m,n)=\dfrac{1}{F_{\alpha}(n,m)}$。

6、典型例题

例1 设 $X_{1},\cdots,X_{6}$ 来自 $N(0,1)$，$Y=(X_{1}+X_{2}+X_{3})^{2}+(X_{4}+X_{5}+X_{6})^{2}$，求常数 $C$ 使 $CY$ 服从 $\chi^{2}$ 分布.

解：$X_{1}+X_{2}+X_{3}\sim N(0,3)$，故 $\dfrac{X_{1}+X_{2}+X_{3}}{\sqrt{3}}\sim N(0,1)$，其平方服从 $\chi^{2}(1)$；同理第二项亦然。由 $\chi^{2}$ 的可加性，$\dfrac{Y}{3}\sim\chi^{2}(2)$，故 $C=\dfrac{1}{3}$.

例2 设 $X_{1},\cdots,X_{n}$ 来自 $N(\mu,\sigma^{2})$，求 $ES^{2}$ 与 $DS^{2}$.

解：由 $\dfrac{(n-1)S^{2}}{\sigma^{2}}\sim\chi^{2}(n-1)$ 及 $E\chi^{2}(k)=k,\ D\chi^{2}(k)=2k$ 得

$$ES^{2}=\frac{\sigma^{2}}{n-1}\cdot(n-1)=\sigma^{2},\quad DS^{2}=\frac{\sigma^{4}}{(n-1)^{2}}\cdot 2(n-1)=\frac{2\sigma^{4}}{n-1}.$$

【注】$ES^{2}=\sigma^{2}$ 正是样本方差分母取 $n-1$ 的原因（无偏性）。

例3 设 $X_{1},X_{2},X_{3},X_{4}$ 来自 $N(0,2^{2})$，$Y=a(X_{1}-2X_{2})^{2}+b(3X_{3}-4X_{4})^{2}$，求 $a,b$ 使 $Y\sim\chi^{2}(2)$.

解：$X_{1}-2X_{2}\sim N(0,20)$，故 $\dfrac{X_{1}-2X_{2}}{\sqrt{20}}\sim N(0,1)$，取 $a=\dfrac{1}{20}$；同理 $3X_{3}-4X_{4}\sim N(0,100)$，取 $b=\dfrac{1}{100}$.

7、常见混淆点辨析

  • $\bar{X}$ 与 $S^{2}$ 相互独立只对正态总体成立，换成其他总体一般不成立。
  • $t$ 统计量中用样本标准差 $S$：$\dfrac{\bar{X}-\mu}{S/\sqrt{n}}\sim t(n-1)$；若换成 $\sigma$ 则是 $N(0,1)$，两者适用条件不同，切勿混用。
  • 自由度要记准：$\dfrac{(n-1)S^{2}}{\sigma^{2}}\sim\chi^{2}(n-1)$ 的自由度是 $n-1$（因 $\bar{X}$ 消耗一个约束）；而 $\dfrac{1}{\sigma^{2}}\displaystyle\sum_{i=1}^{n}(X_{i}-\mu)^{2}\sim\chi^{2}(n)$ 的自由度是 $n$（$\mu$ 已知，无约束）。
  • 分位点的方向：上 $\alpha$ 分位点 $u_{\alpha}$ 满足 $P\{U>u_{\alpha}\}=\alpha$；双侧区间与双侧检验用 $\dfrac{\alpha}{2}$ 分位点。

8、本章小结

  • 三大分布都源于标准正态：$\chi^{2}$=平方和，$t$=正态除以根号卡方，$F$=卡方之比；
  • 单正态总体的四条结论（$\bar{X}$ 的分布、$\bar{X}$ 与 $S^{2}$ 独立、$t$ 统计量、离差平方和的卡方分布）是下一章区间估计与假设检验的全部基础；
  • 记牢数字特征：$E\chi^{2}(n)=n,\ D\chi^{2}(n)=2n$，可顺手推出 $ES^{2}=\sigma^{2}$。

解：$\bar{X}\sim N\left(0,\dfrac{9}{9}\right)=N(0,1)$，故 $P\{\bar{X}>1\}=1-\Phi(1)\approx0.1587$.

第五章：大数定律与中心极限定理

第五章：大数定律与中心极限定理

1、大数定律

（1）依概率收敛

对于随机变量序列 $X_1, X_2, \cdots, X_n, \cdots$ 和常数 $a$，如果对于任意给定的正数 $\varepsilon$，有

$$\lim_{n\to\infty} P\{|X_n - a| < \varepsilon\} = 1,$$

则称随机变量序列 $X_1, X_2, \cdots, X_n, \cdots$ 依概率收敛于 $a$，记作 $X_n \xrightarrow{P} a$.

（2）切比雪夫大数定律

设随机变量 $X_1, X_2, \cdots, X_n, \cdots$ 相互独立，数学期望 $EX_i$ 和方差 $DX_i$ 均存在，且方差 $DX_i$ 有公共上界，即存在常数 $C$，使 $DX_i \leq C$ $(i=1,2,\cdots)$，则对于任意给定的正数 $\varepsilon$，总有

$$\lim_{n\to\infty} P\left\{\left|\frac{1}{n}\sum_{i=1}^{n} X_i - \frac{1}{n}\sum_{i=1}^{n} EX_i\right| < \varepsilon\right\} = 1.$$

【注】上式表明：当 $n$ 很大时，相互独立方差有公共上界的随机变量的平均值 $\frac{1}{n}\sum_{i=1}^{n} X_i$ 依概率收敛于其数学期望 $\frac{1}{n}\sum_{i=1}^{n} EX_i$.

（3）伯努利大数定律

设 $n_A$ 是 $n$ 次独立重复试验中事件 $A$ 发生的次数，$p$ 是事件 $A$ 在每次试验中发生的概率，则对于任意正数 $\varepsilon > 0$，有

$$\lim_{n\to\infty} P\left\{\left|\frac{n_A}{n} - p\right| < \varepsilon\right\} = 1.$$

【注】上式表明：当 $n$ 很大时，随机事件 $A$ 发生的频率 $\frac{n_A}{n}$ 依概率收敛于事件 $A$ 的概率 $p$，因此在试验次数充分大时，可以用频率来近似代替概率.

（4）辛钦大数定律

设随机变量 $X_1, X_2, \cdots, X_n, \cdots$ 相互独立，服从相同的分布，具有数学期望 $EX_i = \mu$ $(i=1,2,\cdots)$，则对于任意给定的正数 $\varepsilon$，总有

$$\lim_{n\to\infty} P\left\{\left|\frac{1}{n}\sum_{i=1}^{n} X_i - \mu\right| < \varepsilon\right\} = 1.$$

【注】上式表明：当 $n$ 很大时，独立同分布的随机变量的平均值 $\frac{1}{n}\sum_{i=1}^{n} X_i$ 依概率收敛于它的数学期望 $\mu$.

2、中心极限定理

（1）列维-林德伯格中心极限定理

设随机变量 $X_1, X_2, \cdots, X_n, \cdots$ 相互独立，服从相同的分布，具有数学期望 $EX_i = \mu$ 和方差 $DX_i = \sigma^2 > 0$ $(i=1,2,\cdots)$，则对于任意实数 $x$，有

$$\lim_{n\to\infty} P\left\{\frac{\sum_{i=1}^{n} X_i - n\mu}{\sqrt{n}\sigma} \leq x\right\} = \Phi(x).$$

【注】上式表明：在定理条件下，当 $n$ 充分大时，$\sum_{i=1}^{n} X_i$ 以正态分布为极限分布.

（2）棣莫弗-拉普拉斯中心极限定理

设随机变量 $X_n$ 服从参数为 $n, p$ $(0 < p < 1, n=1,2,\cdots)$ 的二项分布，即

$$X_n \sim B(n, p),$$

则对于任意实数 $x$，有

$$\lim_{n\to\infty} P\left\{\frac{X_n - np}{\sqrt{np(1-p)}} \leq x\right\} = \Phi(x).$$

【注】上式表明：当重复试验次数足够多时，二项分布以正态分布为极限分布.

3、大数定律与中心极限定理的直观理解

大数定律：频率稳定性的理论保证

  • 直观含义：大量独立重复试验中，样本均值 $\frac{1}{n}\sum_{i=1}^{n}X_i$ 会”稳定”在期望 $\mu$ 附近——这就是”抛硬币次数越多，正面频率越接近 $\frac{1}{2}$”的数学表述。
  • “依概率收敛”的含义：偏差超过任意 $\varepsilon$ 的概率趋于 0，不排除偶尔出现大幅波动，只是波动越来越罕见。
  • 三个大数定律的侧重点：
    • 切比雪夫大数定律：条件最弱（两两不相关、方差一致有界），结论最抽象，是理论基石；
    • 伯努利大数定律：专指频率 $\frac{n_A}{n}$ 依概率收敛于 $p$，是”频率稳定于概率”的直接保证；
    • 辛钦大数定律：独立同分布、只要求期望存在（不要求方差），实用中最常用，也是蒙特卡洛方法的理论依据。

中心极限定理：正态分布”无处不在”的原因

  • 直观含义：大量微小且独立的随机因素叠加，其总和的分布近似正态——无论原始分布是什么形状。这解释了测量误差、人群身高、考试分数为何都接近钟形曲线。
  • 定量形式：$\sum_{i=1}^{n}X_i\approx N(n\mu,n\sigma^2)$，标准化后 $\dfrac{\sum_{i=1}^{n}X_i-n\mu}{\sqrt{n}\sigma}\approx N(0,1)$；注意涨落的量级是 $\sqrt{n}$，即”总和的波动以根号速度增长”。
  • 棣莫弗-拉普拉斯定理是特例：二项分布 $B(n,p)$ 在 $n$ 大时可用 $N(np,np(1-p))$ 近似，一般 $np(1-p)\geqslant 10$ 时效果较好。

4、典型例题

例1 设 $X_1,\cdots,X_{100}$ 独立同分布，$EX_i=1,\ DX_i=4$，估计 $P\left\{80<\sum_{i=1}^{100}X_i<120\right\}$.

解：$\sum_{i=1}^{100}X_i\approx N(100,400)$，标准化得

$$P\left\{80<\sum_{i=1}^{100}X_i<120\right\}\approx\Phi\left(\frac{120-100}{20}\right)-\Phi\left(\frac{80-100}{20}\right)=2\Phi(1)-1\approx 0.6826.$$

例2 一加法器同时收到 20 个相互独立的噪声电压 $V_k\sim U(0,10)$，求总电压超过 105 的概率（已知 $\Phi(0.387)\approx0.652$）。

解：$EV_k=5,\ DV_k=\dfrac{10^2}{12}=\dfrac{25}{3}$，故 $V=\sum_{k=1}^{20}V_k\approx N\left(100,\ \frac{500}{3}\right)$，

$$P\left\{V>105\right\}=1-\Phi\left(\frac{105-100}{\sqrt{500/3}}\right)\approx 1-\Phi(0.387)\approx 0.348.$$

例3 某保险公司有 10000 人投保，每人出险概率 $p=0.006$，每人保费 12 元，出险赔付 1000 元，求公司亏本的概率。

解：出险人数 $X\sim B(10000,0.006)$，亏本即 $1000X>120000$，即 $X>120$。由棣莫弗-拉普拉斯定理，$np=60,\ np(1-p)=59.64$，

$$P\left\{X>120\right\}\approx 1-\Phi\left(\frac{120-60}{\sqrt{59.64}}\right)\approx 1-\Phi(7.77)\approx 0.$$

即亏本概率几乎为零——这就是保险业依靠”大数法则”稳健盈利的原理。

5、常见混淆点辨析

  • 大数定律 vs 中心极限定理：前者说样本均值收敛到常数（$\bar{X}\xrightarrow{P}\mu$），后者说总和的标准化分布趋于正态；大数定律回答”稳不稳”，中心极限定理回答”如何波动”。
  • 依概率收敛 ≠ 逐点收敛：依概率收敛允许偶尔出现大偏差，只是其概率趋于 0。
  • 中心极限定理的使用条件：独立、同分布、方差存在且为正；若分布严重重尾（如柯西分布，方差不存在），定理失效。
  • 二项分布正态近似的连续性修正：更精确的写法是 $P\left\{a\leq X\leq b\right\}\approx\Phi\left(\dfrac{b+0.5-np}{\sqrt{npq}}\right)-\Phi\left(\dfrac{a-0.5-np}{\sqrt{npq}}\right)$，考研中一般不强制要求。

6、本章小结

  • 大数定律：$\dfrac{1}{n}\sum_{i=1}^{n}X_i\xrightarrow{P}\mu$——平均值趋于稳定；
  • 中心极限定理：$\dfrac{\sum_{i=1}^{n}X_i-n\mu}{\sqrt{n}\sigma}\xrightarrow{d}N(0,1)$——总和近似正态；
  • 三个大数定律条件递弱：切比雪夫（不相关 + 方差有界）→ 伯努利（频率特例）→ 辛钦（独立同分布仅需期望）；
  • 应用套路：识别”独立同分布求和”→ 写出 $n\mu$ 与 $n\sigma^2$ → 标准化 → 查 $\Phi$ 表。

第四章：随机变量的数字特征

1、一维随机变量的数学期望

（1）离散型

设随机变量 $X$ 的分布律为 $P\{X=x_i\}=p_i\ (i=1,2,\cdots)$，若级数 $\sum_{i=1}^{\infty} x_i p_i$ 绝对收敛，则称 $EX=\sum_{i=1}^{\infty} x_i p_i$ 为随机变量 $X$ 的数学期望.

（2）连续型

设连续型随机变量 $X$ 的概率密度为 $f(x)$，若积分 $\int_{-\infty}^{+\infty} xf(x)\mathrm{d}x$ 绝对收敛，则称 $EX=\int_{-\infty}^{+\infty} xf(x)\mathrm{d}x$ 为 $X$ 的数学期望

（3）随机变量函数 $Y=g(X)$ 的期望

设 $X$ 是一个随机变量，$g(x)$ 为连续实函数. 令 $Y=g(X)$

1）离散型

若 $X$ 的分布律为 $P\{X=x_i\}=p_i\ (i=1,2,\cdots)$，则

$$EY=E[g(X)]=\sum_{i=1}^{\infty} g(x_i) p_i.$$

2）连续型

若 $X$ 的密度函数为 $f_X(x)$，则

$$EY=E[g(X)]=\int_{-\infty}^{+\infty} g(x) f_X(x)\mathrm{d}x.$$

2、二维随机变量的数学期望

（1）离散型

设 $(X,Y)$ 的概率分布为

$$P\{X=x_i,Y=y_j\}=p_{ij}\ (i,j=1,2,\cdots),$$

则

$$EX=\sum_i x_i p_{i\cdot}=\sum_i\sum_j x_i p_{ij},$$

$$EY=\sum_j y_j p_{\cdot j}=\sum_i\sum_j y_j p_{ij}.$$

（2）连续型

设 $(X,Y)$ 的联合概率密度为 $\varphi(x,y)$，则

$$EX=\int_{-\infty}^{+\infty} x f_X(x)\mathrm{d}x=\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} x f(x,y)\mathrm{d}x\mathrm{d}y,$$

$$EY=\int_{-\infty}^{+\infty} y f_Y(y)\mathrm{d}y=\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} y f(x,y)\mathrm{d}x\mathrm{d}y.$$

（3）随机变量函数 $Z=g(X,Y)$ 的期望

设 $(X,Y)$ 为二维随机变量，$g(x,y)$ 为二元连续实函数，令 $Z=g(X,Y)$

1）离散型

若 $(X,Y)$ 的联合分布律为 $P\{X=x_i,Y=y_j\}=p_{ij},\ i,j=1,2,\cdots$，则

$$EZ=E[g(X,Y)]=\sum_{i=1}^{\infty}\sum_{j=1}^{\infty} g(x_i,y_j) p_{ij}.$$

2）连续型

若 $(X,Y)$ 的联合密度函数为 $f(x,y)$，则

$$EZ=E[g(X,Y)]=\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} g(x,y) f(x,y)\mathrm{d}x\mathrm{d}y.$$

3、最值的数学期望

若 $X_i\ (i=1,2,\cdots,n;\ n\geqslant 2)$ 独立同分布，其分布函数为 $F(x)$，概率密度为 $f(x)$，记 $Y=\min\{X_1,X_2,\cdots,X_n\}$，$Z=\max\{X_1,X_2,\cdots,X_n\}$，则

$$F_Y(y)=1-[1-F(y)]^n, f_Y(y)=n[1-F(y)]^{n-1}f(y)\Rightarrow EY=\int_{-\infty}^{+\infty} y f_Y(y)\mathrm{d}y;$$

$$F_Z(z)=[F(z)]^n, f_Z(z)=n[F(z)]^{n-1}f(z)\Rightarrow EZ=\int_{-\infty}^{+\infty} z f_Z(z)\mathrm{d}z.$$

4、数学期望的性质

（1）$E(C)=C$，$E(EX)=EX$；

（2）$E(CX)=CEX$；

（3）$E(k_1X\pm k_2Y)=k_1EX\pm k_2EY$；

（4）若 $X$ 与 $Y$ 相互独立，则有 $E(XY)=EXEY$.

5、方差

（1）随机变量 $X$ 的方差定义

设 $X$ 是一个随机变量，如果 $E(X-EX)^2$ 存在，则称 $DX=E(X-EX)^2$ 为 $X$ 的方差，称 $\sqrt{DX}$ 为标准差或均方差.

（2）方差的计算公式

$$DX=EX^2-(EX)^2.$$

【注】解题时，常用此公式计算 $EX^2=DX+(EX)^2$.

（3）方差的性质

1）$D(C)=0$，$D[E(X)]=0$，$D[D(X)]=0$；

2）$D(CX)=C^2DX$；

3）$D(C_1X+C_2)=C_1^2D(X)$；

4）$D(X\pm Y)=DX+DY\pm 2\operatorname{cov}(X,Y)$；

5）若 $X,Y$ 相互独立，则 $D(X\pm Y)=DX+DY$.

6、常用分布的 EX, DX

① $0-1$ 分布，$EX=p$，$DX=p-p^2=(1-p)p$.

② $X\sim B(n,p)$，$EX=np$，$DX=np(1-p)$.

③ $X\sim P(\lambda)$，$EX=\lambda$，$DX=\lambda$.

④ $X\sim G(p)$，$EX=\dfrac{1}{p}$，$DX=\dfrac{1-p}{p^2}$.

⑤ $X\sim U(a,b)$，$EX=\dfrac{a+b}{2}$，$DX=\dfrac{(b-a)^2}{12}$.

⑥ $X\sim E(\lambda)$，$EX=\dfrac{1}{\lambda}$，$DX=\dfrac{1}{\lambda^2}$.

⑦ $X\sim N(\mu,\sigma^2)$，$EX=\mu$，$DX=\sigma^2$.

⑧ $X\sim\chi^2(n)$，$EX=n$，$DX=2n$.

5、协方差

（1）定义

$$\operatorname{cov}(X,Y)=E[(X-EX)(Y-EY)].$$

（2）计算公式

$$\operatorname{cov}(X,Y)=EXY-EXEY.$$

（3）性质

1）$\operatorname{cov}(X,Y)=\operatorname{cov}(Y,X)$；

2）$\operatorname{cov}(X,X)=DX$；

3）$\operatorname{cov}(aX,bY)=ab\operatorname{cov}(X,Y)$；

4）$\operatorname{cov}(X,C)=0$；

5）$\operatorname{cov}(k_1X_1\pm k_2X_2,Y)=k_1\operatorname{cov}(X_1,Y)\pm k_2\operatorname{cov}(X_2,Y)$；

6）若 $X$ 与 $Y$ 相互独立，则 $\operatorname{cov}(X,Y)=0$.

6、相关系数

（1）定义

$$\rho_{XY}=\frac{\operatorname{cov}(X,Y)}{\sqrt{DX}\sqrt{DY}}.$$

（2）相关系数的性质

1）$|\rho_{XY}|\leqslant 1$；

2）$|\rho_{XY}|=1\Leftrightarrow P\{Y=aX+b\}=1\ (a\neq 0)$，且

当 $a>0$ 时，$\rho_{XY}=1$；$a<0$ 时，$\rho_{XY}=-1$.

（3）不相关的等价说法

$$\rho_{XY}=0\Leftrightarrow \operatorname{cov}(X,Y)=0\Leftrightarrow EXY=EXEY\Leftrightarrow D(X\pm Y)=DX+DY.$$

（4）不相关与独立的关系

1）$X,Y$ 相互独立 $\Rightarrow X$ 与 $Y$ 不相关，反之不成立；

2）若 $(X,Y)\sim N(\mu_1,\mu_2;\sigma_1^2,\sigma_2^2;\rho)$，则 $X$ 与 $Y$ 独立和 $X$ 与 $Y$ 不相关等价.

7、切比雪夫不等式

设随机变量 $X$ 的期望 $EX$，方差 $DX$ 都存在，则对任意 $\varepsilon>0$ 均有

$$P\{|X-EX|\geqslant\varepsilon\}\leqslant\frac{DX}{\varepsilon^2};$$

或

$$P\{|X-EX|<\varepsilon\}\geqslant 1-\frac{DX}{\varepsilon^2}.$$

8、数字特征的计算要点与直觉理解

  • 期望是”加权平均”：$EX$ 描述分布的”重心”位置；方差 $DX=E(X-EX)^2$ 描述取值围绕期望的离散程度，$DX$ 越小分布越集中。
  • 计算 $EX$、$DX$ 的三条路线：① 定义法（级数/积分求和）；② 性质法（线性性 $E(aX+bY)=aEX+bEY$、$D(aX+b)=a^2DX$）；③ 分解法（把复杂变量拆成简单变量之和，如二项分布拆成 $n$ 个 0-1 分布之和，立得 $EX=np,\ DX=np(1-p)$）。
  • 常用公式 $DX=EX^2-(EX)^2$，常用来反求 $EX^2=DX+(EX)^2$。
  • 协方差的双线性性：$\operatorname{cov}(aX+bY,Z)=a\operatorname{cov}(X,Z)+b\operatorname{cov}(Y,Z)$；$D(X\pm Y)=DX+DY\pm 2\operatorname{cov}(X,Y)$。

9、典型例题

例1 设 $X\sim P(\lambda)$（泊松分布），求 $E[X(X-1)]$.

解：$E[X(X-1)]=\displaystyle\sum_{k=0}^{\infty}k(k-1)\frac{\lambda^k}{k!}e^{-\lambda}=\lambda^2 e^{-\lambda}\sum_{k=2}^{\infty}\frac{\lambda^{k-2}}{(k-2)!}=\lambda^2$.

由此得 $DX=EX^2-(EX)^2=E[X(X-1)]+EX-(EX)^2=\lambda^2+\lambda-\lambda^2=\lambda$.

例2 设 $(X,Y)$ 在单位圆盘 $x^2+y^2\leq 1$ 上服从均匀分布，证明 $X$ 与 $Y$ 不相关但不独立.

解：由对称性 $EX=\dfrac{1}{\pi}\displaystyle\iint_{x^2+y^2\leq 1}x\,\mathrm{d}x\mathrm{d}y=0$，同理 $EY=0$；又 $EXY=\dfrac{1}{\pi}\displaystyle\iint_{x^2+y^2\leq 1}xy\,\mathrm{d}x\mathrm{d}y=0$（关于 $x$ 为奇函数），故 $\operatorname{cov}(X,Y)=0$，即不相关。但取 $A=\{|X|>\tfrac{\sqrt{2}}{2}\},\ B=\{|Y|>\tfrac{\sqrt{2}}{2}\}$，则 $P(AB)=0\neq P(A)P(B)>0$，故不独立。

【注】这是”不相关推不出独立”的经典反例；只有对二维正态，不相关与独立才等价。

例3 设 $EX=\mu,\ DX=\sigma^2$，用切比雪夫不等式估计 $P\{|X-\mu|<3\sigma\}$.

解：$P\{|X-\mu|<3\sigma\}\geqslant 1-\dfrac{\sigma^2}{(3\sigma)^2}=\dfrac{8}{9}\approx 0.89$.

【注】切比雪夫不等式只需期望方差存在、不依赖分布形式，所以估计比较粗糙（若 $X$ 为正态，真值约 $0.997$），但胜在普适，是证明大数定律的理论工具。

例4 设 $X_1,X_2,\cdots,X_n$ 相互独立，$EX_i=\mu,\ DX_i=\sigma^2$，记 $\bar{X}=\dfrac{1}{n}\displaystyle\sum_{i=1}^{n}X_i$，求 $E\bar{X}$、$D\bar{X}$.

解：由期望线性性 $E\bar{X}=\dfrac{1}{n}\cdot n\mu=\mu$；由独立性

$$D\bar{X}=\frac{1}{n^2}\sum_{i=1}^{n}DX_i=\frac{n\sigma^2}{n^2}=\frac{\sigma^2}{n}.$$

【注】$D\bar{X}=\dfrac{\sigma^2}{n}\to 0$ 正是”平均值趋于稳定”的定量表达，是下一章大数定律的雏形。

例5 设 $X\sim N(0,1)$，$Y=X^2$，求 $\operatorname{cov}(X,Y)$，并说明 $X$ 与 $Y$ 是否独立.

解：$EX=0$，$EXY=EX^3=0$（奇函数对称积分），故 $\operatorname{cov}(X,Y)=EXY-EXEY=0$，不相关；但 $Y$ 由 $X$ 完全决定，显然不独立。

【注】再次印证：不相关只排除线性关系，不排除非线性依赖。

10、常见混淆点辨析

  • 独立 vs 不相关：独立 $\Rightarrow$ 不相关，反之一般不成立（见例 2、例 5）；独立是”取值毫无瓜葛”，不相关只是”没有线性关系”。
  • $D(X+Y)=DX+DY$ 成立的条件：需要 $X,Y$ 不相关；一般情形必须加上 $2\operatorname{cov}(X,Y)$。
  • $EXY=EXEY$ 是不相关的等价条件，不是独立的等价条件。
  • 方差的量纲：$DX$ 的量纲是 $X$ 的平方，实际比较离散程度常用标准差 $\sqrt{DX}$ 或变异系数 $\sqrt{DX}/EX$。
  • $\rho_{XY}=\pm1$ 的含义：$X,Y$ 以概率 1 呈线性关系，不是”两个变量完全相同”。

11、本章小结

  • 核心公式：$DX=EX^2-(EX)^2$；$D(X\pm Y)=DX+DY\pm2\operatorname{cov}(X,Y)$；$\rho_{XY}=\dfrac{\operatorname{cov}(X,Y)}{\sqrt{DX}\sqrt{DY}}$；
  • 计算期望方差优先用”性质法 + 分解法”，定义求和留作最后手段；
  • 独立 $\Rightarrow$ 不相关，反向仅对二维正态成立；
  • 切比雪夫不等式是连接数字特征与下一章极限定理（大数定律）的桥梁。

12、补充例题

例6 设 $X,Y$ 相互独立且同服从 $N(0,1)$，求 $E\max\{X,Y\}$.

解：利用恒等式 $\max\{X,Y\}=\dfrac{X+Y+|X-Y|}{2}$，而 $X-Y\sim N(0,2)$，故 $E|X-Y|=\sqrt{2}\cdot\sqrt{\dfrac{2}{\pi}}=\dfrac{2}{\sqrt{\pi}}$，于是 $E\max\{X,Y\}=\dfrac{1}{\sqrt{\pi}}$.

【注】恒等式 $\max\{a,b\}=\frac{a+b+|a-b|}{2}$ 配合正态分布的性质，是处理最值期望的利器。

例7 设 $X$ 服从几何分布 $P\{X=k\}=p(1-p)^{k-1}\ (k=1,2,\cdots)$，求 $EX$.

解：利用幂级数 $\sum_{k=1}^{\infty}kx^{k-1}=\dfrac{1}{(1-x)^{2}}$：

$$EX=\sum_{k=1}^{\infty}kp(1-p)^{k-1}=p\cdot\frac{1}{[1-(1-p)]^{2}}=\frac{1}{p}.$$

【注】几何分布期望 $\frac{1}{p}$ 的直觉：单次成功率越低，首次成功所需的平均等待时间越长。

练习题

  1. 设 $X\sim B(n,p)$，用分解法求 $EX$、$DX$。（提示：$X=\sum_{i=1}^{n}X_i$，$X_i$ 服从 0-1 分布，$EX_i=p,\ DX_i=p(1-p)$。）
  2. 设 $X,Y$ 独立，$DX=4,\ DY=9$，求 $D(2X-3Y)$ 与 $\operatorname{cov}(X,X+Y)$。（提示：$D(2X-3Y)=4\cdot 4+9\cdot 9=97$；$\operatorname{cov}(X,X+Y)=DX=4$。）
  3. 设 $X$ 的密度 $f(x)=\dfrac{1}{2}e^{-|x|}\ (-\infty<x<+\infty)$，求 $EX,DX$。（提示：由对称性 $EX=0$；$EX^2=\displaystyle\int_{0}^{+\infty}x^2 e^{-x}\mathrm{d}x=2$，故 $DX=2$。）

第三章：多维随机变量及其分布

1、联合函数的概念与性质

（1）定义

$$F(x,y)=P\{X\leq x,Y\leq y\}\quad(-\infty<x<+\infty,\ -\infty<y<+\infty)$$

称为二维随机变量 $(X,Y)$ 的联合分布函数，它表示随机事件 $\{X\leq x\}$ 与 $\{Y\leq y\}$ 同时发生的概率。

（2）性质

1）非负性：对于任意实数 $x,y\in R$，$0\leq F(x,y)\leq 1$。

2）规范性：

$$F(-\infty,y)=\lim_{x\to-\infty}F(x,y)=0,\quad F(x,-\infty)=\lim_{y\to-\infty}F(x,y)=0,$$

$$F(-\infty,-\infty)=\lim_{\substack{x\to-\infty\\ y\to-\infty}}F(x,y)=0,\quad F(+\infty,+\infty)=\lim_{\substack{x\to+\infty\\ y\to+\infty}}F(x,y)=1.$$

3）单调不减性：$F(x,y)$ 分别关于 $x$ 和 $y$ 单调不减。

4）右连续性：$F(x,y)$ 分别关于 $x$ 和 $y$ 具有右连续性，即

$$F(x,y)=F(x+0,y),\ F(x,y)=F(x,y+0),\ x,y\in R.$$

2、二维离散型随机变量及其分布

（1）二维离散型随机变量的定义

若二维随机变量 $(X,Y)$ 可能的取值为有限对或可列无穷多对实数，则称 $(X,Y)$ 为二维离散型随机变量。

（2）联合分布律

$$P\{X=x_i,Y=y_j\}=p_{ij},\ (i,j=1,2,\cdots),$$

$$p_{ij}\geq 0,$$

$$\sum_{i=1}^{\infty}\sum_{j=1}^{\infty}p_{ij}=1.$$

（3）边缘分布律

$$P\{X=x_i\}=\sum_{j=1}^{+\infty}P\{X=x_i,Y=y_j\}=\sum_{j=1}^{+\infty}p_{ij}=p_{i\cdot}\ (i=1,2,\cdots),$$

$$P\{Y=y_j\}=\sum_{i=1}^{+\infty}P\{X=x_i,Y=y_j\}=\sum_{i=1}^{+\infty}p_{ij}=p_{\cdot j}\ (j=1,2,\cdots).$$

（4）条件分布律

对于给定的 $j$，若 $P\{Y=y_j\}>0\ (j=1,2,\cdots)$，则称

$$P\{X=x_i\mid Y=y_j\}=\frac{P\{X=x_i,Y=y_j\}}{P\{Y=y_j\}}=\frac{p_{ij}}{p_{\cdot j}},\ i=1,2,\cdots$$

为在 $Y=y_j$ 的条件下随机变量 $X$ 的条件概率分布；

对于给定的 $i$，如果 $P\{X=x_i\}>0\ (i=1,2,\cdots)$，则称

$$P\{Y=y_j\mid X=x_i\}=\frac{P\{X=x_i,Y=y_j\}}{P\{X=x_i\}}=\frac{p_{ij}}{p_{i\cdot}},\ j=1,2,\cdots$$

为在 $X=x_i$ 的条件下随机变量 $Y$ 的条件概率分布。

3、二维连续型随机变量及其分布

（1）定义

设二维随机变量 $(X,Y)$ 的联合分布函数为 $F(x,y)$，如果存在非负可积的二元函数 $f(x,y)$，使得对任意实数 $x,y$，有 $F(x,y)=\int_{-\infty}^{x}\int_{-\infty}^{y}f(u,v)\mathrm{d}u\mathrm{d}v$，则称 $(X,Y)$ 为二维连续型随机变量，称函数 $f(x,y)$ 为二维随机变量 $(X,Y)$ 的概率密度函数或联合密度函数。

（2）性质

1）$f(x,y)\geq 0\ (-\infty<x<+\infty,\ -\infty<y<+\infty)$；

2）$\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty}f(x,y)\mathrm{d}x\mathrm{d}y=1$；

3）设 $D$ 是 $xOy$ 平面上任一区域，则点 $(x,y)$ 落在 $D$ 内的概率为：

$$P\{(X,Y)\in D\}=\iint_{D}f(x,y)\mathrm{d}\sigma;$$

4）若 $f(x,y)$ 在点 $(x,y)$ 处连续，则有 $f(x,y)=\dfrac{\partial^2 F(x,y)}{\partial x\,\partial y}$.

（3）边缘密度函数

$$f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\mathrm{d}y;\quad f_Y(y)=\int_{-\infty}^{+\infty}f(x,y)\mathrm{d}x.$$

（4）条件密度函数

当 $f_Y(y)>0$ 时，称 $f_{X\mid Y}(x\mid y)=\dfrac{f(x,y)}{f_Y(y)}$ 为在条件 $Y=y$ 下 $X$ 的条件密度函数；

当 $f_X(x)>0$ 时，称 $f_{Y\mid X}(y\mid x)=\dfrac{f(x,y)}{f_X(x)}$ 为在条件 $X=x$ 下 $Y$ 的条件密度函数.

4、两个常见的二维连续型分布

（1）二维均匀分布

1）定义

设 $G$ 是平面上有界可求面积的区域，其面积为 $|G|$，若二维随机变量 $(X,Y)$ 其密度函数

$$f(x,y)=\begin{cases}\dfrac{1}{|G|}, & (x,y)\in G,\\[2mm] 0, & (x,y)\notin G\end{cases}$$

则称 $(X,Y)$ 在区域 $G$ 上服从二维均匀分布。

2）性质

若 $(X,Y)$ 在各边平行于坐标轴的矩形区域 $D=\{(x,y)\mid a\leq x\leq b,\ c\leq y\leq d\}$ 上服从二维均匀分布，则它的两个分量 $X$ 和 $Y$ 是独立的，并且分别服从区间 $[a,b],[c,d]$ 上的一维均匀分布。

（2）二维正态分布

1）定义

如果二维连续型随机变量 $(X,Y)$ 的概率密度为

$$\begin{aligned}f(x,y)={}&\frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}}\exp\left\{-\frac{1}{2(1-\rho^2)}\left[\frac{(x-\mu_1)^2}{\sigma_1^2}-\right.\right.\\&\qquad\left.\left.+\frac{2\rho(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2}+\frac{(y-\mu_2)^2}{\sigma_2^2}\right]\right\}\end{aligned}$$

其中 $-\infty<x<+\infty,\ -\infty<y<+\infty$，$\mu_1,\mu_2,\sigma_1>0,\sigma_2>0,-1<\rho<1$ 均为常数，则称 $(X,Y)$ 服从参数为 $\mu_1,\mu_2,\sigma_1,\sigma_2$ 和 $\rho$ 的二维正态分布，记作 $(X,Y)\sim N(\mu_1,\mu_2;\sigma_1^2,\sigma_2^2;\rho)$.

2）性质

① $X\sim N(\mu_1,\sigma_1^2)$，$Y\sim N(\mu_2,\sigma_2^2)$；

② $X$ 与 $Y$ 独立的充分必要条件是 $\rho=0$；

③ $X$ 与 $Y$ 的非零线性组合服从一维正态分布，且

当 $X$ 与 $Y$ 不独立时，

$$k_1X+k_2Y\sim N(k_1\mu_1+k_2\mu_2,\ k_1^2\sigma_1^2+k_2^2\sigma_2^2+2k_1k_2\rho\sigma_1\sigma_2);$$

当 $X$ 与 $Y$ 独立时，

$$k_1X+k_2Y\sim N(k_1\mu_1+k_2\mu_2,\ k_1^2\sigma_1^2+k_2^2\sigma_2^2).$$

④ 若 $(X_1,X_2)$ 服从二维正态分布，且行列式 $\begin{vmatrix} a & b \\ c & d \end{vmatrix}\neq 0$，则 $(aX_1+bX_2,\ cX_1+dX_2)$ 也服从二维正态分布.

5、随机变量的独立性

（1）定义

1）对于任意实数 $x$ 和 $y$ 有：$F(x,y)=F_X(x)F_Y(y)$，则称 $X$ 和 $Y$ 相互独立；

2）对于任意 $i,j=1,2,\cdots$ 有：$P\{X=x_i,Y=y_j\}=P\{X=x_i\}P\{Y=y_j\}$，则称二维离散型随机变量 $X$ 和 $Y$ 相互独立；

3）对于任意实数 $x$ 和 $y$ 有：$f(x,y)=f_X(x)f_Y(y)$，则称二维连续型随机变量 $X$ 和 $Y$ 相互独立.

（2）性质

1）若 $X$ 与 $Y$ 相互独立，$f(x)$ 和 $g(x)$ 为连续函数，则 $f(X)$ 与 $g(Y)$ 也相互独立；

2）若 $X_1,X_2,\cdots,X_n,Y_1,\cdots,Y_m$ 相互独立，$f(\cdot)$ 为 $n$ 元连续函数和 $g(\cdot)$ 为 $m$ 元连续函数，则 $f(X_1,X_2,\cdots,X_n)$ 与 $g(Y_1,Y_2,\cdots,Y_m)$ 也相互独立.

6、两个随机变量简单函数的概率分布

（1）离散型

已知 $(X,Y)$ 的概率分布为

$$P\{X=x_i,Y=y_j\}=p_{ij},\ i,j=1,2,\cdots.$$

则 $Z=g(X,Y)$ 的分布律为

$$P(Z=z_k)=P\{g(X,Y)=z_k\}=\sum_{g(x_i,y_j)=z_k}P(X=x_i,Y=y_j).$$

（2）连续型

1）一般方法（分布函数法）

设二维连续型随机变量 $(X,Y)$ 的概率密度为 $f(x,y)$，则随机变量 $Z=g(X,Y)$ 的分布函数和概率密度为

$$F_Z(z)=P\{Z\leq z\}=P\{g(X,Y)\leq z\}=\iint_{g(x,y)\leq z}f(x,y)\mathrm{d}x\mathrm{d}y,$$

$$f_Z(z)=F_Z’(z).$$

2）公式法（卷积公式）

设二维连续型随机变量 $(X,Y)$ 的概率密度为 $f(x,y)$，则随机变量 $Z=X+Y$ 的密度函数为

$$f_Z(z)=\int_{-\infty}^{+\infty}f(x,z-x)\mathrm{d}x\quad\text{或}\quad f_Z(z)=\int_{-\infty}^{+\infty}f(z-y,y)\mathrm{d}y.$$

若 $X$ 与 $Y$ 独立，则

$$f_Z(z)=\int_{-\infty}^{+\infty}f_X(x)f_Y(z-x)\mathrm{d}x\quad\text{或}\quad f_Z(z)=\int_{-\infty}^{+\infty}f_X(z-y)f_Y(y)\mathrm{d}y.$$

这个公式称为独立和卷积公式。

7、联合分布的使用要点

  • 由联合分布求边缘分布，离散型是”按行/列求和”，连续型是”对另一变量积分”——积分限要按联合密度非零区域确定，这是最常见的失分点。
  • 独立性验证：离散型逐对检查 $p_{ij}=p_{i\cdot}p_{\cdot j}$；连续型检查 $f(x,y)=f_X(x)f_Y(y)$ 是否”可分离变量”且非零区域为矩形（可无边）。
  • 求 $P\{(X,Y)\in D\}$ 的关键是画出 $f(x,y)>0$ 的区域与 $D$ 的交集，在交集上积分。

8、典型例题

例1 设 $(X,Y)$ 在区域 $D:\{(x,y)\mid 0<x<1,\ 0<y<x\}$ 上服从均匀分布，求边缘密度 $f_X(x),f_Y(y)$，并判断独立性。

解：$|D|=\dfrac{1}{2}$，故 $f(x,y)=2\ ((x,y)\in D)$。

$$f_X(x)=\int_{0}^{x}2\,\mathrm{d}y=2x\ (0<x<1);\quad f_Y(y)=\int_{y}^{1}2\,\mathrm{d}x=2(1-y)\ (0<y<1).$$

由于 $f(x,y)\neq f_X(x)f_Y(y)$（且 $D$ 非矩形），$X,Y$ 不独立。

例2 设 $X,Y$ 独立同分布于 $E(\lambda)$，求 $Z=X+Y$ 的密度。

解：由卷积公式，$z>0$ 时

$$f_Z(z)=\int_{0}^{z}\lambda\mathrm{e}^{-\lambda x}\cdot\lambda\mathrm{e}^{-\lambda(z-x)}\,\mathrm{d}x=\lambda^2 z\,\mathrm{e}^{-\lambda z},$$

即 $Z$ 服从参数 $(2,\lambda)$ 的伽马分布（形状参数 2）。

例3 设 $X_1,X_2,\cdots,X_n$ 独立同分布于 $U(0,1)$，求 $Z=\max\{X_1,\cdots,X_n\}$ 的密度与期望。

解：$F_Z(z)=z^n\ (0<z<1)$，故 $f_Z(z)=nz^{n-1}$，

$$EZ=\int_{0}^{1}z\cdot nz^{n-1}\,\mathrm{d}z=\frac{n}{n+1}.$$

直觉：$n$ 个均匀随机数的最大值向 $1$ 靠拢，$n$ 越大越接近 $1$。

例4 设二维离散型分布律中 $P\{X=0,Y=0\}=0.1$，$P\{X=0,Y=1\}=0.3$，$P\{X=1,Y=0\}=0.2$，$P\{X=1,Y=1\}=0.4$，判断 $X,Y$ 是否独立。

解：$p_{0\cdot}=0.4,\ p_{\cdot 0}=0.3$，$p_{00}=0.1\neq 0.4\times 0.3=0.12$，故不独立。

9、常见混淆点辨析

  • 联合分布唯一确定边缘分布，反之不然：相同的边缘分布可以对应不同的联合分布（相关性信息丢失）。
  • 不相关 vs 独立：独立一定不相关；不相关一般推不出独立，但二维正态是例外（$\rho=0\iff$ 独立）。
  • 条件密度 $f_{X\mid Y}(x\mid y)$ 是把 $y$ 固定后 $x$ 的一维密度，分母 $f_Y(y)$ 必须大于 $0$。
  • 用卷积公式时积分区间由 $f_X(x)>0$ 与 $f_Y(z-x)>0$ 同时确定，不画区间图极易写错上下限。

10、本章小结

  • 二维问题的三件套：联合、边缘、条件，满足 $f(x,y)=f_Y(y)f_{X\mid Y}(x\mid y)$；
  • 独立性：联合 = 边缘之积（且区域可分离）；
  • $Z=g(X,Y)$ 的分布首选分布函数法，$Z=X+Y$ 有卷积公式，最值有 $F_{\max}=F^n$、$F_{\min}=1-(1-F)^n$；
  • 二维正态的线性变换仍为正态，$\rho$ 同时是相关系数。

11、补充例题

例5 设 $X,Y$ 相互独立且同服从 $U(0,1)$，求 $E|X-Y|$.

解：$E|X-Y|=\displaystyle\int_{0}^{1}!!\int_{0}^{1}|x-y|\,\mathrm{d}x\mathrm{d}y=2\int_{0}^{1}\mathrm{d}y\int_{0}^{y}(y-x)\,\mathrm{d}x=2\int_{0}^{1}\frac{y^{2}}{2}\mathrm{d}y=\frac{1}{3}$.

【注】利用对称性只算 $x<y$ 那一半再乘 2，是二维期望计算的常用简化。

例6 设 $(X,Y)$ 的联合密度 $f(x,y)=\begin{cases}e^{-y},&0<x<y\\0,&\text{其他}\end{cases}$，求边缘密度并判断 $X$ 与 $Y$ 是否独立.

解：$f_{X}(x)=\displaystyle\int_{x}^{+\infty}e^{-y}\mathrm{d}y=e^{-x}\ (x>0)$；$f_{Y}(y)=\displaystyle\int_{0}^{y}e^{-y}\mathrm{d}x=ye^{-y}\ (y>0)$。因 $f(x,y)\neq f_{X}(x)f_{Y}(y)$，故 $X$ 与 $Y$ 不独立。

【注】边缘密度非零的范围依赖于另一变量（$y>x$），这本身就是不独立的信号。

例7 设 $X$ 与 $Y$ 相互独立，$X\sim N(0,1)$，$Y$ 只取 $\pm1$ 且概率各为 $\frac{1}{2}$，证明 $Z=XY\sim N(0,1)$.

证：由全概率公式，

$$F_{Z}(z)=P\{Y=1\}P\{X\leq z\}+P\{Y=-1\}P\{X\geq -z\}=\frac{1}{2}\Phi(z)+\frac{1}{2}\Phi(z)=\Phi(z),$$

故 $Z\sim N(0,1)$.

【注】此例用了标准正态的对称性 $P\{X\geq -z\}=\Phi(z)$；但需注意 $(X,Z)$ 的联合分布不再是二维正态。

练习题

  1. 设 $(X,Y)$ 在 $D:x^2+y^2\leq 1$ 上均匀分布，求 $f_X(x)$ 并判断独立性。（提示：$f_X(x)=\frac{2}{\pi}\sqrt{1-x^2}$，区域非矩形，不独立。）
  2. 设 $X,Y$ 独立，$X\sim N(1,4)$，$Y\sim N(2,1)$，求 $2X-Y$ 的分布。（提示：独立正态线性组合仍正态，$2X-Y\sim N(0,17)$。）
  3. 设 $X,Y$ 独立同分布，$P\{X=1\}=p$，$P\{X=0\}=1-p$，求 $Z=\min\{X,Y\}$ 的分布律。（提示：$Z\sim B(1,p^2)$。）

第二章：随机变量及其分布

1、分布函数的性质

（1）非负性：$0 \leqslant F(x) \leqslant 1$.

（2）规范性：$F(-\infty) = 0, \ F(+\infty) = 1$.

（3）单调不减性：对任意 $x_1 < x_2$，有 $F(x_1) \leqslant F(x_2)$.

（4）右连续性：$F(x_0 + 0) = F(x_0)$.

2、密度函数的性质

（1）非负性：$f(x) \geqslant 0 \ (-\infty < x < +\infty)$.

（2）规范性：$\int_{-\infty}^{+\infty} f(x)\,\mathrm{d}x = 1$.

（3）对于任意实数 $a$ 和 $b\ (a < b)$，有 $P\{a < X \leqslant b\} = \int_a^b f(x)\,\mathrm{d}x$.

（4）对于连续型随机变量 $X$，有 $P\{X = x\} = 0$，对 $\forall x \in R$ 成立.

（5）连续型随机变量的分布函数 $F(x)$ 是连续函数.

（6）在 $f(x)$ 的连续点处，有 $F’(x) = f(x)$.

3、常用分布（离散型）

1）0-1 分布 $X \sim B(1, p)$

$$P(X = k) = p^k (1 - p)^{1 - k}, \quad (k = 0, 1),$$

$$EX = p, \quad DX = p(1 - p).$$

2）二项分布 $X \sim B(n, p)$

$$P(X = k) = C_n^k p^k (1 - p)^{n - k}, \quad (k = 0, 1, \cdots, n),$$

$$EX = np, \quad DX = np(1 - p).$$

3）泊松分布 $X \sim P(\lambda) \ (\lambda > 0)$

$$P(X = k) = \frac{\lambda^k}{k!}\,\mathrm{e}^{-\lambda}, \quad (k = 0, 1, 2, \cdots),$$

$$EX = \lambda, \quad DX = \lambda.$$

4）几何分布 $X \sim G(p)$

$$P(X = k) = p(1 - p)^{k - 1}, \quad (0 < p < 1, k = 1, 2, \cdots).$$

$$EX = \frac{1}{p}, \quad DX = \frac{1 - p}{p^2}.$$

5）超几何分布 $X \sim H(N, M, n)$

$$P(X = k) = \frac{C_M^k C_{N - M}^{n - k}}{C_N^n}, \quad (k = 0, 1, \cdots, \min\{n, M\}).$$

4、常用分布（连续型）

1）均匀分布 $X \sim U(a, b)$

$$f(x) = \begin{cases} \dfrac{1}{b - a}, & a < x < b, \\ 0, & \text{其他}. \end{cases}$$

$$EX = \frac{a + b}{2}, \quad DX = \frac{(b - a)^2}{12}.$$

2）指数分布 $X \sim E(\lambda) \ (\lambda > 0)$

$$f(x) = \begin{cases} \lambda\,\mathrm{e}^{-\lambda x}, & x > 0, \\ 0, & \text{其他}. \end{cases}$$

$$EX = \frac{1}{\lambda}, \quad DX = \frac{1}{\lambda^2}.$$

3）正态分布

① 一般正态分布 $X \sim N(\mu, \sigma^2)$

$$f(x) = \frac{1}{\sqrt{2\pi}\sigma}\,\mathrm{e}^{-\frac{(x - \mu)^2}{2\sigma^2}}, \ (-\infty < x < +\infty, \sigma > 0).$$

$$EX = \mu, \quad DX = \sigma^2.$$

② 标准正态分布 $X \sim N(0, 1)$

$$\varphi(x) = \frac{1}{\sqrt{2\pi}}\,\mathrm{e}^{-\frac{x^2}{2}} \ (-\infty < x < +\infty).$$

性质：$\Phi(-x) = 1 - \Phi(x)$；$\Phi(0) = \dfrac{1}{2}$；$P\{|X| \leqslant a\} = 2\Phi(a) - 1$.

上 $\alpha$ 分位点：

设 $X \sim N(0, 1)$，对于给定的 $\alpha\ (0 < \alpha < 1)$，如果 $u_\alpha$ 满足条件：

$$P\{X > u_\alpha\} = \alpha,$$

则称 $u_\alpha$ 为标准正态分布的上 $\alpha$ 分位点.

③ 标准正态分布与一般正态分布的关系

正态分布 $X \sim N(\mu, \sigma^2)$，通过线性变换 $Z = \dfrac{X - \mu}{\sigma}$ 变为标准正态分布.

5、一维随机变量函数的分布

（1）离散型

问题：若 $P(X = x_i) = p_i$，$Y = g(X)$，求 $Y$ 的分布律.

方法：$P(Y = y_j) = \sum\limits_{g(x_i) = y_j} P(X = x_i).$

（2）连续型

问题：$X \sim f_X(x)$，$Y = g(X)$，求 $Y$ 的分布密度.

方法：分布函数法

$$F_Y(y) = P\{Y \leqslant y\} = P\{g(X) \leqslant y\} = \int_{g(x) \leqslant y} f_X(x)\,\mathrm{d}x,$$

$$f_Y(y) = F_Y’(y).$$

6、常用分布的实际应用场景

  • 0-1 分布：单次伯努利试验（抛一次硬币、一次抽检是否合格）；
  • 二项分布 $B(n,p)$：$n$ 次独立重复试验中成功次数，如质检抽样、投篮命中数；当 $n$ 大、$p$ 小、$np$ 适中时可用泊松分布近似；
  • 泊松分布 $P(\lambda)$：稀有事件的计数，如单位时间内呼叫中心来电数、放射性粒子数、网页访问量，$\lambda$ 是平均发生率；
  • 几何分布 $G(p)$：首次成功所需的试验次数，具有无记忆性：$P\{X>m+n\mid X>m\}=P\{X>n\}$；
  • 超几何分布：不放回抽样（如产品抽检不放回），当 $N$ 很大时近似二项分布；
  • 均匀分布：舍入误差、随机数生成的原型；
  • 指数分布 $E(\lambda)$：寿命、等待时间建模，同样具有无记忆性 $P\{X>s+t\mid X>s\}=P\{X>t\}$；
  • 正态分布：由中心极限定理，大量独立微小因素叠加的结果（身高、测量误差），是统计推断的基石。

7、典型例题

例1 设随机变量 $X$ 的密度函数为 $f(x)=\begin{cases}kx(2-x), & 0<x<2,\\ 0, & \text{其他}.\end{cases}$ 求 $k$ 与 $P\{X>1\}$.

解：由规范性 $\int_0^2 kx(2-x)\,\mathrm{d}x=k\left[x^2-\dfrac{x^3}{3}\right]_0^2=\dfrac{4k}{3}=1$，得 $k=\dfrac{3}{4}$；

$$P\{X>1\}=\frac{3}{4}\int_1^2(2x-x^2)\,\mathrm{d}x=\frac{3}{4}\left[x^2-\frac{x^3}{3}\right]_1^2=\frac{1}{2}.$$

例2 设 $X\sim N(2,9)$，求 $P\{X>5\}$（用 $\Phi$ 表示）。

解：标准化 $Z=\dfrac{X-2}{3}\sim N(0,1)$：

$$P\{X>5\}=P\left\{Z>\frac{5-2}{3}\right\}=1-\Phi(1).$$

例3 设 $X\sim U(0,2)$，$Y=X^2$，求 $Y$ 的密度函数。

解（分布函数法）：当 $0<y<4$ 时，

$$F_Y(y)=P\{X^2\leq y\}=P\{0\leq X\leq\sqrt{y}\}=\frac{\sqrt{y}}{2},$$

求导得 $f_Y(y)=\dfrac{1}{4\sqrt{y}}\ (0<y<4)$，其余为 $0$。

例4 某路口每分钟通过的车辆数 $X\sim P(3)$，求一分钟内至少有 2 辆车通过的概率。

解：$P\{X\geq 2\}=1-P\{X=0\}-P\{X=1\}=1-\mathrm{e}^{-3}-3\mathrm{e}^{-3}=1-4\mathrm{e}^{-3}$.

8、常见混淆点辨析

  • 分布函数 vs 密度函数：$F(x)$ 是累积概率（无量纲、取值 $[0,1]$、右连续），$f(x)$ 是”概率密度”（可大于 1、在某点的值不是概率）。连续型随机变量取单点概率恒为 $0$。
  • $P\{a<X<b\}$ 与 $P\{a\leq X\leq b\}$：对连续型二者相等；对离散型端点处概率可能为正，必须区分。
  • 几何分布的两种定义：”首次成功所需次数”（取值 $1,2,\cdots$，$EX=\frac{1}{p}$）与”首次成功前失败次数”（取值 $0,1,\cdots$），不同教材口径不同，注意辨认。
  • 指数分布参数：$\lambda$ 是”率”，$EX=\frac{1}{\lambda}$；有的书记作 $E(\theta)$ 且 $EX=\theta$（尺度参数），看题先确认参数化方式。

9、本章小结

  • 分布函数四性质（非负、规范、单调不减、右连续）是判一个函数能否作 $F(x)$ 的充要条件；
  • 离散型抓分布律（归一：$\sum p_i=1$），连续型抓密度（归一：$\int f=1$）；
  • 正态分布计算一律标准化 $Z=\frac{X-\mu}{\sigma}$；
  • 求 $Y=g(X)$ 的分布，通用方法是分布函数法，单调情形可用公式法；
  • 记住常用分布的 $EX,DX$，后续数字特征章直接调用。

练习题

  2. 设 $X\sim E(\lambda)$，证明无记忆性 $P\{X>s+t\mid X>s\}=P\{X>t\}$。（提示：$P\{X>x\}=\mathrm{e}^{-\lambda x}$，代入条件概率定义。）
  3. 设 $X\sim N(0,1)$，$Y=2X+1$，求 $Y$ 的分布。（提示：正态的线性变换仍正态，$Y\sim N(1,4)$。）

第一章：随机事件与概率

1、事件的运算律

交换律：$A \cup B = B \cup A$；$A \cap B = B \cap A$.

结合律：$A \cup (B \cup C) = (A \cup B) \cup C$；$A \cap (B \cap C) = (A \cap B) \cap C$.

分配律：$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$；$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$.

德·摩根律（对偶律）：$\overline{A \cup B} = \bar{A} \cap \bar{B}$，$\overline{A \cap B} = \bar{A} \cup \bar{B}$.

2、概率五大计算公式

（1）加法公式

$$P(A \cup B) = P(A) + P(B) - P(AB),$$

$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(BC) - P(AC) + P(ABC).$$

（2）减法公式

$$P(B - A) = P(B) - P(AB).$$

（3）乘法公式

若 $P(A) > 0$，则 $P(AB) = P(B|A)P(A)$；若 $P(B) > 0$，则 $P(AB) = P(A|B)P(B)$.

若 $P(AB) > 0$，则 $P(ABC) = P(C|AB)P(B|A)P(A) = P(C|AB)P(A|B)P(B)$.

（4）全概率公式

$$P(A) = \sum_{i=1}^{n} P(A|B_i)\,P(B_i),$$

其中 $B_i B_j = \varnothing\ (i \neq j)$，$\bigcup\limits_{i=1}^{n} B_i = \Omega$.

（5）贝叶斯公式

$$P(B_j|A) = \frac{P(A|B_j)\,P(B_j)}{\sum\limits_{i=1}^{n} P(A|B_i)\,P(B_i)},$$

其中 $B_i B_j = \varnothing\ (i \neq j)$，$\bigcup\limits_{i=1}^{n} B_i = \Omega$.

【注】上述公式中事件 $B_i$ 的个数可以是可列个.

3、事件的独立性

$A$ 与 $B$ 独立 $\Leftrightarrow P(AB) = P(A)P(B)$.

$A, B, C$ 两两独立 $\Leftrightarrow$

$$\begin{cases} P(AB) = P(A)P(B), \\ P(AC) = P(A)P(C), \\ P(BC) = P(B)P(C). \end{cases}$$

$A, B, C$ 相互独立 $\Leftrightarrow$

$$\begin{cases} P(AB) = P(A)P(B), \\ P(BC) = P(B)P(C), \\ P(AC) = P(A)P(C), \\ P(ABC) = P(A)P(B)P(C). \end{cases}$$

4、独立的性质与结论

（1）若事件 $A, B$ 相互独立，则 $A$ 与 $\bar{B}$，$\bar{A}$ 与 $B$，$\bar{A}$ 与 $\bar{B}$ 也相互独立.

（2）独立的等价说法：若 $0 < P(A) < 1$，则

事件 $A, B$ 独立

$$\Leftrightarrow P(AB) = P(A)P(B) \Leftrightarrow P(B) = P(B|A) \Leftrightarrow P(B) = P(B|\bar{A}) \Leftrightarrow P(B|A) = P(B|\bar{A}).$$

（3）若 $A_1, A_2, \cdots, A_m, B_1, B_2, \cdots, B_n$ 相互独立，则 $f(A_1, A_2, \cdots, A_m)$ 与 $g(B_1, B_2, \cdots, B_n)$ 也相互独立，其中 $f(\cdot), g(\cdot)$ 分别表示对相应事件作任意事件运算.

（4）若 $P(A) = 0$ 或 $P(A) = 1$，则 $A$ 与任何事件 $B$ 都相互独立.

5、独立、互斥、互逆的关系

（1）$A$ 与 $B$ 互逆 $\Rightarrow A$ 与 $B$ 互斥，但反之不一定成立；

（2）$A$ 与 $B$ 互斥（或互逆）且均为非零概率事件 $\Rightarrow A$ 与 $B$ 不独立；

（3）$A$ 与 $B$ 相互独立且均为非零概率事件 $\Rightarrow A$ 与 $B$ 不互斥.

【注】一般情况下，独立和互斥无关，独立推不出互斥、互斥也推不出独立.

6、利用最值关系求概率

① $\{\max(X, Y) \leqslant a\} = \{X \leqslant a\} \cap \{Y \leqslant a\}$

② $\{\max(X, Y) > a\} = \{X > a\} \cup \{Y > a\}$

③ $\{\min(X, Y) \leqslant a\} = \{X \leqslant a\} \cup \{Y \leqslant a\}$

④ $\{\min(X, Y) > a\} = \{X > a\} \cap \{Y > a\}$

⑤ $\{\max(X, Y) \leqslant a\} \subseteq \{\min(X, Y) \leqslant a\}$

⑥ $\{\min(X, Y) > a\} \subseteq \{\max(X, Y) > a\}$

7、全概率与贝叶斯的直觉理解

  • 全概率公式是”分情况求和”：把导致结果 $A$ 的原因 $B_1,\cdots,B_n$ 切成互斥完备的几类，$P(A)=\sum P(B_i)P(A|B_i)$，即”每条路径的概率 × 该路径上 $A$ 发生的概率”之和。画树状图最直观。
  • 贝叶斯公式是”由果溯因”：已知结果 $A$ 发生了，反推它是由第 $j$ 种原因导致的概率。先验概率 $P(B_j)$ 经过证据 $A$ 的”修正”得到后验概率 $P(B_j|A)$——这正是机器学习朴素贝叶斯分类器的思想。

8、贝叶斯应用案例

（1）医学检测的阳性悖论

设某病患病率为 $0.1%$（$P(B)=0.001$），检测的灵敏度 $P(A|B)=99%$，特异度 $P(\bar{A}|\bar{B})=99%$。若某人检测呈阳性（$A$），其真患病的后验概率为

$$P(B|A)=\frac{0.99\times 0.001}{0.99\times 0.001+0.01\times 0.999}\approx 9%.$$

直觉：健康人基数太大，假阳性（约 1% 的 99.9%）远多于真阳性，故一次阳性远不足以确诊——这就是”先验概率不可忽略”的经典案例。

（2）垃圾邮件过滤

设 $B$=”邮件是垃圾邮件”，$A$=”邮件含’发票’字样”。由历史数据估计 $P(B)$（先验）、$P(A|B)$ 与 $P(A|\bar{B})$（似然），收到新邮件时用贝叶斯公式算后验概率 $P(B|A)$，超过阈值则判为垃圾邮件。实际系统对大量词特征假设条件独立（”朴素”假设），把各词的后验概率相乘合并。

9、典型例题

例1 袋中有 3 红 2 白 5 个球，不放回取两次，求第二次取到红球的概率。

解：设 $B_1$=”第一次取红”，$B_2$=”第一次取白”，$A$=”第二次取红”。由全概率公式：

$$P(A)=\frac{3}{5}\cdot\frac{2}{4}+\frac{2}{5}\cdot\frac{3}{4}=\frac{6+6}{20}=\frac{3}{5}.$$

这说明”抽签公平性”：不放回抽样中每个人抽中的概率相同。

例2 两台机床加工同种零件，甲占 60% 产量、次品率 1%；乙占 40%、次品率 5%。任取一件是次品，求它由甲生产的概率。

解：设 $B_1$=”甲产”，$B_2$=”乙产”，$A$=”次品”。贝叶斯公式：

$$P(B_1|A)=\frac{0.6\times 0.01}{0.6\times 0.01+0.4\times 0.05}=\frac{0.006}{0.026}=\frac{3}{13}.$$

例3 设 $P(A)=0.5,\ P(B)=0.4,\ P(A\cup B)=0.7$，判断 $A,B$ 是否独立。

解：$P(AB)=P(A)+P(B)-P(A\cup B)=0.5+0.4-0.7=0.2=P(A)P(B)$，故独立。

10、常见混淆点辨析

  • 互斥 vs 独立：互斥是”不能同时发生”（集合关系），独立是”互不影响”（概率关系）。非零概率的两事件互斥则必不独立——因为 $P(AB)=0\neq P(A)P(B)$。
  • 条件概率 $P(A|B)$ vs 积事件 $P(AB)$：$P(A|B)$ 的样本空间已缩到 $B$，满足 $P(B|B)=1$；$P(AB)$ 仍在全样本空间 $\Omega$ 中度量。
  • 两两独立 vs 相互独立：三事件相互独立要求额外满足 $P(ABC)=P(A)P(B)P(C)$，两两独立推不出相互独立。
  • $\bar{A}\bar{B}$ 与 $\overline{AB}$：前者是”都不发生”，后者是”不同时发生”，由德摩根律 $\overline{AB}=\bar{A}\cup\bar{B}$，极易混用。

11、本章小结

  • 事件运算的核心工具是德摩根律：”并的补 = 补的交，交的补 = 补的并”；
  • 五大公式中全概率 + 贝叶斯是应用主力：”分阶段用全概率，求原因用贝叶斯”；
  • 独立性用 $P(AB)=P(A)P(B)$ 判定，勿与互斥混淆；
  • 最值事件转化：$\max\leq a$ 取交、$\min\leq a$ 取并。
