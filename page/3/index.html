第7章 微分几何深度指南

微分几何只做一件事：用微积分研究弯曲的空间。

普通几何学（欧几里得那一套）研究的是平直世界里的直线、圆、三角形；而现实世界充满了弯曲——地球是球面、卫星轨道是空间曲线、广义相对论里时空本身就是弯的。微分几何的核心思想是：把弯曲的对象局部线性化（切线、切平面、切空间），用导数刻画”弯曲的程度”，再把这些局部信息拼回整体。

全篇最重要的一个概念是曲率（curvature）。它的直观定义只有一句话：

曲率 = 局部偏离平直的程度。

  • 直线处处不偏离直线 → 曲率为 0；
  • 圆处处均匀偏离 → 曲率为常数，半径越小弯得越狠，曲率越大；
  • 球面向各个方向都弯 → 高斯曲率为正；
  • 马鞍面一个方向向上弯、另一个方向向下弯 → 高斯曲率为负。

工程师为什么要学它？因为机器学习里的”流形学习”、图形学里的”网格平滑”、机器人里的”姿态插值”、深度学习里的”自然梯度”，骨子里全是微分几何。数据往往落在高维空间的一个低维弯曲子流形上，不理解曲率，就理解不了这些算法在做什么。

本篇对应 Bronstein 数学手册第 3 章几何学的微分几何部分，按”曲线 → 曲面 → 内蕴几何 → 流形”的顺序展开，所有公式用 Unicode 书写，所有代码用 SymPy 可直接运行。

1.2 正则曲线（regular curve）

定义：若 r’(t) 处处连续且 r’(t) ≠ 0，称曲线是正则的。

为什么要求 r’ ≠ 0？因为 r’(t₀) = 0 的点，切向量退化，曲线在该点可能出现尖点（cusp）或停顿，微积分工具失效。几何上好的曲线必须先排除这类病态点。正则性保证每一点都有唯一确定的单位切向量。

第二条的直觉：τ = 0 意味着 B 恒定（B’ = 0），密切平面不动，曲线始终躺在同一个平面里。所以挠率是”偏离平面程度”的度量，正如曲率是”偏离直线程度”的度量。

2.4 曲线论基本定理（一句话）

给定光滑函数 κ(s) > 0 与 τ(s)，在空间中存在曲线以它们为曲率与挠率；且在刚体运动（平移+旋转）意义下，这条曲线唯一。

即：κ 和 τ 唯一决定一条曲线——它们是空间曲线的”完整不变量”，相当于曲线的 DNA。两个参数、一个存在性、一个唯一性，这是整个曲线论最漂亮的结果。

Gauss 曲率 K 只依赖于第一基本形式（E, F, G 及其导数），与曲面如何嵌入三维空间无关。

七、流形初步（点到为止）

7.1 n 维流形

n 维流形（manifold）：一个局部看起来像 ℝⁿ 的空间。精确地说，每一点都有一个邻域，可以通过坐标卡（chart） 与 ℝⁿ 的开集建立双射（同胚）；一族覆盖整个空间的坐标卡叫图册（atlas），坐标卡之间重叠区域的转换函数要求光滑（微分同胚）。

地球表面是最贴切的例子：地球整体是球面（不是平面），但每座城市的地图都是平的——一张张平面地图合起来就是图册。流形 = “由局部平坦的地图拼接而成的整体弯曲空间”。

7.2 切空间

流形上每一点 P 处可以定义切空间 T_P M：该点所有切向量构成的 n 维线性空间——它是流形在该点的最佳线性逼近，是把微积分搬到弯曲空间上的舞台。曲线论中的 T、曲面论中的切平面，都是切空间的低维特例。

7.3 黎曼度量与张量

黎曼度量 g：在每个切空间上光滑地指定一个内积：

有了 g 就能度量切向量的长度与夹角，从而度量流形上曲线的长度、区域体积、定义测地线、定义曲率（Riemann 曲率张量、Ricci 曲率、标量曲率）。曲面论中的第一基本形式 I 就是黎曼度量在 2 维情形的化身：g = E du² + 2F du dv + G dv²。

张量（一句话）：张量是定义在切空间上的多线性函数——它吃进去若干个向量/余向量，吐出一个数，且与坐标选取无关。度量张量 g、曲率张量、应力张量、惯性张量，都是这个统一框架的实例。”坐标会变，张量不变”，这正是物理学定律需要的语言。

动力系统（Dynamical Systems）研究的是「状态随时间演化的规则」：给一条演化法则（微分方程或迭代映射），问的不是「某一步等于几」，而是「长期行为长什么样」——收敛到不动点？绕周期轨转圈？还是永不重复地游荡？这门学科最震撼的发现是：完全确定的方程可以产生本质上不可长期预测的行为。混沌（Chaos）不是随机噪声——系统每一时刻都由上一时刻唯一决定——而是「对初值的敏感依赖」：初始差一个 1e-15 的舍入误差，几十步之后两条轨道天差地别。天气预报两周失效、双摆不可复现、Logistic 种群数在 r > 3.57 后看似乱跳，全是同一个机制。本指南以工程师视角组织 Bronstein 手册第17章的主线：连续流与离散映射 → 不动点与线性化稳定性 → 三种基本分岔 → 极限环与 Hopf 分岔 → Logistic 映射倍周期之路与 Feigenbaum 普适常数 → Lyapunov 指数 → Lorenz 奇异吸引子，最后给出分岔图、Lyapunov 指数、Lorenz 吸引子的完整可运行 Python 代码，并把每个概念翻译成 ML/工程语言。

泛函分析（Functional Analysis）的核心思想只有一句话：把”函数”当作空间中的一个”点”。一个 n 维向量 x = (x₁, …, xₙ) 是 n 个数；一个函数 f: [a,b] → ℝ 可以看成”无穷多个坐标”——每个自变量 x 处都有一个分量 f(x)。一旦接受这个视角，有限维线性代数里熟悉的一切——长度、夹角、正交、投影、基、特征值——都可以在无穷维的”函数空间”里重新定义，而泛函分析就是研究这套推广何时成立、如何成立、以及成立的代价是什么的学科。它是有限维线性代数在无穷维的推广，也是从”会算”走向”会证”的分水岭：微分方程解的存在唯一性、Fourier 级数为什么收敛、量子力学为什么用算子描述可观测量、核方法为什么合法，答案全部藏在本文的定理里。

主线：度量空间（距离与完备）→ 赋范空间（长度）→ 内积空间（角度与正交）→ Hilbert 空间（完备的内积空间，无穷维里”最像 ℝⁿ”的空间）→ 线性算子与泛函 → Riesz 表示 → 谱理论 → 应用（PDE 弱解 / 量子力学 / RKHS 核方法）。案头参照 Bronstein《数学手册》第 12 章。

工程师视角的一句话：线性代数告诉你”对称矩阵可正交对角化、最小二乘就是投影”；泛函分析告诉你这两件事在无穷维依然成立——只要空间完备（Hilbert）、算子性质足够好（有界/紧/自伴）。核方法、谱聚类、最小二乘、值迭代收敛，全是这套定理的推论。

积分变换的共同思想只有一句话：选一个核函数 K(t, u)，把函数 f(t) 投影到另一组基上，让在时域难做的运算（求导、卷积、解微分方程）在新坐标系里变成简单运算（乘法、查表、代数移项）。对 Laplace 核是 e^{-st}，对 Fourier 核是 e^{-iωt}，对离散序列核是 z^{-n}。

最值钱的一个事实：指数函数是求导运算的特征函数。

所以一旦把任意函数拆成指数函数的叠加（投影到指数基），求导就整体变成了乘法——这就是 Laplace 与 Fourier 全部威力的来源。本指南按工程师的使用顺序讲：Laplace 解微分方程与控制系统 → Fourier 级数与变换做频谱 → 采样、DFT/FFT 落地到代码 → z 变换统治离散世界，最后给出三大变换对比、Python 实战与 ML/工程对照表。

1.1 定义与收敛域

第14章 数值分析深度指南

数学课本给你闭式解（closed-form solution）：x = (−b ± √(b²−4ac)) / 2a、e^{At} y₀、∫ sin x dx = −cos x。工程现实给你的是：一个十次多项式方程没有求根公式、一个百万阶稀疏矩阵求不了逆、一条只有采样点没有表达式的传感器曲线、一个无法解析积分的被积函数。数值分析（Numerical Analysis）就是回答一个问题：当解析解不存在或算不起时，怎样用有限的浮点运算逼近真解，并且知道逼近得有多好。

本指南对应 Bronstein 数学手册第 19 章的工程师视角展开：误差与浮点、非线性方程求根、线性方程组的直接与迭代解法、特征值算法、插值与逼近、数值微分、数值积分、ODE 初值问题数值解。一切数值方法都围绕同一条主线——误差从哪来、怎么控制：模型误差、截断误差、舍入误差，分别对应「问题选得对不对、公式逼近得好不好、计算机算得准不准」。每节配可运行的 Python / NumPy / SciPy 代码，最后给出 ML / 工程对照表与验收清单。
