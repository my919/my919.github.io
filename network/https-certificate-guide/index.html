1. 概念说明：HTTPS 与 TLS

HTTPS = HTTP + TLS，不是新协议——先经 TLS 加密、再传输 HTTP 报文。URL 以 https:// 开头，默认端口 443（明文 HTTP 为 80）。

TLS 提供三件事：

能力 说明
机密性 对称加密载荷，防窃听
完整性 MAC / AEAD 防篡改
身份认证 X.509 证书链证明「服务器是它声称的那个」

不解决什么：TLS 不能替代应用层鉴权与输入校验，https:// 不等于站点没有 XSS/CSRF 等业务漏洞。

握手定密钥，传输用对称：TLS 握手协商出对称会话密钥，之后 HTTP 记录用对称算法加密以获得性能。

2. TLS 握手原理

2.1 简化握手

2.2 TLS 1.2 vs 1.3

维度 TLS 1.2 TLS 1.3
握手往返 2-RTT 1-RTT（0-RTT 可选）
密钥交换 RSA / ECDHE 等可选 仅 (EC)DHE，强制前向保密
对称算法 CBC、RC4 等遗留并存 仅 AEAD（AES-GCM、ChaCha20-Poly1305）
握手加密 证书等明文传输 ServerHello 之后大部分加密
重协商 支持 移除

TLS 1.3 完整握手：

key_share 在首个 ClientHello 就带上客户端的 (EC)DHE 公钥，省掉 TLS 1.2 里单独的 ServerKeyExchange 往返，这是 1-RTT 的关键。

0-RTT 风险：有重放风险，敏感操作应禁用或二次校验。

3. 证书链与主机名校验

浏览器/客户端会校验：

  1. 证书是否由受信任 CA 签发，链是否完整
  2. SAN（Subject Alternative Name） 是否覆盖当前访问主机名
  3. 有效期、吊销信息（OCSP Stapling 等）

证书关键字段（openssl x509 -text 可见）：

字段 含义
Subject / Issuer 持有者 / 签发者 DN
SAN 覆盖的域名列表（现代客户端以此为准）
Not Before / After 有效期
Subject Public Key Info 公钥算法与位长（RSA-2048、ECDSA P-256 等）
Authority Key Identifier 指向上级 CA，用于组链

自签名证书仅适合内网或开发，公网须使用可信 CA 或组织内 PKI。

4. ALPN

在 TLS 握手中通过 ALPN 协商应用层协议：h2 表示后续走 HTTP/2 帧；h3 与 QUIC/HTTP/3 相关（QUIC 内含 TLS 1.3 集成握手）。

5. 证书类型对比

类型 验证程度 价格 适用
DV 验证域名所有权 免费（Let’s Encrypt） 绝大多数场景
OV 验证企业身份 数百元/年 企业官网
EV 深度验证+地址栏企业名 数千元/年 金融等高信任场景

10. 常见故障排查

报错（curl / openssl） 常见原因 解决
certificate has expired 证书过期；续期后未重载服务 续期 + reload
unable to get local issuer certificate 服务端漏配中间证书 用 fullchain.pem
hostname mismatch SAN 不含访问域名；SNI 未携带 重新申请带正确域名
self signed certificate 自签名证书 换 CA 证书或客户端显式信任
wrong version number 对端端口是明文 HTTP 检查端口与协议
续期失败 http-01 验证不过 80 端口被占用/被墙 用 dns-01 验证（acme.sh）
后端回调拿不到 https 没传 X-Forwarded-Proto 补配置

11. 安全加固清单

  • 仅启用 TLS 1.2+（优先 1.3），禁用 SSLv3 / TLS 1.0 / 1.1
  • 套件只保留 AEAD；开启 OCSP Stapling
  • HSTS：Strict-Transport-Security: max-age=31536000; includeSubDomains
  • 私钥权限 chmod 600、与证书分离存放
  • 自动化续期（ACME / certbot）并监控到期时间
  • 全站 HTTPS：HTTP→HTTPS 301 跳转，杜绝 mixed content

14. 常见误用与陷阱

坑 现象/后果 解法
Nginx 只配 cert.pem 不配 fullchain.pem 桌面能开，手机/小程序报证书链不完整 一律用 fullchain.pem
HSTS max-age 一上来就设一年 配置出错想回退 HTTP 也回不去 从 max-age=300 起步，稳定后再加长
续期 cron 静默失败 证书过期全站告警才发现 去掉 --quiet，失败接告警
私钥权限 644 任意本机用户可读私钥 chmod 600 privkey.pem
续期成功但没 reload Nginx 磁盘上新证书，进程里还是旧证书 永远带 --post-hook "systemctl reload nginx"
启用 HTTPS 后混入 http 资源 浏览器拦混合内容 全站资源/接口统一 https
