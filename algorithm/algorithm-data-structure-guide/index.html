1. 概念说明

数据结构是数据在计算机中的组织方式，算法是解决问题的步骤集合。二者的核心评价指标是时间复杂度（随输入规模 n 增大，操作次数增长量级，用大 O 表示）和空间复杂度（额外内存用量）。

4. 复杂度分析速查

复杂度 典型算法
O(1) 数组随机访问、哈希查找
O(log n) 二分查找、平衡树操作
O(n) 线性遍历、多数排序
O(n log n) 归并排序、快速排序、堆排序
O(n²) 冒泡/选择/插入排序、双重循环
O(2ⁿ) 递归枚举、暴力组合

4.1 怎么推导复杂度（方法论）

  • 顺序结构：取最大项，常数系数忽略（O(n) + O(n) = O(n)）
  • 嵌套循环：内外相乘，但内层范围受外层影响时要细算（如冒泡是 1+2+…+n ≈ n²/2）
  • 递归：用主定理或递归树估算。二分 T(n)=T(n/2)+O(1)=O(log n)；归并 T(n)=2T(n/2)+O(n)=O(n log n)
  • 均摊分析：动态数组 append 偶尔扩容是 O(n)，但分摊到每次操作是 O(1)（哈希表、栈的批量弹出同理）

常见误区：把「循环次数」当复杂度。实际是「基本操作执行次数随 n 的增长量级」。两层 for i in range(n) 是 O(n²)，但内层 range(i) 时仍是 O(n²)；内层恒为常数时（如固定窗口 k）是 O(n)。

7. 动态规划进阶（背包/LIS/编辑距离）

DP 三板斧：定义状态 → 写转移方程 → 确定边界。以下三个经典题覆盖最常见的 DP 形态。

7.1 0-1 背包（容量约束下的最优选择）

n 个物品各有重量和价值，背包容量 W，每个物品选或不选，求最大价值。滚动数组把 O(nW) 空间降到 O(W)。

创建 src/algo/knapsack.py：

关键细节：cap 必须倒序遍历。正序会用本物品更新后的值再更新更大的容量，导致同一物品被重复选择（变成完全背包）。

7.2 最长递增子序列（LIS，LeetCode 300）

dp[i] 表示以 nums[i] 结尾的最长递增子序列长度。转移：往前找比 nums[i] 小的所有 j，取最大 dp[j]+1。
