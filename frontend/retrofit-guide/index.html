7. 最佳实践

项 做法
实例 Retrofit / OkHttpClient 全应用单例；每 new 一个客户端就多一个连接池和线程池
baseUrl 以 / 结尾；接口相对路径不要以 / 开头，否则会覆盖 base 的路径部分
调用方式 优先 suspend；Java 项目用 enqueue，不要在主线程 execute
日志 HttpLoggingInterceptor 只在 debug 开 BODY，线上关闭（会打印敏感数据）
错误 统一封装为 ApiResult，UI 层只处理三种分支
鉴权 公共头走拦截器；401 刷新走 Authenticator
模型 DTO（网络层）与领域模型分离，避免后端字段变更污染业务代码
超时 连接 10s、读取 30s 起步，按接口特性单独配
