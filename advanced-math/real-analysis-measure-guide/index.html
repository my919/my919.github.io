第19章：实分析与测度论初步

第19章：实分析与测度论初步

微积分告诉你”怎么算”——求导用链式法则，积分找原函数，级数套判别法。实分析追问的是”凭什么这么算”：极限为什么存在？连续函数为什么有最值？极限号和积分号什么时候能交换？”无穷小”到底是不是一个数？这些问题在 19 世纪把数学搅了个天翻地覆：Weierstrass 给出了处处连续但处处不可微的函数，Dirichlet 给出了 Riemann 积分处理不了的函数，Cantor 干脆造出了一个”长度为 0 却不可数”的怪物。实分析（Real Analysis）就是这场危机的产物——它用 ε-δ 语言、完备性公理和测度论，把极限、连续、积分重新打了一遍地基。对工程师而言，这门课的直接回报是：概率论的公理化（Kolmogorov 把概率定义为测度、期望定义为 Lebesgue 积分）与泛函分析（Lᵖ 空间的完备性）都以它为起点；没有这层地基，”随机变量的收敛””期望里换极限”这些日常操作都是空中楼阁。本文定位”初步”：追求直觉与地图感，不做证明大全，但每个定理都说清楚”它在防什么坑”。

主线：实数系完备性（地基的地基）→ 点集拓扑（开闭紧）→ 极限与连续严格化 → 函数列收敛（一致 vs 逐点）→ Riemann 积分的局限 → 测度论 → Lebesgue 积分与三大收敛定理 → Lᵖ 空间 → 衔接概率论与泛函分析。

0. 学习地图

工程师视角的一句话：实分析就是给”取极限”这件事买保险——单点收敛不够，要一致收敛；竖着切不行，就横着切；只要极限过程受控，换序就合法。你每天在代码里写 np.mean(samples)、在论文里写 E[X]，背后全是这套保险条款。

9. 实分析 → ML/工程对照表

实分析概念 ML / 工程对应 一句话说明
几乎处处（a.e.） 梯度下降的例外点 ReLU 在 0 不可微、BN 边界点——零测集上的坏行为不影响积分与期望
完备性 / Cauchy 列 迭代算法收敛判据 先证参数序列是 Cauchy 列，再用完备性断言极限存在
Lᵖ 范数 损失函数范数 L2 损失 = L² 范数平方，L1 正则 = L¹ 范数，p → ∞ 对应 Chebyshev 误差
控制收敛定理 期望与极限换序 梯度期望 ∇E[L] = E[∇L] 的合法性依据（找得到”可积大伞”才敢换）
单调收敛定理 非负序列的极限 非负奖励的累积期望、递增近似序列的误差极限可换序
测度 概率严格化 连续分布、混合分布、测度变换（重要性采样/RN 导数）的共同语言
σ-代数 信息结构 过滤（filtration）建模”随时间增加的信息”，鞅论的基础
紧性 参数空间有界假设 权重裁剪/投影梯度下降把参数约束在紧集，最值定理保证最优解存在
一致收敛 泛化界 / 函数逼近 VC 理论、Glivenko-Cantelli 类：经验误差一致收敛到真实误差才可学习
零测集 / Cantor 集 数据分布的支撑集 高维数据常集中在低维流形上，Lebesgue 测度为 0 但不可忽略
Fatou 引理 损失下极限估计 lim inf 损失的期望 ≥ 期望的 lim inf——收敛分析里的标准一步
可测函数 随机变量 / 特征映射 模型输出、特征变换必须是可测函数，期望才有定义
