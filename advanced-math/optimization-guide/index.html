第13章：最优化

对应 Bronstein《数学手册》第 18 章主线：优化问题分类 → 无约束最优性条件（∇f=0 与 Hessian）→ 迭代下降算法族（梯度/动量/Newton/BFGS）→ 线性规划（单纯形与顶点原理）→ 对偶理论（弱/强对偶、互补松弛）→ 凸优化与 KKT → 整数规划与动态规划。工程师视角：一切机器学习训练都是带约束（或隐式正则）的最优化，看懂 KKT 与对偶，就看懂了 SVM 与正则化的半部真经。

原问题 ⟷ 对偶问题对应规则（以不等式形为例）：

原问题 (min) 对偶问题 (max)
min cᵀx max bᵀy
第 i 个约束 aᵢᵀx ≥ bᵢ 对偶变量 yᵢ ≥ 0
第 j 个约束 aⱼᵀx = bⱼ 对偶变量 yⱼ 自由
变量 xⱼ ≥ 0 第 j 个对偶约束 Aᵀy 的第 j 行 ≤ cⱼ
变量 xⱼ 自由 第 j 个对偶约束取等号

8. 最优化 → ML/工程对照表

最优化概念 ML/工程对应
min f(x) 目标函数 损失函数最小化（训练即优化）
无约束 ∇f=0 经验风险极小点；深度学习里多为鞍点而非坏局部极小
Hessian / 条件数 κ 损失面曲率、病态峡谷、预条件器设计
梯度下降 + 线搜索 SGD + 学习率调度
Nesterov / 动量 Momentum / NAG 优化器
Newton / BFGS 二阶法、K-FAC、L-BFGS 全批量精调
约束 ⟷ 罚/对偶 正则化：约束 ‖w‖≤t ⟺ 损失 + λ‖w‖（Lagrange 对偶视角）
L1 范数 稀疏化（LASSO）：不可微点在原点，解被”推”到坐标轴上
KKT 条件 SVM 最优性、支持向量稀疏性来源
LP 对偶 / 影子价格 资源定价、敏感性分析、影子成本
强对偶 + 内积形式 核技巧：对偶只含 xᵢᵀxⱼ → 换成 K(xᵢ,xⱼ)
分支定界 / 松弛 组合优化求解器（Gurobi/SCIP）、特征选择的穷搜替代
Bellman 方程 强化学习值迭代/策略迭代、Q-learning
凸 ⟹ 局部=全局 凸损失（logistic/线性回归）无局部极小困扰；深度网络靠过参数化”近似”此性质
