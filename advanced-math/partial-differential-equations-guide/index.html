第9章 偏微分方程深度指南

常微分方程（ODE）只有一个自变量（通常是时间），描述「一个点的命运」；偏微分方程（PDE）有多个自变量（时间 + 空间），描述「一整片场的命运」——温度场、应力场、电磁场、概率密度场。工程师每天打交道的传热仿真、结构 CAE、流体 CFD、图像扩散模型，底层全是 PDE。

PDE 的共同思想只有一句话：未知量是一个多元函数 u(x, t)，方程把 u 对各个自变量的偏导数绑在一起。导数从一元变成多元之后，解不再是「一条曲线」而是「一个曲面/场」，定解也不再只靠几个初值，而要靠边界条件 + 初始条件共同裁剪出唯一解。

本指南对应 Bronstein 数学手册第 9 章 PDE 部分与第 11 章积分方程，按工程师的使用顺序讲：基本概念与适定性 → 二阶方程三分法（椭圆/抛物/双曲）→ 三大典型方程逐个拆 → 特征线法 → 分离变量法完整走一遍 → 积分变换与 Green 函数 → 弱解与有限元的入口 → 积分方程简述 → 有限差分数值求解 → ML/工程对照表 → Python 实战。

2. 二阶线性 PDE 的分类：椭圆 · 抛物 · 双曲

2.1 判别式

2.2 三类方程的物理原型与解的性格对比

性质 椭圆型（Laplace/Poisson） 抛物型（热方程） 双曲型（波动方程）
物理原型 稳态温度场、静电势、不可压无旋流 热传导、扩散、黏性耗散 弦振动、声波、电磁波
时间角色 无时间（稳态/平衡） 单向演化（时间之箭） 双向传播
定解条件 纯边界条件（边值问题） 初值 + 边界（初边值） 两个初值 u、u_t（+边界）
信息传播速度 无穷大（全域瞬时耦合） 无穷大（高斯核处处非零） 有限 = c（特征锥）
正则性 内部解析，边界奇性不外传 瞬时光滑化（t>0 即 C^∞） 奇性沿特征线原样传播
极值原理 强极值原理（最值在边界） 极值原理（最值在初始或边界） 无极值原理
时间可逆性 不涉及 不可逆（倒向热方程不适定） 可逆（t → -t 仍是解）
数值主战场 有限元 / 五点差分 显式/隐式差分（CFL） 差分 + CFL（Δt ≤ Δx/c）

特征线法是一般方法：拟线性方程 a(x,t,u) u_x + b(x,t,u) u_t = c(x,t,u) 的解沿特征曲线 dx/ds = a, dt/ds = b, du/ds = c 逐条构造——把 PDE 化成一族 ODE。

非线性的代价——激波（一句话）：对 u_t + u u_x = 0（Burgers 无黏版），特征线速度依赖 u 本身，快处追上慢处，特征线相交，解出现间断（激波），经典解破裂，必须用弱解 + 熵条件续命。

允许一阶导平方可积的函数构成 Sobolev 空间 H¹，弱解就在其中寻找（Lax-Milgram 定理保证适定性）。有限元方法直接建立在弱形式上：把区域剖成小单元，用分片多项式拼出试探函数与检验函数，弱形式自动导出单元刚度矩阵——这就是为什么 CAE 软件从不要求你去验证解的二阶导。

10. PDE ↔ ML/工程对照表

工程 / ML 场景 对应 PDE 概念 关键联系
图像去噪与高斯平滑 热方程 u_t = αΔu 高斯模糊 = 热方程短时间演化；Perona-Malik 各向异性扩散保边缘
扩散模型（Diffusion Model） 热方程 / Fokker-Planck 前向加噪 = 热扩散，反向去噪 = 学习 score（∇ log p）逆转 SDE/PDE
结构强度与振动仿真（CAE） 椭圆型 + 特征值问题 有限元求位移场 u（Laplace 类），模态分析 = 特征值问题 λₙ ↔ 固有频率
流体仿真（CFD） Navier-Stokes（非线性抛物） 动量方程 = 对流项 + 扩散项 + 压力项，不可压约束 ⇔ 压力 Poisson 方程
电磁波与天线仿真 波动方程 / Maxwell u_tt = c²Δu 的矢量版，FDTD 是显式差分 + CFL 的直接实现
声学仿真与房间混响 波动方程 d’Alembert 依赖区间 ↔ 声音到达时间；特征线 ↔ 声线追踪
图像分割 / 水平集 双曲型守恒律 + 曲率流 水平集方程 φ_t + F
Black-Scholes 期权定价 倒向抛物型 经变量代换化为热方程求解，终点条件 = 到期收益（倒向时间）
PINN 物理信息神经网络 三类 PDE 通吃 网络输出 u_θ(x,t)，自动微分算 PDE 残差加入损失，无需网格
图神经网络消息传递 离散热方程 邻居聚合 = 图 Laplacian 扩散，过平滑现象 ≡ 热方程抹平初值
电池/半导体电热仿真 热方程 + Poisson 耦合 温度场（抛物）与电势场（椭圆）耦合，多物理场仿真的标准配置
反问题（CT、地层反演） Fredholm 第一类积分方程 病态 + 不适定 ⇒ Tikhonov 正则化，Hadamard 第三条的直接应用
