第12章：动力系统与混沌

动力系统（Dynamical Systems）研究的是「状态随时间演化的规则」：给一条演化法则（微分方程或迭代映射），问的不是「某一步等于几」，而是「长期行为长什么样」——收敛到不动点？绕周期轨转圈？还是永不重复地游荡？这门学科最震撼的发现是：完全确定的方程可以产生本质上不可长期预测的行为。混沌（Chaos）不是随机噪声——系统每一时刻都由上一时刻唯一决定——而是「对初值的敏感依赖」：初始差一个 1e-15 的舍入误差，几十步之后两条轨道天差地别。天气预报两周失效、双摆不可复现、Logistic 种群数在 r > 3.57 后看似乱跳，全是同一个机制。本指南以工程师视角组织 Bronstein 手册第17章的主线：连续流与离散映射 → 不动点与线性化稳定性 → 三种基本分岔 → 极限环与 Hopf 分岔 → Logistic 映射倍周期之路与 Feigenbaum 普适常数 → Lyapunov 指数 → Lorenz 奇异吸引子，最后给出分岔图、Lyapunov 指数、Lorenz 吸引子的完整可运行 Python 代码，并把每个概念翻译成 ML/工程语言。

2. 一维系统与三种基本分岔

分岔（bifurcation）：当参数 μ 连续变化经过某个临界值 μ_c 时，系统的定性行为突变——不动点突然诞生/消失、稳定性互换、周期轨冒出来。分岔图（横轴参数、纵轴稳态）是观察分岔的标准工具。

三种分岔一张表（连续一维，离散情形把判据换成 |f’(x*)| 与 1 比较即可）：

分岔 标准形 临界现象 工程画面
鞍结 ẋ = μ + x² 一对不动点成对生灭 突跳、跳闸、电压崩溃
跨临界 ẋ = μx − x² 两分支交换稳定性 阈值切换、物种更替
叉式（超临界） ẋ = μx − x³ 一支失稳裂成两支稳定 屈曲、对称破缺
叉式（亚临界） ẋ = μx + x³ 失稳后无近邻稳态 突变 + 滞后回线

3. 二维系统与极限环

3.1 相平面回顾

二维自治系统 ẋ = f(x, y), ẏ = g(x, y) 的平衡点分类在常微分方程篇已详述：由 Jacobian 的迹 τ 与行列式 Δ 判定——结点、鞍点、焦点（螺旋）、中心。二维相平面的特殊价值在于 Jordan 曲线定理：闭轨把平面分成内外，轨道不能乱窜，因此二维系统的长期行为只有三种归宿：平衡点、闭轨（极限环）、或平衡点/闭轨拼接的环——二维流形上没有混沌！混沌至少需要三维连续系统（或一维不可逆离散映射）。

9. 动力系统 → ML/工程对照表

动力系统概念 ML/工程对应 工程含义
动力系统 x_{n+1} = f(x_n) 梯度下降 θ_{n+1} = θ_n − η∇L(θ_n) 训练本身就是离散动力系统，参数是状态
连续流 ẋ = F(x) 梯度流 θ̇ = −∇L(θ)、Neural ODE 学习率 η→0 的极限；用 ODE 理论分析训练
不动点及其稳定性 训练收敛到极小点/鞍点 Jacobian（≈Hessian）特征值定局部收敛性
f’(x*) 过大 → 失稳 学习率 η 过大 → 震荡、发散 η > 2/λ_max(H) 时迭代矩阵特征值模 > 1，等价于越过倍周期分岔
倍周期/混沌 edge of stability、loss 震荡后自发下降 训练在稳定性边缘运行时呈现类分岔动力学
RNN 前向传播 离散映射的反复复合 f(f(…f(x)…)) 雅可比连乘 → 梯度爆炸/消失 = 正/负 Lyapunov 指数
Lyapunov 指数 λ 相邻初值隐状态分离速率 回声状态网络要求 λ < 0（回声状态性质）
奇异吸引子 数据分布的低维流形 生成模型学的「数据流形」可视为某种吸引集
分岔 超参数越过临界值后行为质变 batch size、学习率、初始化尺度的相变现象
遍历性 SGD 噪声下的稳态分布 时间平均 ≈ 后验/稳态分布采样（SGLD 的理论根基）
极限环 周期行为的训练动态/GAN 振荡 GAN 对抗训练不收敛而绕圈 ≈ 中心/极限环动力学
吸收域（basin） 初始化决定收敛到哪个解 不同初值落到不同吸引子 = 不同极小点
