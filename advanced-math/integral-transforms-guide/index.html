第4章 积分变换深度指南：Laplace · Fourier · FFT · z变换

发表于 2026-10-10 更新于 2026-10-11 分类于 Advanced Math 本文字数： 14k 阅读时长 ≈ 13 分钟

第4章 积分变换深度指南

积分变换的共同思想只有一句话：选一个核函数 K(t, u)，把函数 f(t) 投影到另一组基上，让在时域难做的运算（求导、卷积、解微分方程）在新坐标系里变成简单运算（乘法、查表、代数移项）。对 Laplace 核是 e^{-st}，对 Fourier 核是 e^{-iωt}，对离散序列核是 z^{-n}。

所有积分变换都长着同一张脸：

最值钱的一个事实：指数函数是求导运算的特征函数。

所以一旦把任意函数拆成指数函数的叠加（投影到指数基），求导就整体变成了乘法——这就是 Laplace 与 Fourier 全部威力的来源。本指南按工程师的使用顺序讲：Laplace 解微分方程与控制系统 → Fourier 级数与变换做频谱 → 采样、DFT/FFT 落地到代码 → z 变换统治离散世界，最后给出三大变换对比、Python 实战与 ML/工程对照表。

0. 全景地图

1. Laplace 变换：把微分方程变成代数方程

1.1 定义与收敛域

收敛域（ROC）一句话：使该反常积分（绝对）收敛的 s 全体，对单边变换通常是右半平面 Re(s) > σ₀，σ₀ 称为收敛横坐标。例如 L{e^{3t}} = 1/(s-3) 的收敛域是 Re(s) > 3。

为什么要乘 e^{-σt}？因为现实中大量信号（e^{3t}、阶跃）本身不衰减，直接做 Fourier 变换积分发散；先用 e^{-σt} 强行压住，才能讨论。所以 Laplace 比 Fourier「胃口更好」，这是它统治初值问题的原因。

3.5 Parseval 与能量谱

信号总能量在时域、频域完全相等。滤波器砍掉某些频段，等价于扣掉这部分积分能量——均衡器、降噪的定量语言。

3.6 与自相关的关系（Wiener–Khinchin 定理）

自相关的 Fourier 变换 = 幅度谱的平方（功率谱）。工程上估计功率谱的两条路线由此而来：直接对 FFT 取模平方（周期图法），或先算自相关再变换。Rff(0) = ∫|f|² = 信号总能量。雷达测距、基音检测、周期查找本质上都在找自相关峰。

4. 离散化：采样、DFT、FFT

计算机只认识离散样本。连续 Fourier 世界到工程代码之间隔着三步：采样 → DFT → 用 FFT 加速。

4.1 采样定理（Nyquist–Shannon）

混频（aliasing）现象：fs < 2fmax 时，高于 fs/2 的成分会「折叠」进基带，假装成一个低频信号，且事后无法分离。车轮在视频里倒转、螺旋桨看着变慢，都是混频。

4.3 为什么必须有 FFT

蝶形运算一句话：把序列按下标奇偶不断拆成两半（分治），两个半序列的 DFT 用形如 X = A + W·B、Y = A − W·B 的「蝶形」单元组合，旋转因子 W = e^{-i2π/N}。N 是 2 的整数次幂时效率最高（基-2 FFT），不足可补零。np.fft.fft、SciPy、MATLAB fft 内部都是它。

5. z 变换：离散世界的 Laplace

5.1 定义

一句话：把离散序列投影到 z^{-1} 基上，z^{-1} 在时序里就是「延迟一个采样周期」的算子——数字滤波器和离散控制框图里的每个延迟单元都是一个 z^{-1}。

5.2 与 Laplace / Fourier 的关系

5.3 收敛域

稳定性判据（必须背）：离散 LTI 系统稳定 ⟺ 传递函数 H(z) 的全部极点在单位圆内（等价于连续系统「极点在左半平面」）。

5.4 用途（点到为止）

最常用的一条性质：Z{x[n-1]} = z^{-1}X(z)（零初始状态下），延迟一步 = 乘 z^{-1}。

核心用途 ODE 初值问题、控制系统、电路暂态 频谱分析、滤波、PDE、调制 差分方程、数字滤波器、离散控制
离散/数字形态 z 变换 DFT / FFT —（本身即离散）
稳定性判据 极点全在左半开平面 谱有界/系统函数收敛域含虚轴 极点全在单位圆内
初值处理 天然携带初值 不处理初值 单边形式携带初值
典型用户 控制工程师、模拟/电源电路工程师 音频/图像/通信/算法工程师 DSP、嵌入式、数字控制工程师
