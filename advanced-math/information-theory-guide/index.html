第17章 信息论深度指南

1948 年，Shannon 在《A Mathematical Theory of Communication》中用两个定理回答了三个根本问题：信息怎么度量（熵）、消息能压到多小（信源编码定理：平均码长下界 = 熵）、噪声信道能传多快（信道编码定理：速率低于容量 C 就能任意可靠）。今天机器学习的损失函数一半是信息论：交叉熵损失、KL 正则、VAE 的 ELBO、语言模型的困惑度，本质都是熵与 KL 散度的换皮。工程师视角：每个概念都落到 numpy / scipy 可运行代码，并给出 ML / 工程对照。

8. 信息论 → ML 对照表

信息论概念 对应 ML 概念 关键关系
交叉熵 H(p,q) 分类任务的交叉熵损失 最小化 H(p,q) ⟺ 最大似然 ⟺ 最小化 D_KL(数据分布‖模型分布)
KL 散度 正则项 / 早停的隐式正则 损失中含 D_KL(后验‖先验)，约束模型不偏离先验太远
条件熵 / 联合熵分解 VAE 的 ELBO ELBO = E[log p(x|z)] - D_KL(q(z|x)‖p(z))，重构项 + KL 项
互信息 I(X;Y) 信息瓶颈理论 学表征 Z：最大化 I(Z;Y) 且最小化 I(Z;X)，压缩掉无关信息
条件熵减少量 决策树的信息增益 Gain = H(Y) - H(Y|特征) = I(特征;Y)，ID3/C4.5 的分裂准则
互信息 特征选择 按 I(特征ᵢ; 标签) 排序选 top-k，sklearn 的 mutual_info_classif
熵 H(p) 模型蒸馏的温度 温度 τ soften 输出分布提高其熵，暗知识藏在软标签的相对概率里
熵 语言模型困惑度 PPL = 2^H(p, q_θ)，交叉熵损失的指数化；PPL 越低模型越好
互信息 对比学习 InfoNCE 损失是 I(正样本对) 的下界估计，最大化表示间互信息
KL 散度不对称性 RLHF / 策略优化 PPO/DPO 用 D_KL(新策略‖旧策略) 限制更新幅度，防止策略崩坏
信道容量 生成模型上限 数据熵是给定算力下模型困惑度的理论下界，类似「信道极限」
微分熵 / 最大熵 最大熵强化学习 目标 = 回报 + τ·H(策略)，SAC 鼓励探索防止策略过早塌缩
