第2章：常微分方程

常微分方程（Ordinary Differential Equation，ODE）描述的是「一个量如何随时间（或某个自变量）变化」：从人口增长、物体冷却、弹簧振动、电路充放电，到控制系统、Neural ODE、扩散模型、梯度流，本质上都是在解 ODE。本指南以 MIT 18.03 的实用主线组织内容——一阶方程的全部主流解法、二阶常系数方程、一阶线性方程组与相平面分析，再到 Laplace 变换法与数值法的选择、SymPy / SciPy 可运行代码。只讲工程与机器学习中真正高频的内容，每个类型都配完整例题。

7. ODE → ML / 工程对照表

ODE 形态 ML / 工程对应
线性系统 + 输入 u：y’ = Ay + Bu 控制系统状态空间；Laplace 后得传递函数 G(s) = C(sI − A)^{−1}B + D，PID 与频域设计全部基于它
dx/dt = fθ(t, x)（右端是神经网络） Neural ODE：用 ODE 求解器替代一堆残差块，深度变成「积分终止时间」，用伴随法反向传播，显存与层数无关
dx = f(x,t) dt + g(t) dW 扩散模型的正向 SDE（加噪）；反向 SDE 或概率流 ODE 负责去噪生成，DDPM 是其离散特例
离散 h_{t+1} = F(h_t, x_t) 连续化 RNN / 残差网络的连续极限 dh/dt = F(h, x(t))；Neural ODE 可视作无限深的连续 RNN
S’ = −βSI/N，I’ = βSI/N − γI，R’ = γI 流行病 SIR 模型；基本再生数 R₀ = β/γ 决定是否暴发，疫苗即降低易感池
m x’’ + c x’ + kx = F(t) 机械振动与 RLC 电路数学同构；SPICE、多体仿真器都在数值积分这类 ODE
x’ = σ(y−x)，y’ = x(ρ−z)−y，z’ = xy−βz Lorenz 混沌系统：对初值极端敏感、奇异吸引子，是确定性不可预测性的标准示例
dθ/dt = −∇L(θ) 梯度流即 ODE：把梯度下降看成连续动力系统，用 ODE 理论分析优化器的收敛速率与稳定性
E–L 方程导出的 q’’ = f(q, q’) 机器人与多体动力学；MuJoCo、Isaac Gym 等物理引擎的核心就是 ODE 积分器
连续状态空间 + 过程噪声 dW 连续时间 Kalman 滤波、目标跟踪、随机最优控制；伊藤随机微分方程是 ODE 的随机推广
Logistic / Lotka–Volterra 方程组 增长预测、捕食—猎物种群周期振荡，参数可由时序数据反演（系统辨识）
