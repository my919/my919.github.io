第14章 数值分析深度指南

数学课本给你闭式解（closed-form solution）：x = (−b ± √(b²−4ac)) / 2a、e^{At} y₀、∫ sin x dx = −cos x。工程现实给你的是：一个十次多项式方程没有求根公式、一个百万阶稀疏矩阵求不了逆、一条只有采样点没有表达式的传感器曲线、一个无法解析积分的被积函数。数值分析（Numerical Analysis）就是回答一个问题：当解析解不存在或算不起时，怎样用有限的浮点运算逼近真解，并且知道逼近得有多好。

本指南对应 Bronstein 数学手册第 19 章的工程师视角展开：误差与浮点、非线性方程求根、线性方程组的直接与迭代解法、特征值算法、插值与逼近、数值微分、数值积分、ODE 初值问题数值解。一切数值方法都围绕同一条主线——误差从哪来、怎么控制：模型误差、截断误差、舍入误差，分别对应「问题选得对不对、公式逼近得好不好、计算机算得准不准」。每节配可运行的 Python / NumPy / SciPy 代码，最后给出 ML / 工程对照表与验收清单。

9. 数值分析 → ML / 工程对照表

数值分析概念 ML / 工程对应
不动点迭代 x_{k+1} = g(x_k) 梯度下降、EM 算法、Q-learning 贝尔曼迭代，本质都是求不动点
Newton 法二次收敛 二阶优化（L-BFGS、自然梯度、K-FAC）快但每步贵；SGD 用一阶换廉价
机器精度 ε float32 ε≈1.2e−7、float16 ε≈9.8e−4 决定梯度噪声地板与最小可分辨更新
相消抵消 log(1+x) 用 log1p、softmax 减 max、cross-entropy 用 log-sum-exp 技巧
病态问题 vs 不稳定算法 数据共线性（病问题）加正则；公式选错（烂算法）换稳定实现
条件数 κ(A) Hessian 条件数大 → 梯度下降来回振荡 → 动量/自适应学习率/预条件
LU/Cholesky 求 Ax=b 高斯过程回归、卡尔曼滤波解协方差系统，全部走 Cholesky
Jacobi/GS/CG 迭代 大规模线性系统（图神经网络传播、PDE 求解）的稀疏迭代思想
幂法 PageRank、谱聚类主特征向量、PCA 的幂迭代实现
Runge 现象 高次多项式特征过拟合/外推爆炸，等价于容量控制问题
三次样条 轨迹规划、动画补间、学习率 schedule 的平滑过渡
最小二乘 线性回归 = 最小二乘；lstsq 的 SVD 实现解释了为什么它比正规方程稳
数值微分 h 两难 gradcheck 用 h≈1e−5；生产训练用自动微分而非差分
自适应积分 自适应步长思想后代：自适应学习率、Neural ODE 的容差控制
截断误差 vs 舍入误差 模型偏差 vs 数值噪声：步长/网格细化降前者，升精度降后者
