分布 记号 期望 方差 典型场景
0-1 分布 B(1,p) p p(1−p) 单次点击 / 转化

几何分布 G(p) 1/p (1−p)/p² 首次成功 / 首次崩溃（离散）
均匀分布 U(a,b) (a+b)/2 (b−a)²/12 随机数生成、量化误差
指数分布 Exp(λ) 1/λ 1/λ² 无故障时间、到达间隔
正态分布 N(μ,σ²) μ σ² 测量误差、聚合指标（CLT）
χ² 分布 χ²(n) n 2n 方差推断、拟合优度检验
t 分布 t(n) 0 (n>1) n/(n−2) (n>2) 小样本均值检验
F 分布 F(m,n) n/(n−2) (n>2) 见手册 方差比检验、ANOVA

8. 概率统计 → ML / 工程对照表

概率统计概念 ML / 工程对应
最大似然估计 MLE 交叉熵损失 = 伯努利 / softmax 模型的负对数似然
贝叶斯公式 先验 → 后验的序贯更新、贝叶斯优化、垃圾邮件过滤
中心极限定理 A/B 测试均值近似的合法性、多机指标聚合、误差平均化
大数定律 蒙特卡洛估计、埋点统计收敛、在线学习收敛的前提
马尔可夫链 / 平稳分布 PageRank、强化学习 MDP、隐状态解码
正态分布 权重初始化（Xavier / He 的方差设计）、误差建模
方差 / 协方差 偏差-方差权衡、特征共线性诊断、PCA 的协方差矩阵
条件独立 朴素贝叶斯假设、贝叶斯网络 / 概率图模型
假设检验 / p 值 特征显著性筛选、线上实验的显著性判断
置信区间 线上指标报表的误差条、灰度发布监控
MLE + 正则化 MAP 估计：L2 正则 ⟺ 高斯先验，L1 正则 ⟺ 拉普拉斯先验
χ² / F 检验 卡方特征选择、ANOVA 特征筛选（sklearn 内置）
泊松 / 指数分布 请求到达建模、排队论容量规划、可靠性 MTBF 分析
t 分布 小样本 A/B 测试、厚尾修正的置信区间

9. Python 实战：scipy.stats 与 numpy 模拟

运行要点：scipy.stats 的每个分布都有 pdf/pmf（密度 / 分布律）、
cdf（分布函数）、ppf（分位数，即查表）、rvs（抽样）四个方法；
检验函数统一返回 (统计量, p 值) 二元组；区间估计用
stats.t.interval / stats.norm.interval，scale 参数传标准误 S/√n。
