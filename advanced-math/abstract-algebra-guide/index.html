第20章：抽象代数

微积分研究”变化”，线性代数研究”线性空间”，而抽象代数研究的是运算本身的结构。小学算术告诉我们 3 + 5 = 8，抽象代数问的是更深一层的问题：为什么整数加法和矩阵乘法、置换复合、时钟上的取模加法”长得那么像”？它们共享同一套公理——把 + 和 × 的共性抽出来，就得到了”群”；把加减乘除全部抽出来，就得到了”域”。

这套看似纯粹烧脑的抽象游戏，统治着现代工程的半壁江山：魔方的最小解法步数、晶体的 230 种对称分类、AES 加密里那张大名鼎鼎的字节替换表、二维码被遮住一半仍能扫出的纠错码、比特币签名用的椭圆曲线——背后全是群、环、域的语言。可以说，密码学就是”在有限群上制造计算难题”的艺术，而纠错码就是”在有限域上做线性代数”的工程。

本指南以工程师视角重排标准教材（Artin《Algebra》、Dummit & Foote 的主干）：从群的定义与海量例子出发，经子群与 Lagrange 定理、同态与商群、群作用，进入环与有限域，然后以密码学应用（RSA / DH / ECC / 纠错码）作为重头戏收尾，最后给出 CS 对照表、Python 实战与验收清单。读完后你应当能：验证一个代数结构是不是群、手推 Lagrange 定理、用群论语言重写 RSA、实现椭圆曲线点加、说清楚为什么 256 位 ECC 等价于 3072 位 RSA。

一、群的定义与直觉：对称性的代数

1.1 四公理

群（group）是”一个集合 + 一种运算”满足四条公理的结构：

四条公理一条都不能少，且结合律最不起眼却最关键——矩阵乘法不可交换但可结合，所以可逆矩阵成群；减法连结合律都不满足（(3−2)−1 ≠ 3−(2−1)），所以 (ℤ, −) 不是群。

直觉上，群就是**”可逆操作的全集”**：每个操作都能做、能复合、能撤销、有”什么都不做”。魔方转动的复合、棋子的合法移动、加密与解密，都是这个直觉的化身。

1.2 例子先行：工程师的群动物园

学群论最好的方式是见足够多的例子。下表是工程师必须认识的群：

逐个解释：

  • (ℤ, +)：加法群的原型。0 是单位元，a 的逆元是 −a。
  • (ℤ_n, +)：时钟算术。12 点制时钟就是 ℤ_12；计算机的 32 位无符号整数就是 ℤ_2³²。模 n 乘法要成群必须筛掉不可逆元素：模 n 意义下 a 有乘法逆元 ⟺ gcd(a, n) = 1，所以 (ℤ_n*, ·) 只保留与 n 互素的剩余类。例如 ℤ_10* = {1, 3, 7, 9}，阶为 φ(10) = 4（欧拉函数）。
  • GL(n)：一般线性群，所有可逆 n×n 矩阵。它是”空间的线性对称”——旋转、缩放、剪切的复合。det ≠ 0 就是封闭性的全部条件。
  • S_n（对称群）：n 个元素的全排列，共 n! 个，运算是”先做再做”的置换复合。洗牌算法、排序下标、数据库行重排都是 S_n。
  • D_4（二面体群）：正方形保持自身重合的刚体变换——4 个旋转（0°, 90°, 180°, 270°）加 4 条轴的翻转，共 8 个元素。注意”先旋转再翻转 ≠ 先翻转再旋转”，所以它非阿贝尔。
  • 魔方群：所有合法转动序列的集合，|G| ≈ 4.3 × 10¹⁹。它是一个巨大但有限的置换群（贴在 48 个可动色块上），”上帝之数 20”就是这个群图的直径（见第八节）。

图 20-1　正三角形全部对称构成 D3：3 个旋转 + 3 个翻转共 6 个元素

1.3 阶与元素的阶

例子（写加法时 g^k 读作 k·g，e 读作 0）：

  • ℤ_12 中 5 的阶：5, 10, 3, 8, 1, 6, 11, 4, 9, 2, 7, 0 → ord(5) = 12（与 12 互素，能”走遍”整个群）
  • ℤ_12 中 4 的阶：4, 8, 0 → ord(4) = 3
  • S_3 中 3-循环 (1 2 3) 的阶为 3；对换 (1 2) 的阶为 2
  • GL(2) 中旋转 90° 矩阵的阶为 4；一般可逆矩阵阶可能是 ∞

工程直觉：元素的阶度量了”重复一个操作多久回到原点”。线性反馈移位寄存器（LFSR）的周期、密码学生成元的安全强度、迭代算法的循环检测，全都在算元素的阶。

图 20-3　模 12 加法下不断 +1 走完整圈回到 0，构成 12 阶循环群

二、子群与 Lagrange 定理

2.1 子群判定

子群 H ≤ G：H 是 G 的子集，且在 G 的运算下自己也成群。判定只需验证：

例子：nℤ = {…, −2n, −n, 0, n, 2n, …} ≤ ℤ；旋转子群 {e, r, r², r³} ≤ D_4；SL(n)（行列式为 1 的矩阵）≤ GL(n)。

2.2 循环群与生成元

由一个元素反复运算生成的子群：

  • ℤ = ⟨1⟩ = ⟨−1⟩；ℤ_n = ⟨1⟩，且 ⟨k⟩ = ℤ_n ⟺ gcd(k, n) = 1
  • ℤ_7* = ⟨3⟩ = {3, 2, 6, 4, 5, 1}（3 是模 7 的原根）；但 2 只生成 {2, 4, 1}，阶 3
  • 循环群必阿贝尔；循环群的子群仍循环

工程对应：原根 = 乘法群的发电机。Diffie-Hellman 选的大素数 p 配原根 g，就是要 ⟨g⟩ = ℤ_p*，让 g 的幂遍历尽可能多的密钥。

工程意义：Lagrange 定理告诉你**”子结构的大小必须整除总大小”**。设计哈希分桶、分布式分片、纠错码的校验位结构时，这个整除约束会反复出现；密码协议里子群攻击（如小阶子群泄露）正是利用”忘查 ord(g) 是否够大”。

三、同态与同构：结构保持的映射

3.1 同态

例子：

  • 指数函数 exp: (ℝ, +) → (ℝ₊*, ·)，exp(a+b) = exp(a)·exp(b)——这就是”log 把乘法变加法”的代数表述
  • 取模映射 π: ℤ → ℤ_n，k ↦ k mod n
  • 行列式 det: GL(n) → ℝ*，det(AB) = det(A)·det(B)
  • 奇偶性 sgn: S_n → {+1, −1}（把置换映为其符号）

3.2 核与像

工程直觉：核是映射丢掉的信息，像是映射保住的信息。有损压缩、降维投影、特征提取——凡是”扔掉一部分结构保住另一部分”的操作，抽象代数都用核与像来刻画。

3.3 同构与 Cayley 定理

双射的同态叫同构（isomorphism），记 G ≅ H。同构的群在代数上”完全相同”，只是元素换了个名字：

Cayley 定理：每个群都同构于某个置换群的子群（把 g 看作”左乘 g”这个 G 上的置换）。一句话解读：置换群是群的万有模型——任何群都能在 S_n 里找到一份拷贝。这正是洗牌、加密、状态机里置换无处不在的深层原因。

四、正规子群与商群：模掉一个子结构

4.1 陪集

例子：G = ℤ，H = 3ℤ，陪集为 3ℤ、1 + 3ℤ、2 + 3ℤ——这就是模 3 的三个剩余类。商群的思想正是”把陪集当作一个新元素”。

直觉：正规子群是可以被”整体模掉”的子结构——它对 G 的内部对称（共轭）不敏感。非正规子群（如 D_4 里单个翻转生成的 {e, s}）左、右陪集不一致，无法定义陪集乘法。

五、群作用与对称性（简述）

群作用（group action）是群”动起来”的方式——群元素作为集合 X 上的变换：

Burnside 引理（一句话版）：在群 G 作用下，X 的不同轨道数 = G 中各元素不动点的平均数。它是计数染色问题的核武器——“n 颗珠子 k 种颜色的项链，旋转/翻转后本质不同的有多少种”，套 Burnside 一分钟出答案，不用枚举。化学同分异构体计数、逻辑电路的等价类计数都用它。

例子直觉：正方形的顶点着色在 D_4 作用下，轨道的概念把”看起来不同但对称等价”的染色合并——这正是”对称性计数”与”穷举去重”的本质。

六、环与域：两种运算的舞台

6.1 环

环（ring）把加法和乘法放在同一个集合上：

整环：无零因子的交换环（a·b = 0 ⟹ a = 0 或 b = 0），如 ℤ、ℤ_p（p 素数）。理想 I ⊲ R：对加法封闭、且”吸收”环乘法的子集（∀r ∈ R, i ∈ I，r·i ∈ I）。理想之于环正如正规子群之于群——可以模掉它得到商环 R/I，同态基本定理的环版照常成立。

GF(2⁸) 与 AES：AES 的 SubBytes 和 MixColumns 全部在 GF(2⁸) 上定义，取不可约多项式 m(x) = x⁸ + x⁴ + x³ + x + 1。一个字节就是一个域元素：

7.1 RSA：一句话的群论表述

7.2 Diffie-Hellman：循环群上的离散对数

工程要点：群的选取就是安全性的选取。ℤ_p* 要配大素数与原根，且必须检查元素阶（小阶子群攻击）；这也是为什么现代实践转向椭圆曲线群。

7.3 椭圆曲线群：几何定义的加法

椭圆曲线 E: y² = x³ + ax + b（判别式 4a³ + 27b² ≠ 0 保证无奇点）上的点，加上一个”无穷远点” 𝒪，构成阿贝尔群：

封闭性来自三次曲线与直线的交点恰有三个（Bezout 定理的特例），结合律是唯一不显然的公理（可用代数几何或直接验证证明）。任何域上都能定义这个群——密码学用的是 GF(p) 或 GF(2ⁿ) 上的版本：直线变成模 p 意义下的”直线”，图像从平滑曲线变成离散点阵，但群公理一字不改。

7.4 纠错码：有限域上的线性代数

Reed-Solomon 码更进一步：把消息看作 GF(2⁸) 上多项式的系数，码字是它在 n 个点上的取值；插值定理保证”任意 k 个正确值即可重建多项式”——这就是二维码破损可读、CD 划伤可播的数学。没有有限域，现代存储与通信一天都撑不下去。
