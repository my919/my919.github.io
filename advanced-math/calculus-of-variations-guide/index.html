第6章：变分法

普通微积分解决的问题是：给定一个函数 f(x)，在点 x 里找极值；而变分法（Calculus of Variations）解决的问题是：在一个函数族里找极值——自变量本身就是函数 y(x)，被求极值的对象叫泛函 J[y]。如果说普通微积分是在地图上找最低的山谷，变分法就是在”所有可能路线”的空间里找最优的那条路。工程师关心的最速降线、悬链线、测地线、最小作用量、最短时间控制、路径规划，乃至 VAE 的变分下界，全部是这一个思想的不同面孔。

主线：泛函 J[y] → 一阶变分 δJ=0 → Euler-Lagrange 方程（无限维空间的”梯度为零”）→ 第一积分降阶 → 约束与边界 → 物理（Hamilton / Noether / Fermat）→ 工程（Pontryagin / Bellman / LQR）→ ML（ELBO / 变分推断 / 正则化）。

0. 学习地图

工程师视角的一句话：梯度下降是”沿负梯度改参数”，变分法是”沿负泛函梯度改整条曲线”。Euler-Lagrange 方程就是函数空间里的”驻点条件 ∇f=0”。

1. 从有限维到无限维：泛函与变分

1.1 泛函 J[y] 的定义

寻找使 J 取极小（或驻值）的函数 y(x)，就是在无限维的函数空间里做极值问题。

1.2 变分 δy 与 δJ：对照普通微分 dy

对照记忆：δy ↔ dx（自变量的扰动），δJ ↔ df（目标量的一阶变化），δJ=0 ↔ df=0（驻点条件）。区别只在于：普通微分处理有限个坐标，变分处理无限个坐标（连续的 x）。
