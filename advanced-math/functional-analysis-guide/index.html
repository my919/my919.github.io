第10章 泛函分析深度指南：Banach空间 · Hilbert空间 · 算子与谱

发表于 2026-10-10 更新于 2026-10-11 分类于 Advanced Math 本文字数： 15k 阅读时长 ≈ 14 分钟

第10章 泛函分析深度指南

泛函分析（Functional Analysis）的核心思想只有一句话：把”函数”当作空间中的一个”点”。一个 n 维向量 x = (x₁, …, xₙ) 是 n 个数；一个函数 f: [a,b] → ℝ 可以看成”无穷多个坐标”——每个自变量 x 处都有一个分量 f(x)。一旦接受这个视角，有限维线性代数里熟悉的一切——长度、夹角、正交、投影、基、特征值——都可以在无穷维的”函数空间”里重新定义，而泛函分析就是研究这套推广何时成立、如何成立、以及成立的代价是什么的学科。它是有限维线性代数在无穷维的推广，也是从”会算”走向”会证”的分水岭：微分方程解的存在唯一性、Fourier 级数为什么收敛、量子力学为什么用算子描述可观测量、核方法为什么合法，答案全部藏在本文的定理里。

主线：度量空间（距离与完备）→ 赋范空间（长度）→ 内积空间（角度与正交）→ Hilbert 空间（完备的内积空间，无穷维里”最像 ℝⁿ”的空间）→ 线性算子与泛函 → Riesz 表示 → 谱理论 → 应用（PDE 弱解 / 量子力学 / RKHS 核方法）。案头参照 Bronstein《数学手册》第 12 章。

0. 学习地图

工程师视角的一句话：线性代数告诉你”对称矩阵可正交对角化、最小二乘就是投影”；泛函分析告诉你这两件事在无穷维依然成立——只要空间完备（Hilbert）、算子性质足够好（有界/紧/自伴）。核方法、谱聚类、最小二乘、值迭代收敛，全是这套定理的推论。

1. 从有限维到无穷维：函数是空间中的”点”

1.1 把函数当向量看

线性代数里的大多数概念都可以照搬：线性组合 αf + βg 仍是函数；线性映射的连续版本是积分算子：

这个对照不是比喻，而是严格的数学：Green 函数、核方法的核函数、积分变换的核，全都是”无穷维矩阵”。

1.2 无穷维的新麻烦：为什么需要新工具

照搬不是免费的。无穷维空间里有两个有限维绝不成立的”事故”，它们决定了泛函分析必须引入拓扑（收敛性）的概念：

一句话：有限维里”空间”由其代数结构（维数）唯一决定；无穷维里代数结构之外还有拓扑结构，选范数就是选拓扑，选错范数整个理论就不成立。

2. 度量空间：距离、完备性与压缩映射

2.1 距离三公理与开/闭集

度量空间是最一般的”能谈收敛”的舞台：不要求加法、不要求数乘，只要有距离。这把”收敛”从微积分的实数轴解放出来，可以谈”函数列收敛”、”曲面列收敛”、”测度列收敛”。

2.2 Cauchy 列与完备性

工程直觉：不完备的空间像有漏洞的容器——迭代算法可能收敛到一个”不在定义域里”的答案。所有数值算法的第一步，都是确认自己工作在完备空间里。

2.3 压缩映射原理（Banach 不动点定理）

这是整个应用数学中”构造性存在唯一性证明”的模板：不仅断言解存在，还顺手给出了算法（迭代）和误差估计（qⁿ 几何收敛）。

注意这个证明的”泛函”风格：完全不逐点分析微分方程，而是在函数空间里对算子用不动点定理。这就是泛函分析的威力——把”解方程”翻译成”空间几何问题”。

3. 赋范空间与 Banach 空间

3.1 范数三公理

度量给”距离”，范数额外给”长度”且与线性结构相容（齐次性）。有了长度才能谈球面、单位向量、级数绝对收敛。

3.2 C[a,b]：连续函数空间与一致收敛

3.3 Lᵖ 空间

3.4 ℓᵖ 序列空间

对照记忆：Lᵖ 看积分（连续坐标），ℓᵖ 看级数（离散坐标）；有限区域 Lᵖ 越大的 p 越强，ℓᵖ 越小的 p 越强。

4. 内积空间与 Hilbert 空间

4.1 内积公理与诱导范数

范数给长度，内积额外给角度：cos θ = ⟨x,y⟩/(‖x‖‖y‖)。有了角度才有正交 x ⊥ y ⟺ ⟨x,y⟩ = 0，才有投影与基——Hilbert 空间因此是无穷维里几何性质最贴近 ℝⁿ 的空间。

4.2 Cauchy-Schwarz 不等式

工程史上最常用的不等式之一：信号处理的相关上界、量子力学的测不准原理、SVM 间隔的估计，全都从它出发。

9. 泛函分析 → ML/工程对照表

泛函分析中的概念 ML / 工程中的对应
函数 = 空间中的点 embedding：词/图/用户被表示为向量，整个数据集是空间中的点云
Hilbert 内积 ⟨f,g⟩ 特征空间点积、余弦相似度、attention 的 ⟨Q,K⟩
正交投影定理（残差 ⊥ 子空间） 最小二乘、线性回归的正规方程、Galerkin/有限元、Kalman 滤波
Riesz 表示定理 对偶表示：参数向量即函数；RKHS 中 f = Σ αᵢk(xᵢ,·) 的依据
广义 Fourier 展开 / Parseval 正交基变换、谱分解、信号能量守恒、图信号处理
压缩映射 ⟹ 不动点唯一+几何收敛 值迭代/Bellman 算子（γ<1 是压缩常数）、EM、不动点迭代收敛分析
自伴算子谱定理（谱全实、正交对角化） 谱聚类与图神经网络的图拉普拉斯分解、PCA（协方差算子对角化）
紧算子谱离散 积分方程数值化、Nyström 方法、核矩阵低秩逼近的合法性
L² 范数 / L² 空间 MSE 损失、能量泛函、白噪声功率、最小均方估计（MMSE）
Lᵖ 范数（p≠2 无内积） L1/L2 正则、Huber/分位数等鲁棒损失、p-范数约束的几何差异
有界 ⟺ 连续、算子范数 Lipschitz 常数、谱归一化、网络的 Lipschitz 界与对抗鲁棒证书
对偶空间 X* / Hahn-Banach 凸优化对偶问题、KKT 条件、SVM 的间隔最大化 ⟺ 对偶形式
完备性（Cauchy 列收敛） 数值格式可靠性：迭代极限不跑出解空间，Banach 空间的算法前提
