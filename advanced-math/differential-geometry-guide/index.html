第7章 微分几何深度指南

微分几何只做一件事：用微积分研究弯曲的空间。

普通几何学（欧几里得那一套）研究的是平直世界里的直线、圆、三角形；而现实世界充满了弯曲——地球是球面、卫星轨道是空间曲线、广义相对论里时空本身就是弯的。微分几何的核心思想是：把弯曲的对象局部线性化（切线、切平面、切空间），用导数刻画”弯曲的程度”，再把这些局部信息拼回整体。

全篇最重要的一个概念是曲率（curvature）。它的直观定义只有一句话：

曲率 = 局部偏离平直的程度。

  • 直线处处不偏离直线 → 曲率为 0；
  • 圆处处均匀偏离 → 曲率为常数，半径越小弯得越狠，曲率越大；
  • 球面向各个方向都弯 → 高斯曲率为正；
  • 马鞍面一个方向向上弯、另一个方向向下弯 → 高斯曲率为负。

工程师为什么要学它？因为机器学习里的”流形学习”、图形学里的”网格平滑”、机器人里的”姿态插值”、深度学习里的”自然梯度”，骨子里全是微分几何。数据往往落在高维空间的一个低维弯曲子流形上，不理解曲率，就理解不了这些算法在做什么。

本篇对应 Bronstein 数学手册第 3 章几何学的微分几何部分，按”曲线 → 曲面 → 内蕴几何 → 流形”的顺序展开，所有公式用 Unicode 书写，所有代码用 SymPy 可直接运行。

一、参数曲线：正则性与弧长参数化

1.1 参数曲线

1.2 正则曲线（regular curve）

定义：若 r’(t) 处处连续且 r’(t) ≠ 0，称曲线是正则的。

为什么要求 r’ ≠ 0？因为 r’(t₀) = 0 的点，切向量退化，曲线在该点可能出现尖点（cusp）或停顿，微积分工具失效。几何上好的曲线必须先排除这类病态点。正则性保证每一点都有唯一确定的单位切向量。

1.3 弧长与自然参数

曲线的弧长：

定义弧长函数 s(t) = ∫[a,t] |r’(τ)| dτ，则 ds/dt = |r’(t)| > 0，可反解 t = t(s)，把曲线重新参数化为 r(s)。

弧长参数化（自然参数化）的标志：

直觉：用弧长当参数，相当于”匀速运动”，每走 1 个单位参数就前进 1 个单位路程。弧长参数是曲线的内蕴参数——它只依赖曲线本身的形状，不依赖于你用什么速度去描它。理论上的一切公式（Frenet 公式等）都在弧长参数下最简洁。

1.4 平面曲线的曲率 κ 与曲率半径 ρ

设平面曲线取弧长参数 r(s)，单位切向量 T(s) = r’(s)。曲率定义为切向量方向的转弯速率：

若切向量与 x 轴夹角为 θ(s)，则 κ = |dθ/ds|——曲率就是方向角对弧长的变化率，即”每前进一单位路程，方向转了多少”。这正是”偏离平直的程度”的精确化。

  • 直线：方向不变 → κ = 0；
  • 半径为 R 的圆：走一圈 2πR 路程方向转 2π → κ = 1/R。

2.2 Frenet–Serret 公式

标架随 s 的变化率完全被两个函数 κ(s)、τ(s) 决定：

  • κ(s)：曲率，刻画 T 转向 N 的速率——曲线”弯”得多快；
  • τ(s)：挠率（torsion），刻画 B 的变化——曲线”扭”出密切平面的速率。τ > 0 还是 < 0 区分右旋/左旋（DNA 双螺旋、螺丝的旋向）。

2.3 两个退化判据

第二条的直觉：τ = 0 意味着 B 恒定（B’ = 0），密切平面不动，曲线始终躺在同一个平面里。所以挠率是”偏离平面程度”的度量，正如曲率是”偏离直线程度”的度量。

2.4 曲线论基本定理（一句话）

给定光滑函数 κ(s) > 0 与 τ(s)，在空间中存在曲线以它们为曲率与挠率；且在刚体运动（平移+旋转）意义下，这条曲线唯一。

即：κ 和 τ 唯一决定一条曲线——它们是空间曲线的”完整不变量”，相当于曲线的 DNA。两个参数、一个存在性、一个唯一性，这是整个曲线论最漂亮的结果。

五、Gauss 绝妙定理：曲率是内蕴的

5.1 Theorema Egregium（1827）

Gauss 曲率 K 只依赖于第一基本形式（E, F, G 及其导数），与曲面如何嵌入三维空间无关。

Gauss 自己称之为”绝妙定理”。表面上看 K = κ₁κ₂ 用的是主曲率——那是曲面在空间中弯曲的外蕴信息；但绝妙定理断言，二者的乘积恰好可以只用曲面内部的度量算出来（Brioschi 公式把 K 写成 E,F,G 及其偏导的表达式）。一只生活在曲面上的二维蚂蚁，不离开曲面、不抬头看三维空间，仅用尺子和量角器测量内部几何，就能算出 K。

5.2 推论一：地图为什么必然变形

球面 K = 1/R² > 0，平面 K = 0。等距变换保持 I，从而保持 K。若存在球面到平面的等距映射，K 必须处处相等——矛盾。所以：

不存在把球面无失真地摊成平面的地图。 任何世界地图都必然在面积、形状或距离上变形（墨卡托投影保角但高纬度面积爆炸，等积投影保面积但形状扭曲）。这不是制图技术不够好，而是 Gauss 曲率的刚性。

5.3 推论二：纸为什么能弯成圆柱

平面纸 K = 0，圆柱面：一个主方向沿圆周弯曲（κ₁ = 1/R），另一个主方向沿母线是直的（κ₂ = 0），故 K = κ₁κ₂ = 0。K 相同 ⇒ 局部等距存在 ⇒ 纸可以无拉伸、无褶皱地弯成圆柱（或圆锥）。但你永远不能把一张纸平整地裹住篮球（K = 1/R² ≠ 0）——纸会起皱，披萨店把披萨边卷起来拿防止下垂，利用的也是 K = 0 保持不变的刚性。

六、测地线：曲面上的”直线”

6.1 定义与直觉

**测地线（geodesic）**是曲面上”尽可能直”的曲线，两个等价刻画：

物理直觉：在曲面上开车，不打方向盘走出的轨迹就是测地线。变分法视角：测地线是弧长泛函 L = ∫ ds 的极值曲线，满足测地线方程（一个关于 u(t), v(t) 的二阶常微分方程组，系数由第一基本形式的 Christoffel 符号给出）。

6.2 球面上的测地线是大圆

球面的测地线恰好是大圆（过球心的平面与球面的交线，如赤道和所有经线圈）。纬线圈（除赤道外）不是测地线——沿纬线走必须持续”转弯”。

这解释了航线为什么绕弯：北京飞旧金山的航班在平面地图上画出一条向北凸的弧线，看起来绕远，实际上那是球面大圆航线——球面上的最短路径。平面地图（墨卡托投影）把大圆画成了曲线，把”直”的显示成了”弯”的，这正是曲率与地图变形联手造成的错觉。

七、流形初步（点到为止）

7.1 n 维流形

n 维流形（manifold）：一个局部看起来像 ℝⁿ 的空间。精确地说，每一点都有一个邻域，可以通过坐标卡（chart） 与 ℝⁿ 的开集建立双射（同胚）；一族覆盖整个空间的坐标卡叫图册（atlas），坐标卡之间重叠区域的转换函数要求光滑（微分同胚）。

地球表面是最贴切的例子：地球整体是球面（不是平面），但每座城市的地图都是平的——一张张平面地图合起来就是图册。流形 = “由局部平坦的地图拼接而成的整体弯曲空间”。

7.2 切空间

流形上每一点 P 处可以定义切空间 T_P M：该点所有切向量构成的 n 维线性空间——它是流形在该点的最佳线性逼近，是把微积分搬到弯曲空间上的舞台。曲线论中的 T、曲面论中的切平面，都是切空间的低维特例。

7.3 黎曼度量与张量

黎曼度量 g：在每个切空间上光滑地指定一个内积：

有了 g 就能度量切向量的长度与夹角，从而度量流形上曲线的长度、区域体积、定义测地线、定义曲率（Riemann 曲率张量、Ricci 曲率、标量曲率）。曲面论中的第一基本形式 I 就是黎曼度量在 2 维情形的化身：g = E du² + 2F du dv + G dv²。

张量（一句话）：张量是定义在切空间上的多线性函数——它吃进去若干个向量/余向量，吐出一个数，且与坐标选取无关。度量张量 g、曲率张量、应力张量、惯性张量，都是这个统一框架的实例。”坐标会变，张量不变”，这正是物理学定律需要的语言。
