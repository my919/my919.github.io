第18章 随机过程深度指南

承接《概率论与数理统计深度指南》第 7 节「随机过程入门」，本篇把它展开成完整专题。核心点题一句话：**随机变量描述「一次抽样的不确定」，随机过程描述「随时间演化的不确定」——概率论加上时间轴，就是随机过程。**主线：基本概念 → 离散时间马尔可夫链（核心）→ 吸收链 → 连续时间马尔可夫链 → 泊松过程 → 布朗运动 → MCMC（工程重头戏）→ 鞅与停时。工程师视角：每个概念都落到 numpy 可运行代码，并给出 ML / 工程对照（PageRank、扩散模型、强化学习、排队容量规划）。

9. 随机过程 → ML / 工程对照表

随机过程概念 ML / 工程对应
马尔可夫链平稳分布 πP = π PageRank：网页图随机游走的长期停留分布
马尔可夫链 + 隐状态 HMM 与词性标注 / 语音识别：Viterbi 解码、前向后向算法
MCMC（MH / Gibbs） 贝叶斯深度学习与概率编程：PyMC / Stan 的后验采样
布朗运动 / SDE 扩散模型（DDPM / Score SDE）：前向加噪是扩散，反向去噪是反向 SDE
马尔可夫决策过程 MDP 强化学习：转移矩阵 + 奖励 + 折扣，Bellman 方程的宿主
泊松过程 / 排队论 容量规划：线程池 / 连接池 / 坐席 sizing，M/M/1 延迟估算
指数分布无记忆性 可靠性工程：MTBF 建模、故障间隔分析、恒定失效率假设
CTMC 生灭过程 M/M/1、M/M/c 队列：服务台数量与等待时间权衡
鞅 / 可选停时定理 量化交易「择时无效」判据、序列检验 SPRT、A/B 提前终止分析
Gibbs 采样 LDA 主题模型、协同过滤中的缺失值插补
高斯过程（布朗运动的近亲） 贝叶斯优化代理模型、超参搜索、时空插值 kriging
吸收马尔可夫链 漏斗转化 / 用户流失分析：平均生命周期 = 平均吸收时间
