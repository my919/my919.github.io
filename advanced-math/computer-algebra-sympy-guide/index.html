第16章：计算机代数与 SymPy

Bronstein 手册第 20 章「计算机代数」的工程师版本：符号计算（CAS）与数值计算是两条互补的腿——符号计算操作表达式本身，给出精确结果（√2 就是 √2，不是 1.41421356）；数值计算操作浮点数，给出近似结果但速度极快。推公式、化简、求解析解用前者；批量算数据、训练模型用后者。本系列前几篇散落各处的 SymPy 代码，在这里系统化成一条完整工作流：建符号 → 化简 → 求解 → 求值 → lambdify 上生产。

1. CAS 全景：什么是计算机代数系统

主流 CAS 对比：

系统 许可 实现语言 生态与适用场景
SymPy BSD（免费开源） 纯 Python 嵌入 Python 项目、教学、代码生成、CI 里推公式
Mathematica 商业（昂贵） Wolfram Language 科研原型、符号能力最全、交互笔记本强大
Maple 商业 Maple 语言 工程计算、微分方程传统强项、与 MATLAB 集成
SageMath GPL（免费开源） Python（胶水层） 数论/代数几何/组合数学，聚合 Maxima、GAP 等
Maxima GPL（免费开源） Common Lisp 老牌 CAS（源自 MACSYMA），批处理脚本、wxMaxima 界面
MATLAB Symbolic Toolbox 商业 封装 MuPAD 已买 MATLAB 的工程团队顺手使用

SymPy 的定位一句话：纯 Python、零依赖、可 pip install、能把符号推导直接嵌进你的代码库和流水线——这是它对工程师最大的价值；符号能力深度不如 Mathematica，但够用且免费。

11. 计算机代数 → 工程对照表

CAS 能力 工程场景对应
符号求导 / 化简 公式推导自动化：损失函数梯度、灵敏度分析、控制器设计
codegen / lambdify 代码生成：推导一次，生成 C/Fortran/numpy 代码进生产
有理数精确算术 金融计算、密码学，杜绝浮点累积误差
假设系统 量纲 / 定义域检查：positive、real、integer 约束的形式化表达
方程求解 solve/dsolve 协议验证、参数反演、平衡点解析
符号微分 与自动微分（AD）的区别：符号微分给表达式、会膨胀；AD 沿计算图给数值、ML 主流
lambdify + 扫描 符号回归前置：先拟合结构假设，再数值优化参数
表达式树遍历 自定义规则引擎：编译器优化、查询重写、定理证明
矩阵符号运算 机器人运动学（DH 参数）、结构力学刚度阵推公式
任意精度 evalf 高精度基准值：校验数值算法的误差阶
不等式求解 稳定性条件、可行域分析、安全包络
