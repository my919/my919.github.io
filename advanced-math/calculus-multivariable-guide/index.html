9. 多变量微积分 → ML / 工程对照

概念 ML / 工程对应
梯度 梯度下降 / 上升、参数更新方向
方向导数 对抗扰动方向（FGSM：沿 ∇L 符号方向）
多元链式法则 / Jacobian 反向传播、流模型雅可比
Hessian / 鞍点 二阶优化、深度学习损失面、牛顿法
Lagrange / KKT SVM、约束优化、正则化的对偶解释
重积分 / 边际化 联合与边缘概率、Bayes 积分、期望
雅可比行列式 归一化流密度变换（log det J）、变量替换
散度 守恒律、概率流（Fokker-Planck）
旋度 / 环流 流体、电磁、涡量
Green/Stokes/Gauss 数值 PDE、电磁仿真、图形学流体
