第一章：函数、极限、连续

发表于 2026-08-30 更新于 2026-10-25 分类于 高等数学 本文字数： 3.2k 阅读时长 ≈ 3 分钟

第一章：函数、极限、连续

1、常用等价无穷小

当 $x \to 0$ 时，

$$\sin x \sim \tan x \sim \arcsin x \sim \arctan x \sim e^x - 1 \sim \ln(1+x) \sim x,$$

$$\alpha^x - 1 \sim x\ln\alpha, \qquad 1 - \cos x \sim \frac{1}{2}x^2, \qquad (1+x)^{\alpha} - 1 \sim \alpha x,$$

$$x - \ln(1+x) \sim \frac{1}{2}x^2, \qquad x - \sin x \sim \arcsin x - x \sim \frac{1}{6}x^3,$$

$$\tan x - x \sim x - \arctan x \sim \frac{1}{3}x^3, \qquad \tan x - \sin x \sim \arcsin x - \arctan x \sim \frac{1}{2}x^3.$$

2、几个常用极限

$$\lim_{x \to 0} x^{\alpha}\ln^{\beta} x = 0, \alpha > 0, \beta \text{ 为任意常数；}$$

$$\lim_{x \to +\infty} \frac{x^{\alpha}}{e^{\beta x}} = 0, \alpha \text{ 为任意常数}, \beta > 0\text{；}$$

$$\lim_{x \to +\infty} \frac{\ln^{\beta} x}{x^{\alpha}} = 0, \alpha > 0, \beta \text{ 为任意常数；}$$

$$\lim_{n \to \infty} \sqrt[n]{n} = 1, \lim_{x \to 0^+} x^x = 1.$$

3、常用麦克劳林公式

$$e^x = 1 + x + \frac{1}{2!}x^2 + \cdots + \frac{1}{n!}x^n + o(x^n)$$

$$\ln(1+x) = x - \frac{1}{2}x^2 + \frac{1}{3}x^3 - \cdots + (-1)^{n-1}\frac{x^n}{n} + o(x^n)$$

$$\sin x = x - \frac{x^3}{3!} + \cdots + (-1)^n\frac{x^{2n+1}}{(2n+1)!} + o(x^{2n+1})$$

$$\cos x = 1 - \frac{1}{2!}x^2 + \cdots + (-1)^n\frac{x^{2n}}{(2n)!} + o(x^{2n})$$

$$\tan x = x + \frac{1}{3}x^3 + o(x^3)$$

$$\arcsin x = x + \frac{1}{6}x^3 + o(x^3)$$

$$\arctan x = x - \frac{1}{3}x^3 + o(x^3)$$

$$\frac{1}{1-x} = 1 + x + x^2 + \cdots + x^n + o(x^n)$$

$$\frac{1}{1+x} = 1 - x + x^2 + \cdots + (-1)^n x^n + o(x^n)$$

$$(1+x)^m = 1 + mx + \frac{m(m-1)}{2!}x^2 + \cdots + \frac{m(m-1)\cdots(m-n+1)}{n!}x^n + o(x^n)$$

4、等价无穷小的使用要点与常见误区

等价无穷小替换的本质是麦克劳林展开”取主部”：当 $x\to 0$ 时，函数与其泰勒展开的首个非零项等价。

  • 乘除可换，加减慎换：替换只适用于整个分子或分母中的因子。例如求 $\lim\limits_{x\to 0}\dfrac{\tan x-\sin x}{x^3}$ 时不能把 $\tan x,\sin x$ 各自换成 $x$（会错误地得到 $0$），因为相减后主部抵消，必须保留到三阶：$\tan x-\sin x\sim\dfrac{1}{2}x^3$。
  • 展开阶数原则：”上下同阶”——分母是几阶无穷小，分子就展开到几阶；加减式则展开到”不抵消为止”。
  • 上述常用极限反映增长量级：当 $x\to+\infty$ 时 $\ln x\ll x^{\alpha}\ll\mathrm{e}^{x}$；当 $x\to 0^+$ 时任何正幂次 $x^{\alpha}$ 都”压过” $\ln x$。

5、典型例题

例1 求 $\lim\limits_{x\to 0}\dfrac{x-\sin x}{x^3}$.

解：由 $\sin x=x-\dfrac{x^3}{3!}+o(x^3)$，得 $x-\sin x=\dfrac{x^3}{6}+o(x^3)$，故极限为 $\dfrac{1}{6}$。直接用结论 $x-\sin x\sim\dfrac{1}{6}x^3$ 亦可。

例2 求 $\lim\limits_{x\to 0}\dfrac{\mathrm{e}^x-1-x}{x^2}$.

解：$\mathrm{e}^x=1+x+\dfrac{x^2}{2}+o(x^2)$，分子 $=\dfrac{x^2}{2}+o(x^2)$，故极限为 $\dfrac{1}{2}$。注意：若把 $\mathrm{e}^x-1$ 换成 $x$，分子变成 $0$，正是”加减慎换”的反例。

例3 求 $\lim\limits_{x\to+\infty}x\big(\sqrt{x^2+1}-x\big)$.

解：分子有理化，$\sqrt{x^2+1}-x=\dfrac{1}{\sqrt{x^2+1}+x}$，故

$$\lim_{x\to+\infty}\frac{x}{\sqrt{x^2+1}+x}=\lim_{x\to+\infty}\frac{1}{\sqrt{1+\frac{1}{x^2}}+1}=\frac{1}{2}.$$

例4 求 $\lim\limits_{x\to 0}(1+2x)^{1/x}$（$1^{\infty}$ 型）.

解：取对数化为乘积：$(1+2x)^{1/x}=\mathrm{e}^{\frac{\ln(1+2x)}{x}}$，而 $\ln(1+2x)\sim 2x$，故极限为 $\mathrm{e}^2$。此类题的标准套路是”取对数 $+$ 等价替换”。

6、与后续章节的联系

麦克劳林公式是第二章泰勒定理在 $x_0=0$ 处的特例，也是第七章函数幂级数展开的”源头”；等价无穷小与洛必达法则互为补充——等价替换优先（快），洛必达法则兜底（通用）。$\lim\limits_{x\to 0^+}x^{\alpha}\ln^{\beta}x=0$ 这类结论是第三章反常积分判敛的直觉基础。

7、本章小结

  • 极限计算三板斧：等价替换（乘除因子）、泰勒展开（加减抵消）、取对数（$1^{\infty}$ 型）；
  • 展开阶数原则：上下同阶、加减到不抵消为止；
  • 常用极限刻画增长量级：$\ln x\ll x^{\alpha}\ll\mathrm{e}^{x}\ (x\to+\infty)$。

练习题

  1. 求 $\lim\limits_{x\to 0}\dfrac{\arctan x-x}{x^3}$。（提示：$\arctan x=x-\dfrac{x^3}{3}+o(x^3)$，答案 $-\dfrac{1}{3}$。）
  2. 求 $\lim\limits_{x\to 0}\dfrac{\sqrt{1+x}-\sqrt{1-x}}{x}$。（提示：分子有理化，或用 $(1+x)^{1/2}\approx 1+\dfrac{x}{2}$，答案 $1$。）
  3. 判断 $\lim\limits_{x\to 0}\dfrac{\sin x-x\cos x}{x^3}$ 中能否把 $\sin x$ 换成 $x$，并求极限。（提示：不能直接换，需把 $\sin x,\cos x$ 都展开到三阶，答案 $\dfrac{1}{3}$。）
