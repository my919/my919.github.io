第四章：微分方程

发表于 2026-08-30 更新于 2026-10-25 分类于 高等数学 本文字数： 6.5k 阅读时长 ≈ 6 分钟

第四章：微分方程

1、可分离变量方程

$$f_1(x)g_1(y)\,\mathrm{d}x + f_2(x)g_2(y)\,\mathrm{d}y = 0,$$

分离变量两边同除 $g_1(y)f_2(x) \neq 0$，得

$$\frac{f_1(x)}{f_2(x)}\,\mathrm{d}x + \frac{g_2(y)}{g_1(y)}\,\mathrm{d}y = 0,$$

然后两边积分即可。

2、齐次方程

$$y’ = f\left(\frac{y}{x}\right),$$

令 $u = \dfrac{y}{x}$，则 $y = ux$，$y’ = u + x\dfrac{\mathrm{d}u}{\mathrm{d}x}$，于是原方程可化为

$$u + x\frac{\mathrm{d}u}{\mathrm{d}x} = f(u) \Rightarrow \frac{\mathrm{d}u}{f(u) - u} = \frac{\mathrm{d}x}{x} \Rightarrow \int \frac{\mathrm{d}u}{f(u) - u} = \ln|x| + C.$$

求出积分后，再以 $\dfrac{y}{x}$ 代替 $u$，便得所给齐次方程的通解。

3、一阶线性方程

$$y’ + p(x)y = q(x),$$

求解公式：

$$y = \left[\int q(x)\mathrm{e}^{\int p(x)\,\mathrm{d}x}\,\mathrm{d}x + C\right]\mathrm{e}^{-\int p(x)\,\mathrm{d}x}.$$

4、伯努利方程

$$y’ + p(x)y = q(x)y^n,$$ 其中 $n \neq 0,1$

令 $z = y^{1-n}$，则方程化为

$$\frac{1}{1-n}\frac{\mathrm{d}z}{\mathrm{d}x} + p(x)z = q(x) \Rightarrow \frac{\mathrm{d}z}{\mathrm{d}x} + (1-n)p(x)z = (1-n)q(x),$$

变形后已是一阶线性方程，可直接带入公式。

5、全微分方程

$$M(x,y)\,\mathrm{d}x + N(x,y)\,\mathrm{d}y = 0 \text{ 为全微分方程} \Leftrightarrow \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}.$$

通解为

$$u(x,y) = \int_{x_0}^{x} M(x, y_0)\,\mathrm{d}x + \int_{y_0}^{y} N(x,y)\,\mathrm{d}y = C.$$

6、二阶常系数线性微分方程

$$y’’ + py’ + qy = 0,$$ 其中 $p,q$ 均为常数

特征方程：

$$\lambda^2 + p\lambda + q = 0,$$

（1）当 $\lambda_1, \lambda_2$ 为互异实根时，微分方程通解为 $y(x) = C_1\mathrm{e}^{\lambda_1 x} + C_2\mathrm{e}^{\lambda_2 x}$；

（2）当 $\lambda_{1,2}$ 相同时，通解为 $y(x) = (C_1 + C_2x)\mathrm{e}^{\lambda_1 x}$；

（3）当 $\lambda = \alpha \pm i\beta$（复根）时，通解为 $y(x) = \mathrm{e}^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$。

7、二阶常系数线性非齐次方程

$$y’’ + py’ + qy = f(x),$$ 其中 $p,q$ 均为常数

通解的求解步骤：

（1）求对应的齐次方程的通解 $Y(x)$；

（2）用待定系数法求出非齐次方程的特解 $y^*(x)$；

（3）写出非齐次方程的通解为 $y^*(x) + Y(x)$。

8、二阶常系数非齐次线性方程的非齐次项与特解的关系

$y’’ + py’ + qy = f(x)$ 特解 $y^*(x)$ 的形式
$f(x) = P_n(x)\mathrm{e}^{\alpha x}$

其中 $P_n(x)$ 为 $x$ 的 $n$ 次多项式		 $\alpha$ 不是特征根，$y^* = R_n(x)\mathrm{e}^{\alpha x}$，

$\alpha$ 是特征方程的单根，$y^* = xR_n(x)\mathrm{e}^{\alpha x}$

$\alpha$ 是特征方程的重根，$y^* = x^2R_n(x)\mathrm{e}^{\alpha x}$

（$R_n(x)$ 为 $n$ 次多项式的一般形式）
$f(x) = P_n(x)\mathrm{e}^{\alpha x}\sin\beta x$

或 $f(x) = P_n(x)\mathrm{e}^{\alpha x}\cos\beta x$

其中 $P_n(x)$ 为 $n$ 次多项式的一般形式		 $y^*(x) = x^k\mathrm{e}^{\alpha x}\left[Q_n(x)\cos\beta x + W_n(x)\sin\beta x\right]$

$\alpha \pm i\beta$ 不是特征根，$k = 0$

$\alpha \pm i\beta$ 是特征根，$k = 1$

（$Q_n(x), W_n(x)$ 为 $n$ 次多项式的一般形式）

9、可降阶微分方程

（1）方程 $y^{(n)} = f(x)$，直接求 $n$ 次积分得解。

（2）方程 $y’’ = f(x, y’)$ 的特点是不显含未知数 $y$。

令 $u = y’$，则微分方程 $y’’ = f(x, y’)$ 变为一阶微分方程 $u’ = f(x, u)$。

（3）方程 $y’’ = f(y, y’)$ 的特点是不显含自变量 $x$。

令 $u = y’$，则

$$\frac{\mathrm{d}^2y}{\mathrm{d}x^2} = \frac{\mathrm{d}u}{\mathrm{d}x} = \frac{\mathrm{d}u}{\mathrm{d}y}\frac{\mathrm{d}y}{\mathrm{d}x} = u\frac{\mathrm{d}u}{\mathrm{d}y},$$

则微分方程 $y’’ = f(y, y’)$ 变为 $uu’ = f(y, u)$，这是一个以 $y$ 为自变量，$u(y)$ 为未知函数的一阶微分方程。

10、二阶以上的常系数线性齐次微分方程

$n$ 阶常系数线性齐次微分方程的一般形式是：

$$y^{(n)} + p_1y^{(n-1)} + p_2y^{(n-2)} + \cdots + p_{n-1}y’ + p_ny = 0,$$ 其中 $p_i\,(i = 1,2,\cdots,n)$ 为常数。

相应的特征方程为

$$\lambda^n + p_1\lambda^{n-1} + p_2\lambda^{n-2} + \cdots + p_{n-1}\lambda + p_n = 0,$$

（1）若特征方程有 $n$ 个不同的实根 $\lambda_1, \lambda_2, \cdots, \lambda_n$，则方程通解

$$y = C_1\mathrm{e}^{\lambda_1 x} + C_2\mathrm{e}^{\lambda_2 x} + \cdots + C_n\mathrm{e}^{\lambda_n x}.$$

（2）若 $\lambda_0$ 为特征方程的 $k$ 重实根（$k \leq n$），则方程通解中含有

$$(C_1 + C_2x + \cdots + C_kx^{k-1})\mathrm{e}^{\lambda_0 x}.$$

（3）若 $\alpha \pm i\beta$ 为特征方程的 $k$ 重共轭复根（$2k \leq n$），则方程通解中含有

$$\mathrm{e}^{\alpha x}\left[(C_1 + C_2x + \cdots + C_kx^{k-1})\cos\beta x + (D_1 + D_2x + \cdots + D_kx^{k-1})\sin\beta x\right].$$

11、欧拉方程

形如 $x^2y’’ + axy’ + by = f(x)$ 的微分方程称为二阶欧拉方程，其中 $a,b$ 是常数。

求解方法：当 $x > 0$ 时，作变量代换 $x = \mathrm{e}^t$，则

$$\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}y}{\mathrm{d}t}\frac{\mathrm{d}t}{\mathrm{d}x} = \frac{1}{x}\frac{\mathrm{d}y}{\mathrm{d}t},$$

$$\frac{\mathrm{d}^2y}{\mathrm{d}x^2} = \frac{1}{x^2}\left(\frac{\mathrm{d}^2y}{\mathrm{d}t^2} - \frac{\mathrm{d}y}{\mathrm{d}t}\right).$$

原欧拉方程变为

$$\frac{\mathrm{d}^2y}{\mathrm{d}t^2} + (a-1)\frac{\mathrm{d}y}{\mathrm{d}t} + by = f(\mathrm{e}^t),$$

这是一个以 $t$ 为自变量，$y$ 为未知函数的二阶线性常系数微分方程。当 $x < 0$ 时，通过变量代换 $x = -\mathrm{e}^t$，可类似求解。

12、通解结构的直觉理解

  • 一阶线性方程的求解公式可由常数变易法得到：先求齐次方程 $y’+p(x)y=0$ 的解 $y=C\mathrm{e}^{-\int p(x)\mathrm{d}x}$，再把常数 $C$ 换成待定函数 $C(x)$ 代入非齐次方程确定它。公式中的因子 $\mathrm{e}^{\int p(x)\mathrm{d}x}$ 也叫积分因子——方程两边同乘它后，左端恰好是 $\big(y\,\mathrm{e}^{\int p(x)\mathrm{d}x}\big)’$，直接积分即得解。
  • 二阶常系数齐次方程的物理原型是弹簧振子/RLC 电路：$\lambda^2+p\lambda+q=0$ 的两个实根对应过阻尼与临界阻尼（指数衰减），复根 $\alpha\pm i\beta$ 对应欠阻尼（衰减振荡，$\alpha$ 控制衰减速度、$\beta$ 是振荡频率）。
  • 非齐次方程通解 = 齐次通解 + 非齐次特解，这与线性方程组 $Ax=b$ 的解结构完全一致——线性问题的共性。

13、典型例题

例1 求 $y’=\dfrac{y}{x}+1$ 的通解。

解：这是齐次方程，令 $u=\dfrac{y}{x}$，则 $y’=u+xu’$，代入得 $xu’=1$，即 $\mathrm{d}u=\dfrac{\mathrm{d}x}{x}$，积分得 $u=\ln|x|+C$，故通解为 $y=x(\ln|x|+C)$。

例2 求 $y’+y=\mathrm{e}^{-x}$ 的通解。

解：$p(x)=1,\ q(x)=\mathrm{e}^{-x}$，积分因子 $\mathrm{e}^{\int 1\mathrm{d}x}=\mathrm{e}^x$，套公式：

$$y=\left[\int \mathrm{e}^{-x}\cdot\mathrm{e}^{x}\,\mathrm{d}x+C\right]\mathrm{e}^{-x}=(x+C)\mathrm{e}^{-x}.$$

例3 求 $y’’-3y’+2y=0$ 的通解。

解：特征方程 $\lambda^2-3\lambda+2=0$，解得 $\lambda_1=1,\lambda_2=2$（互异实根），故通解为

$$y=C_1\mathrm{e}^{x}+C_2\mathrm{e}^{2x}.$$

例4 求 $y’’+y=2x$ 的一个特解，并写出通解。

解：齐次方程特征根 $\lambda=\pm i$，齐次通解 $Y=C_1\cos x+C_2\sin x$。非齐次项 $2x$ 中 $\alpha=0$ 不是特征根，设特解 $y^*=ax+b$，代入方程得 $ax+b=2x$，故 $a=2,b=0$，$y^*=2x$。通解为

$$y=C_1\cos x+C_2\sin x+2x.$$

例5 求 $y’’=x$ 的通解（可降阶型）。

解：直接逐次积分：$y’=\dfrac{x^2}{2}+C_1$，$y=\dfrac{x^3}{6}+C_1x+C_2$。此类 $y^{(n)}=f(x)$ 方程积分 $n$ 次即得含 $n$ 个任意常数的通解。

14、常见错误警示

  • 分离变量时两边同除 $g_1(y)f_2(x)$，会丢掉使除式为零的特解（如 $y’=y$ 分离变量会丢掉 $y\equiv 0$），最后要补回检验。
  • 一阶线性公式中 $\int p(x)\mathrm{d}x$ 只需取一个原函数（不带 $C$），多写常数反而出错。
  • 设特解时若 $\alpha$ 是特征根，必须乘 $x$（单根）或 $x^2$（重根），否则代入后矛盾。
  • 可降阶方程 $y’’=f(y,y’)$ 换元后 $y’’=u\dfrac{\mathrm{d}u}{\mathrm{d}y}$，自变量变成了 $y$，切勿再对 $x$ 求导。

15、本章小结

  • 一阶方程按”可分离 → 齐次 → 线性 → 伯努利 → 全微分”的顺序识别类型；
  • 二阶常系数齐次方程归结为解特征方程，三种根对应三种通解形态；
  • 非齐次特解用待定系数法，关键看 $\alpha$（或 $\alpha\pm i\beta$）是否为特征根；
  • 通解 = 齐次通解 + 特解，结构与线性代数中 $Ax=b$ 的解一致。

考研中微分方程常与几何（切线截距）、物理（冷却、衰变、振动）及积分（变限积分求导得方程）综合命题；由解反推方程（已知通解形式写特征方程）也是常见题型。欧拉方程为数一考点，核心是代换 $x=\mathrm{e}^t$ 化为常系数。

16、补充例题

例6（初值问题）求微分方程 $y’’+4y’+4y=0$ 满足 $y(0)=1,\ y’(0)=0$ 的特解.

解：特征方程 $r^2+4r+4=0$ 得重根 $r=-2$，通解 $y=(C_1+C_2x)e^{-2x}$。代入初值：$y(0)=C_1=1$；$y’=(C_2-2C_1-2C_2x)e^{-2x}$，$y’(0)=C_2-2C_1=0\Rightarrow C_2=2$。故特解为 $y=(1+2x)e^{-2x}$.

【注】重根情形第二解要乘 $x$；求导后代初值时先化简再代入可减少计算量。

练习题

  1. 求 $y’=2xy$ 的通解。（提示：分离变量，答案 $y=C\mathrm{e}^{x^2}$；注意 $y\equiv 0$ 含于其中。）
  2. 求 $y’’+2y’+y=0$ 的通解。（提示：$\lambda=-1$ 为二重根，答案 $y=(C_1+C_2x)\mathrm{e}^{-x}$。）
  3. 求 $y’’+4y=\sin 2x$ 特解的形式（不必求系数）。（提示：$\pm 2i$ 是特征根，设 $y^*=x(A\cos 2x+B\sin 2x)$。）
