1. 概念说明

入门篇完成了”训练一个回归模型”的最小闭环。本篇解决实战中的核心问题：

  • 分类：样本属于哪个类别（垃圾邮件、用户流失、图片识别）。
  • 聚类：无标签数据自动分组（用户分群、异常检测）。
  • 特征工程：决定模型上限的关键——特征清洗、编码、缩放、选择。
  • 模型评估：不能只看准确率（类别不均衡时失真），要看精准率/召回率/F1/AUC。
  • 过拟合：训练集好、测试集差，是机器学习第一敌人，用交叉验证与正则化对抗。

标准流程：数据加载 → EDA → 特征工程 → 划分数据集 → 交叉验证选模型 → 调参 → 评估 → 保存。

3.4 评估指标（不均衡类别必看）

指标 含义 场景
精准率 Precision 预测正例中真正例占比 误报代价高（反欺诈）
召回率 Recall 真正例中被找出占比 漏报代价高（癌症筛查）
F1 两者调和平均 综合平衡
AUC 排序能力（0.5 随机，1 完美） 模型总体区分度

阈值调整：precision_recall_curve 找最佳阈值，不盲目用 0.5。

10. 常见误用与陷阱

坑 现象 解法
数据泄漏：全量数据先 fit 标准化/目标编码/特征选择再划分 线下 AUC 0.95，上线暴跌；模型”偷看”了测试集统计 先 train_test_split，所有 fit 封进 Pipeline，CV 在折内拟合
类别不平衡只看 accuracy 正类 8% 时全猜 0 也有 92% 正确率，模型实际没学会 看 Precision/Recall/F1/ROC-AUC 与 PR 曲线
SMOTE 在划分前做、或在验证折上重采样 用合成样本验证，指标虚高 用 imblearn.pipeline.Pipeline，重采样只作用于训练折
小类别未分层划分 训练/测试集类别比例漂移，评估不稳 train_test_split(..., stratify=y)，CV 用 StratifiedKFold
特征未标准化就上正则化/距离模型 LR/SVM/KMeans 被”收入”这类大尺度特征支配 StandardScaler（树模型不需要，可跳过）
死守 0.5 阈值 / 把 predict 当概率 漏报代价高的业务召回不足 predict_proba + precision_recall_curve 按业务成本定阈值
线上预处理与训练不一致 编码顺序、缺失填充逻辑漂移，预测全偏 Pipeline 整体 joblib.dump，线上加载同一对象
