4. 主成分分析（PCA）

4.1 原理

降维：把高维数据投影到”方差最大”的几个正交方向上，保留主要信息、去掉冗余。

训练算法：SVD/特征分解（一次计算，无迭代）。

保留信息量：前k个特征值之和 / 全部特征值之和，一般 ≥ 0.95 说明降维不丢信息。

7. 常见误用与陷阱

坑 现象 解法
K-Means 不标准化 金额(上千)碾压次数(个位)，簇实际只按一个特征切分 聚类前 StandardScaler；必要时对数变换
肘部法则误判 inertia 曲线平滑无拐点，硬选一个 K 轮廓系数/间隙统计交叉验证，结合业务簇数
DBSCAN 的 eps 拍脑袋 eps 稍大全并成一簇，稍小全标噪声 画 k-距离曲线取拐点，min_samples 随维度调
对独热/高维稀疏特征直接用欧氏距离 距离全部趋同，KMeans/DBSCAN 失效 用余弦/K-Modes，或先 PCA 降维再聚类
把簇标签当稳定 ID 每次重训标签编号随机轮换，运营策略错位 标签与簇画像做映射，按中心特征而非编号引用
PCA 在每份数据上重复 fit 训练/测试主成分方向不一致，特征对不上 只在训练集 fit，其余只 transform；PCA 前先标准化
噪声点直接当违规处置 DBSCAN 误判导致正常用户被处罚 噪声只作线索，接人工复核与申诉闭环
