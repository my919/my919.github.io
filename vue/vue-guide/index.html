1. 概念说明

Vue 3 是渐进式前端框架：核心是声明式渲染——你声明”界面 = f(状态)”，状态变化自动更新视图。渐进式的含义是：可以从一个 <script> 引入的页面级脚本，一路扩展到路由、状态、SSR、工程化的完整应用，接入范围由项目需要决定。

四个核心概念：

  • 响应式（Reactivity）：基于 Proxy 拦截对象读写，依赖收集 + 派发更新。
  • 组件（Component）：UI 复用单元，props 进、事件出。
  • 模板（Template）：声明式描述 DOM，指令（v-if / v-for / v-model / @click）把状态与视图绑起来。
  • 生命周期：组件从创建、挂载、更新到卸载的钩子序列，用来放置副作用（请求、定时器、清理）。
  • Composition API：按逻辑组织代码（setup + ref/reactive/computed/watch），替代 Options API 的按选项组织——细节见进阶篇。
  • 虚拟 DOM：先算差异再更新真实 DOM，批量高效。

3.2 响应式

ref 包基本类型与对象（.value 访问）；reactive 包对象（直接访问属性，但解构会丢响应式）。新代码统一用 ref，细节与 computed / watch 的完整用法见进阶篇「响应式深入」。

3.3 组件

组件是 UI 复用单元：props 进、事件出。父子通信用 props/emit，跨层用 provide/inject，跨组件共享用 Pinia；组件通信的完整方式与示例见进阶篇。

3.4 模板

模板是声明式渲染层，常用指令：

指令 作用
{{ }} 插值表达式（自动解包 ref）
v-if / v-else 条件渲染（条件不成立不渲染节点）
v-for 列表渲染，必须配稳定唯一的 :key
v-model 表单双向绑定（组件上 = modelValue + update 事件）
@click / v-on 事件绑定
:prop / v-bind 属性绑定

v-if 与 v-for 不要写在同一元素上（3.x 中 v-if 先执行，访问不到循环变量），外层 template v-for、内层 v-if 分开写。

3.5 生命周期（setup 版本）

常用钩子：onBeforeMount / onMounted（挂载）、onBeforeUpdate / onUpdated（更新）、onBeforeUnmount / onUnmounted（卸载）。副作用必须有对应的清理，这是组件生命周期最容易出错的地方。
