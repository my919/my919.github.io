1. 概念说明

Vue 3 是渐进式前端框架：核心是声明式渲染——你声明”界面 = f(状态)”，状态变化自动更新视图。

核心概念：

  • 响应式（Reactivity）：基于 Proxy 拦截对象读写，依赖收集 + 派发更新。
  • 组件（Component）：UI 复用单元，props 进、事件出。
  • Composition API：按逻辑组织代码（setup + ref/reactive/computed/watch），替代 Options API 的按选项组织。
  • 虚拟 DOM：先算差异再更新真实 DOM，批量高效。

13. 常见误用与陷阱

坑 现象/后果 解法
在子组件里直接修改 props 控制台警告，父组件数据不会变 emit 通知父级修改；表单场景用 v-model
ref 忘写 .value 逻辑「看着对」但视图不更新 JS 中 ref 一律 .value；模板中才自动解包
解构 props / reactive 响应式断开，父更新子无感 toRefs()，或始终通过 props.xxx 访问
v-if 与 v-for 用在同一元素 3.x 中 v-if 先执行，访问 item 直接报错 外层 template v-for、内层 v-if 分开写
v-for 用 index 当 key 删除/过滤后 DOM 复用错乱、输入框串行 用唯一业务 id 作 key
路由同组件参数变化不刷新 /user/1 → /user/2 页面数据不变 watch(() => route.params.id) 重新取数
定时器/事件监听不清理 组件卸载后仍执行，内存泄漏 onBeforeUnmount 里 clearInterval / 解绑
localStorage 存对象未序列化 读出来是 "[object Object]" 存时 JSON.stringify，取时 JSON.parse
