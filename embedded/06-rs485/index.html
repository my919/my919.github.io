第六章：RS485

发表于 2026-05-01 更新于 2026-10-25 分类于 嵌入式 本文字数： 3.5k 阅读时长 ≈ 3 分钟

第六章：RS485

概念基础

  1. RS485（TIA/EIA-485） 是差分电气标准：用 A/B 两线电压差表示信号，抗共模干扰强、可达上千米，是工业现场最常用的物理层。
  2. 总线型多机：一条双绞线手拉手（daisy-chain）挂多个节点，配合地址协议实现多机组网；总线两端各接 120Ω 终端电阻。
  3. 半双工：两线制同一时刻只能一个方向发送，收发器需 DE/RE 引脚切换方向。
  4. 只管电气不管语义：RS485 只解决「电信号怎么传」，上层要跑 Modbus RTU 等主从协议才能完成有效通信。
  5. 与 UART 的关系：MCU 的 UART 产生字节流，经 MAX485/SN65HVD 收发器转成差分信号——UART 管逻辑、485 管物理。

一、拓扑

  • 半双工：同一时刻只能一个方向发送；需 DE/RE 引脚控制收发器方向。
  • 共模范围：约 -7V ~ +12V，适合工业现场。

差分电平怎么判定

接收端只看压差，不参考绝对地——所以电机启停、地电位浮动产生的共模噪声被天然抵消。这是 485 能在车间拉几百米的根本原因。

关键电气参数

参数 值 说明
最大节点数 32（标准负载）/ 128、256（分数负载收发器） 由收发器输入阻抗决定
最远距离 ~1200 m（低速率） 速率与距离反相关
最高速率 10 Mbps（短距离） 典型应用 ≤ 115200 bps
共模范围 -7V ~ +12V 超范围收发器损坏

速率与距离的经验组合：100 kbps 下约 1200 m；1 Mbps 下约 120 m；10 Mbps 仅限十几米。

二、UART + RS485 收发器

MCU 第四章：UART 接 MAX485/SN65HVD 等：

发送前切换 DE；切换后需等待收发器稳定再发首字节，避免毛刺。

STM32 方向切换的正确姿势

三个经典翻车点全在这段代码里：

  1. DE 拉高后立刻发数据 → 首字节丢失或畸变，需数 µs 稳定时间。
  2. 发完 TXE 就拉低 DE → 最后一字节被截断，必须等 TC。
  3. 忘记拉回接收 → 总线一直被自己占用，别的主站应答全被吃掉。

部分 MCU（如 STM32F3/F7/H7）UART 自带 RS485 硬件流控模式，可直接驱动 DE 引脚并自动处理时序，能省掉上述手工操作。

三、与 Modbus RTU

第一章：Modbus RTU 在 RS485 上最常见：主站轮询、从站地址 1~247、CRC16 帧尾。
与 第三章：Modbus ASCII 比，RTU 更紧凑、工业现场更常用。

RS485 本身不限制上层协议，现场还能见到：

  • Modbus RTU：绝对主流。
  • Profibus DP：西门子系 PLC 现场总线，同样跑在 485 电气层上。
  • 自定义主从协议：小型设备集联常自定义「地址 + 长度 + 数据 + 校验」帧。
  • DMX512：舞台灯光控制，也是 485 物理层。

四、对比 RS232

项目 RS232 RS485
信号 单端 差分
距离 短 长
节点数 点对点为主 多机总线
双工 全双工常见 半双工为主

补充几个工程维度：

项目 RS232 RS485
抗干扰 弱（单端对地） 强（差分 + 共模抑制）
电平摆幅 ±5~±15V 差分 200mV 门限
布线成本 每设备一对线 一根总线挂全部
典型速率 ≤115200 100k~10M（视距离）
连接器 DB9 标准化 无标准，常用端子排

还有全双工 485（4 线制）：两对差分线分别收发，等价于差分版 RS232，常见于长距离点对点，但失去了总线多机能力。

五、布线注意

  • 双绞线、屏蔽层单端接地（现场依规范）。
  • 终端电阻 120Ω 仅在总线两端；中间节点不加。
  • GND 参考：虽为差分，仍建议可靠参考地，避免共模超范围。
  • ESD 与浪涌：户外/电机旁加保护器件。

终端电阻与偏置电阻

  • 为什么 120Ω：匹配双绞线特征阻抗，吸收线末反射。总线两端各一个，等效 60Ω 负载——这也是驱动器输出能力按 60Ω 设计的原因。
  • 失效偏置（Fail-safe bias）：总线空闲无驱动时，A/B 压差接近 0，接收端输出不确定，可能被误判为起始位而产生幽灵字节。解法：总线上（通常主站侧）加一对上拉/下拉偏置电阻（如 560Ω~1kΩ），强制空闲时 A>B；现代收发器（如 SN65HVD 系列）内置失效保护，输出固定为高，可省掉外部偏置。
  • 中间节点 Stub 越短越好：分支引线超过几十厘米会形成反射点；星型拓扑是 485 大忌，必须用集线器。

现场施工要点

项目 做法
线缆 屏蔽双绞线（RVSP 2×0.5 常见），与动力线分开走槽
屏蔽层 单点接地（通常控制柜侧），两端接地会引入地环流
过电压 户外进线端加 TVS / 气体放电管；雷击多发区用隔离收发器
节点地址 上电前拨码/写地址并做台账，避免两个从站同地址互相抢答
测试 断电测总线 A-B 电阻，应约 60Ω（两个 120Ω 并联），远大于说明少接终端，接近 0 说明短路

六、调试与排查

  • USB-485 适配器搭车监听：旁路挂在总线上只收不发，记录主从全部流量。
  • 示波器看差分：探头分别接 A、B 用 MATH 相减，或差分探头直接看；重点看摆幅、反射台阶、共模漂移。
  • 逐节点排除法：总线异常时按手拉手顺序逐个断电，定位拉垮总线的故障节点（收发器击穿会把整条总线钳死）。
  • 万用表静态检查：断电测 A-B 间电阻 ≈60Ω；测各节点 A/B 对地电压，异常节点常有明显偏移。

七、隔离与失效保护设计

工业级节点的常见加固手段：

  • 隔离收发器：ADM2483、ISOW7841 等把 UART 侧与总线侧电气隔离（磁耦/电容隔离 + 隔离电源），阻断地环流与高压串入，变频器、电力柜场景几乎必选。
  • TVS + 自恢复保险丝：A/B 线上双向 TVS（SMBJ12CA 类）吸收浪涌，PPTC 限制持续故障电流。
  • 共模电感：端口侧串共模扼流圈抑制高频干扰，常与 TVS 组成 EMC 三件套。
  • 失效保护收发器：SN65HVD 系列等在总线开路/短路/空闲时输出固定逻辑，替代外部偏置电阻。
  • 上电静默：MCU 复位期间 DE 引脚电平不确定，可能误发数据污染总线——DE 加上下拉电阻固定初态，或选上电三态的收发器。

八、485 集线器与拓扑扩展

当现场布线确实无法手拉手（多楼层、多方向出线），**RS485 集线器（Hub）**是合规解法：每个端口是独立隔离的收发段，主站侧一条线接入，下行分出多条总线，同时实现：

  • 星型布线的物理便利 + 每段独立的终端电阻配置；
  • 故障段自动隔离，不影响其他分支；
  • 级联延长距离，突破单段 1200 m 限制。

注意 Hub 只做电气转发，地址冲突仍需靠上层协议（如 Modbus 地址规划）解决；各级延迟叠加也要算进主站超时时间。

本章小结

要点 结论
电气 差分（A/B） 传输，共模约 -7V~+12V，抗干扰强、距离长
拓扑 总线型手拉手，两端各接 120Ω 终端电阻，中间节点不加
双工 两线制半双工，发送前切 DE，切后等收发器稳定
组合 UART 控制器 + 485 收发器（MAX485/SN65HVD）
上层协议 最常见搭配 Modbus RTU（主站轮询、从站地址 1~247）
