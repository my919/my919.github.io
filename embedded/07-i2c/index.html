第七章：I2C

发表于 2026-05-01 更新于 2026-10-25 分类于 嵌入式 本文字数： 3.5k 阅读时长 ≈ 3 分钟

第七章：I2C

概念基础

  1. I2C（Inter-Integrated Circuit）是 Philips 发明的两线同步总线：SCL 时钟 + SDA 数据，是板级互联传感器/存储器等外设的事实标准。
  2. 地址寻址多从：每个从设备有 7 位地址（0x00~0x7F），主设备以地址帧寻址——两根线即可挂多个器件，扩展外设几乎不加线。
  3. 开漏 + 上拉：SDA/SCL 均为开漏输出加上拉电阻，天然支持多主仲裁与时钟同步，也决定了速率上限（100k/400k/1M/3.4M）。
  4. 协议机制清晰：START/STOP 条件界定传输，逐字节 ACK/NACK 确认；读操作用重复 START 切换方向。
  5. 取舍：线最少、成本低，EEPROM/RTC/IMU/OLED 全支持；但速率不如 SPI，上拉取值需按总线电容与速率权衡。

一、信号与起始/停止

  • 空闲：SDA、SCL 均为高（靠上拉电阻）。
  • START：SCL 高时 SDA 下降沿。
  • STOP：SCL 高时 SDA 上升沿。
  • 数据位：SCL 低时 SDA 变化，SCL 高时采样。

一次完整写传输的波形语义

几个容易忽略的细节：

  • ACK 由接收方发出：第 9 个时钟，发送方释放 SDA（保持高），接收方拉低表示 ACK。
  • NACK 不一定是错误：主设备读最后一个字节时故意回 NACK，告诉从机「别再发了」，然后发 STOP。
  • 时钟延展（Clock Stretching）：从机来不及处理时可在字节间把 SCL 拉低不放，主机必须等待——主机代码若不支持检测 SCL 实际电平，与慢速从机通信会莫名失败。
  • 开漏的意义：任何设备都能拉低总线，没有人能推高——这是多主仲裁与 ACK 机制的电气基础。

二、7 位地址帧（写）

读操作：写寄存器指针 → 重复 START → 读地址 + 读数据 + NACK + STOP。

地址字节的两套记法

地址字节 = 7bit 地址 << 1 | R/W，文档有两种写法，极易混淆：

记法 EEPROM 24C02 示例
7 位地址 0x50

三、速率模式

模式 速率
Standard 100 kHz
Fast 400 kHz
Fast Mode Plus 1 MHz
High Speed 3.4 MHz（较少用）

上拉电阻：常见 2.2k~10k（3.3V、总线电容与速率相关）；长电缆或多设备需降低电容、可能用 I2C 缓冲器/扩展器。

上拉电阻怎么选

RC 上升时间是核心约束：SCL/SDA 靠上拉电阻对总线电容充电，规范要求 100 kHz 下上升沿 ≤ 1000 ns、400 kHz 下 ≤ 300 ns。

场景 推荐上拉
板内短走线、1~2 个器件 4.7kΩ ~ 10kΩ（省电）
多器件、400 kHz 2.2kΩ ~ 3.3kΩ
长排线 / 高电容 1kΩ ~ 2.2kΩ，或改用总线缓冲器（PCA9515）

示波器看 SCL 波形：上升沿呈明显圆弧说明上拉偏弱或电容过大；正常应接近方波。

四、典型设备

  • EEPROM（24Cxx）、RTC（DS3231）、IMU、OLED 小屏、PMIC、GPIO 扩展（PCF8574）。
  • 同一地址冲突：部分芯片有 ADDR 引脚改地址；否则需不同总线（I2C mux）。

地址冲突的处理手段：

  1. ADDR 引脚：多数传感器留 1~3 个地址引脚，可改低位地址。
  2. I2C 多路复用器：TCA9548A 把一路总线分成 8 路，先选通道再通信，可挂 8 个同地址设备。
  3. 第二路 I2C 外设：MCU 有多个 I2C 控制器时分开挂。
  4. 软件模拟（bit-bang）：GPIO 模拟时序，灵活但占 CPU，适合调试或非关键低速设备。

五、调试与排障

  • 逻辑分析仪解码：廉价的 8 通道逻辑分析仪软件（如 PulseView/sigrok）自带 I2C 解码，能直接显示地址、ACK/NACK、数据，定位「哪一步没 ACK」一目了然。
  • 地址扫描：主机遍历 0x08~0x77 发地址帧看哪个 ACK，10 秒确认设备是否在线：

常见问题清单

现象 可能原因
地址帧就 NACK 地址没左移/右移错；设备未上电；SDA/SCL 接反
总线锁死（SDA 恒低） 上次通信中途复位，从机挂在传输中；主机动打 9 个 SCL 脉冲可解锁
读回全 0xFF 上拉缺失或设备根本没接，总线浮空为高

多主互相干扰 仲裁逻辑未实现；双主系统先确认双方都支持多主

第九章：CAN 总线：帧结构、多主仲裁与 CAN FD 用于车载/工业现场总线，抗干扰与仲裁不同于 I2C。

选型速记：板内低速多外设选 I2C；板内高速单外设选 SPI；出板/远距离选 UART+收发器或现场总线。

七、协议家族的延伸

  • SMBus：I2C 的「严格版」子集（PC 主板电源管理、智能电池），限定电平、超时与包格式（PEC 校验）。
  • PMBus：SMBus 之上针对电源管理 IC 的命令集，服务器电源监控的标准。
  • I3C：MIPI 推出的现代继任者，推挽为主、速率 12.5 MHz 起步，支持带内中断与热插拔，传感器领域逐步替代 I2C。
  • TWI：Atmel/Microchip 的 I2C 兼容叫法（规避商标），协议一致。

本章小结

要点 结论
总线 SCL+SDA 两线同步总线，开漏 + 上拉，支持多主多从
寻址 7 位地址帧寻址，读方向用重复 START 切换
握手 每字节 ACK/NACK 确认；START/STOP 界定传输
速率 标准 100k / 快速 400k / FM+ 1M / HS 3.4M
实务 上拉 2.2k~10k 按速率与电容配置；地址冲突用 ADDR 引脚或 I2C mux
