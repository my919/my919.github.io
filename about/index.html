一、语言基础（1–8）

目标：至少精通一门主力语言，其余达到「能读能写」。语言是所有后续阶段的载体。

前置要求：计算机基础（数据结构、操作系统、网络）。

关键知识点：

  • 内存模型与 GC（Java 分代回收 / Go 三色标记 / Rust 所有权）
  • 并发原语（线程池 / goroutine / async-await）
  • 类型系统（泛型、Trait、Protocol）
  • 标准库与生态（包管理、构建工具）
  • 单元测试与基准测试
  • 移动端与跨端：原生性能、跨端方案取舍
  • 可访问性：WCAG 与语义化

二、工程框架（9–12）

目标：掌握主力技术栈的企业级框架，理解框架背后的设计决策，而非只会 CRUD。

前置要求：阶段一。

关键知识点：

  • 依赖注入与控制反转
  • 自动装配 / 启动流程 / 扩展点
  • 配置管理与 Profile
  • 安全集成（认证授权）
  • 网络编程模型（Reactor 模式）
  • 多语言框架选型方法论

三、数据与存储（13–19）

目标：按场景选对存储，写对索引与事务，处理缓存与消息的一致性问题。

前置要求：阶段一、二。

关键知识点：

  • 事务隔离级别与 MVCC
  • B+ 树 / LSM 树 / 倒排索引的原理与取舍
  • 缓存三大问题（穿透 / 击穿 / 雪崩）与一致性方案
  • 消息可靠投递：发送端确认、Broker 持久化、消费端幂等
  • 分库分表与数据迁移

四、服务与接口（20–21）

目标：从「一个服务」到「一组服务」：拆分、通信、流量治理、故障隔离。

前置要求：阶段三。

关键知识点：

  • 服务拆分原则（按业务能力 / 团队拓扑）
  • 接口设计：幂等、版本化、错误码规范
  • 网关职责：路由、鉴权、限流、熔断
  • 通信模式：同步 RPC vs 异步事件
  • 高可用：超时、重试、隔离、降级
  • 长连接网关与实时推送
  • 协议选型：REST / gRPC / GraphQL 与网关治理
  • RPC 序列化与服务间通信契约

    里程碑：绘制当前系统的服务拓扑图，标注每条链路的超时/重试/降级策略。
