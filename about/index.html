阶段详解

一、语言基础（1–9）

目标：至少精通一门主力语言，其余达到「能读能写」。语言是所有后续阶段的载体。

前置要求：计算机基础（数据结构、操作系统、网络）。

关键知识点：

  • 内存模型与 GC（Java 分代回收 / Go 三色标记 / Rust 所有权）
  • 并发原语（线程池 / goroutine / async-await）
  • 类型系统（泛型、Trait、Protocol）
  • 标准库与生态（包管理、构建工具）
  • 单元测试与基准测试

已收录文章：

  • Java：核心篇 · 进阶篇 · JVM · GC 日志分析 · CPU 分析 · 内存分析
  • Golang：Go 实战指南
  • Python：基础 · 进阶 · FastAPI · Django
  • Rust：Rust 指南 · Web 系统
  • TypeScript：进阶指南
  • Node.js：全栈指南 · NestJS · 轻量 API
  • Vue：基础 · 进阶 · Vue3 栈
  • React：全栈指南
  • WASM：指南

里程碑：用主力语言完成一个含并发处理的 CLI 工具 + 一个 Web 服务；能看懂该语言主流框架源码中的惯用法。

二、工程框架（10–14）

目标：掌握主力技术栈的企业级框架，理解框架背后的设计决策，而非只会 CRUD。

前置要求：阶段一。

关键知识点：

  • 依赖注入与控制反转
  • 自动装配 / 启动流程 / 扩展点
  • 配置管理与 Profile
  • 安全集成（认证授权）
  • 网络编程模型（Reactor 模式）
  • 多语言框架选型方法论

已收录文章：

  • Spring Boot：指南 · 安全 · Spring 全栈 · 微服务
  • Spring Cloud Alibaba：总览 · 网关与 Sentinel · 限流
  • Netty：指南 · 协议设计
  • 多语言对比：Go 微服务 · Python 数据 AI · 博客系统
  • 前端工程化：指南

里程碑：用 Spring Boot / Go 独立搭建一个带鉴权、日志、限流的生产级服务骨架。

三、数据与存储（15–22）

目标：按场景选对存储，写对索引与事务，处理缓存与消息的一致性问题。

前置要求：阶段一、二。

关键知识点：

  • 事务隔离级别与 MVCC
  • B+ 树 / LSM 树 / 倒排索引的原理与取舍
  • 缓存三大问题（穿透 / 击穿 / 雪崩）与一致性方案
  • 消息可靠投递：发送端确认、Broker 持久化、消费端幂等
  • 分库分表与数据迁移
  • RPC 序列化与服务间通信契约

已收录文章：

  • Database：设计规范 · SQL 业务建模 · SQL 建模进阶 · 备份恢复 · 慢查询治理
  • MySQL：指南
  • Redis：基础 · 进阶 · 集群 · 缓存架构 · 故障排查
  • Search：引擎指南
  • MQ：可靠性 · 可靠性终版 · Kafka · RabbitMQ
  • GraphQL：指南
  • gRPC：指南

里程碑：设计一个「MySQL + Redis + MQ」组合的下单链路，说清每一步的失败场景与补偿手段。

四、服务治理（23–29）

目标：从「一个服务」到「一组服务」：拆分、通信、流量治理、故障隔离。

前置要求：阶段三。

关键知识点：

  • 服务拆分原则（按业务能力 / 团队拓扑）
  • 接口设计：幂等、版本化、错误码规范
  • 网关职责：路由、鉴权、限流、熔断
  • 通信模式：同步 RPC vs 异步事件
  • 高可用：超时、重试、隔离、降级
  • 长连接网关与实时推送

已收录文章：

  • Service：设计 · 高可用 · API 性能 · 定时任务 · Excel 导入导出 · OnCall 排障
  • Microservice：指南 · 实践
  • Service Mesh：指南
  • Realtime：指南

里程碑：绘制当前系统的服务拓扑图，标注每条链路的超时/重试/降级策略。

五、系统架构（30–35）

目标：具备架构视角：权衡取舍、容量估算、领域建模、分布式一致性。

前置要求：阶段二、三、四。

关键知识点：

  • 架构演进：单体 → 模块化单体 → 微服务 → Cell-Based
  • C4 模型与 ADR 决策记录
  • 经典系统设计：短链、秒杀、Feed 流、IM
  • DDD：限界上下文、聚合、防腐层
  • 分布式：CAP/BASE、Raft/Paxos、分布式事务（2PC/TCC/Saga）
  • 安全架构：OAuth 2.0 + OIDC 现代协议栈

已收录文章：

  • Architecture：架构设计实战 · 架构风格全景 · OAuth 2.0 + OIDC 2026 协议栈
  • SysDesign：系统设计指南
  • Identity（相关）：身份认证 2026

里程碑：独立完成一个新系统的架构设计文档（含 C4 图、容量估算、ADR 三篇以上）。

六、基础设施（36–42）

目标：打通从操作系统到云平台的基础层，理解应用之下发生的一切。

前置要求：阶段一。

关键知识点：

  • Linux：进程、文件描述符、性能工具链（top/vmstat/strace）
  • 网络：TCP 握手挥手、拥塞控制、TLS 握手、DNS
  • Nginx：反向代理、负载均衡策略、限流模块
  • 容器：namespace/cgroup、镜像分层、多阶段构建
  • K8s：声明式 API、控制器模式、调度、CNI/CSI
  • IaC 与云服务计费模型

已收录文章：

  • Linux：指南 · DevOps · 常用命令
  • Network：指南 · 抓包排错 · HTTPS 证书
  • Nginx：指南 · 负载均衡与高可用
  • Kubernetes：指南 · eBPF：Cilium · Tetragon · 持续剖析
  • IaC：指南

里程碑：用 Terraform + K8s 部署一个完整应用（含 Ingress、证书、HPA、监控）。

七、DevOps 与质量（43–52）

目标：让交付又快又稳：自动化流水线、分层质量保障、持续重构。

前置要求：阶段六（至少 Docker）。

关键知识点：

  • CI/CD 流水线设计与制品晋级
  • 测试金字塔：单元 / 集成 / 全链路 / 容量
  • 性能测试：建模、施压、拐点分析
  • 混沌工程：稳态假设、爆炸半径控制
  • 技术债管理：识别、量化、偿还节奏
  • 遗留系统现代化：绞杀者模式、防腐层

已收录文章：

  • Test：测试指南 · 全链路测试 · 容量规划 · 性能测试实战
  • Performance：指南
  • Standards：编码规范 · 安全编码
  • TechDebt：指南
  • Modernization：指南

里程碑：为主力项目搭建从提交到生产的全自动流水线（含自动化测试门禁）。

八、可观测（53–57）

目标：系统出问题时 5 分钟内定位；用数据驱动稳定性与成本决策。

前置要求：阶段六、七。

关键知识点：

  • 三支柱：Metrics / Logging / Tracing
  • OpenTelemetry 统一遥测与采样策略
  • 告警规则设计：分级、降噪、值班联动
  • SLO / 错误预算 / 事后复盘（Postmortem）
  • FinOps：成本可视化与优化闭环
  • Feature Flag：灰度、实验、秒级回滚

已收录文章：

  • Monitor：总览 · 日志与链路 · SkyWalking · 告警规则 · 日志分析实战
  • Observability：指南
  • SRE：指南
  • FinOps：指南
  • Feature Flag：指南

里程碑：为核心服务定义 SLO 并建立看板；完成一次完整的告警收敛专项。

九、安全与身份（58–61）

目标：建立纵深防御视角：从 Web 漏洞到身份协议再到合规审计。

前置要求：阶段四（API / 网关基础）。

关键知识点：

  • OWASP Top 10 与安全编码
  • 认证 vs 授权；OAuth 2.1 / OIDC / Passkey
  • Zero Trust：持续验证、最小权限
  • 合规框架：等保、GDPR、数据分类分级
  • 可访问性：WCAG 与语义化

已收录文章：

  • Security：Web 安全指南
  • Identity：身份认证与授权 2026
  • A11y：指南
  • 相关：OAuth 2.0 + OIDC 2026 协议栈 · 安全编码

里程碑：完成一次自家系统的安全自查（对照 OWASP 清单）并修复全部高危项。

十、AI 与数据（62–68）

目标：既懂传统 ML，也掌握 LLM 应用工程（RAG / Agent / 评测），并了解多媒体技术栈。

前置要求：阶段一（Python 优先）、三（数据存储）。

关键知识点：

  • 机器学习工作流：特征 → 训练 → 评估 → 部署
  • 深度学习基础：网络结构、反向传播、训练技巧
  • LLM 应用：Prompt、RAG、Agent、Function Calling
  • AI 工程化：评测集、可观测、成本控制
  • 音视频：编码、转码、直播协议、低延迟

已收录文章：

  • AI：总览 · 实践 · LLM 应用 · 监督学习 · 无监督 · 神经网络训练
  • 数据平台：湖仓一体：Iceberg · Flink · Trino
  • AI Engineering：指南 · 向量数据库：Milvus · Qdrant · pgvector
  • Blockchain：智能合约 · DApp 全栈 · Layer 2 · 去中心化存储 · DID/SIWE · 跨链桥 · 发币实战 · 代币经济 · DAO 治理 · 元宇宙开发
  • Video：处理 · 直播
  • Mobile：指南

里程碑：上线一个带 RAG 的问答应用，并建立评测基线（准确率 / 延迟 / 成本）。

十一、平台与协作（69–79）

目标：从工程师到平台/团队视角：打造内部平台、提升开发者体验、管理项目与协作。

前置要求：阶段六、七、八。

关键知识点：

  • 平台工程：IDP、黄金路径、自助化
  • DX：反馈环时长、脚手架、文档即代码
  • Edge：边缘函数与全球分发
  • SaaS：多租户隔离、订阅计费
  • 管理：DORA 度量、估算、风险
  • 效率工具：CLI 生产力、Git 工作流

已收录文章：

  • Platform：指南
