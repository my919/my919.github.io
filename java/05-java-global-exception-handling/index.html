第五章：Java 全局异常处理：@RestControllerAdvice 与统一 Result

发表于 2026-05-04 更新于 2026-10-25 分类于 Java 本文字数： 7.8k 阅读时长 ≈ 7 分钟

第五章：Java 全局异常处理：@RestControllerAdvice 与统一 Result

概念基础

  1. 为什么需要全局异常处理：没有统一捕获时，try-catch 散落在各 Controller，重复代码多，且异常返回格式五花八门。
  2. 核心机制：@RestControllerAdvice + @ExceptionHandler 由 Spring 拦截 Controller 抛出的异常，集中转换为统一响应。
  3. 统一返回体：正常与异常响应都输出 Result<T> JSON（code / msg / data），前端只需处理一种结构。
  4. 异常分层：业务异常（BusinessException，业务代码主动抛出、带业务码）与系统异常（Exception 兜底、记日志）分开处理。
  5. HTTP 与业务码各司其职：协议层语义用 HTTP 状态码（400/405/500），业务语义用 Result.code（如 409/429）。

统一 Result<T> JSON 与 @RestControllerAdvice 全局捕获，避免 Controller 里散落 try-catch。本文给出完整 Handler 源码（通用模板）。

springboot 仓库落地（HTTP 状态码映射、与校验/枚举配合）见 第八章：SpringBoot 统一返回体与全局异常——以仓库代码为准，本文作 Java 层参考。

二、错误码规范与异常体系

错误码规范：团队内定一套分段编码，前端/监控据此定位模块：

段位 区间 含义
通用 200 / 400 / 401 / 403 / 404 / 405 / 429 / 500 与 HTTP 语义对齐
用户模块 1001-1999 如 1001=用户名已存在、1002=密码错误
订单模块 2001-2999 如 2001=库存不足、2002=订单状态冲突
支付模块 3001-3999 如 3001=余额不足

五、ProblemDetail（RFC 7807）

Spring Boot 3 / Spring 6 内建支持 RFC 7807 问题详情（application/problem+json），与自定义 Result 可并存——对外开放 API 用 ProblemDetail 更贴合国际标准：

ErrorResponseException 子类（如 MethodArgumentNotValidException 在 Spring 6 中）已实现 ErrorResponse 接口，默认即可输出 ProblemDetail；设置 spring.mvc.problemdetails.enabled=true 后框架级异常也走该格式。

六、日志脱敏

异常日志常含手机号、身份证、token、订单地址等敏感字段，落盘前必须脱敏：

进阶方案：Logback/Log4j2 自定义 Converter/Pattern 全局脱敏，配合 MDC 注入 traceId 串联请求链路；密码、密钥字段永不出现在任何级别日志——DTO 的 toString()（含 Lombok @Data）要排除。

七、设计要点

项 建议
HTTP vs code 协议层用 HTTP 状态；业务语义用 Result.code（可 409/429）
不要吞异常 Exception 处理器打日志，生产勿向前端暴露堆栈
403/401 BusinessException(401/403, ...) 并在 Handler 中映射 HTTP 状态
错误码分段 按模块分段编码，监控据此聚合告警
ProblemDetail 对外 API 可用 RFC 7807；对内 Result 足够
日志脱敏 手机号/邮箱/证件打码，密码密钥永不落日志

本章小结

要点 结论
统一出口 @RestControllerAdvice 集中捕获异常，Controller 层零 try-catch
业务异常 BusinessException(code, msg) 主动抛出，Handler 按业务码映射 HTTP 状态
错误码规范 按模块分段编码；模块异常继承基类自带默认码
参数校验 配合 @Valid / @Validated，统一捕获校验异常并返回 400 与字段错误信息
兜底策略 Exception 兜底处理器记日志、返回 500，不向前端暴露堆栈
双层语义 协议层用 HTTP 状态码，业务语义用 Result.code
ProblemDetail RFC 7807 对外 API 标准格式，Spring 6/Boot 3 内建支持
日志脱敏 敏感字段打码落盘，密码密钥永不出现在日志
