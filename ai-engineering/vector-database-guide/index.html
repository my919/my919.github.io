向量数据库深度指南

2026 年企业 AI 应用的检索基础设施。聚焦最新实践：HNSW / DiskANN 索引、二值量化、混合检索（BM25 + 向量 + RRF + Rerank）、父子分块与 GraphRAG、pgvector 0.8 与 Milvus 2.5+ 生产落地。

0. 定位：RAG 栈中的检索层

向量数据库的本质职责：给定查询向量，在亿级向量中毫秒级找出近似最近邻（ANN），并支持结构化过滤。

1. 基础概念

1.1 距离度量

度量 公式 适用
Cosine（余弦） 1 − cos(θ) 通用文本 Embedding 默认
Inner Product（内积） −A·B 已归一化向量（等价余弦），推荐系统
L2（欧氏） ‖A−B‖² 图像特征、地理坐标

实践要点：OpenAI / BGE 等主流 Embedding 已归一化，此时内积 ≡ 余弦，用 IP 更快。

6. Embedding 模型与数据管理

6.1 模型选型

模型 维度 特点
BGE-M3（开源） 1024 稠密 + 稀疏 + ColBERT 多向量三合一，中文强，自建首选

Matryoshka（套娃）表示学习：训练时让前缀维度也可用，可截断到 512/256 维省内存，精度缓降。

6.2 分块策略演进

  • 父子块：用 256 token 小块精确匹配，命中后回溯 2K token 父块给 LLM，两头兼得。
  • GraphRAG：抽取实体关系建知识图谱，社区摘要回答全局性问题（”这批文档的主要结论”）。

9. 安全审计清单

10. 演进趋势（2026 → 2027）

  1. pgvector 化：大部分 RAG 场景”Postgres 就是向量库”，独立向量库留给亿级场景。
  2. 二值量化 + 重排成为十亿级标配：32x 内存压缩 + 精排补偿。
  3. 混合检索下沉到数据库：BM25/稀疏向量成为向量库内置能力（Milvus 2.5 / Qdrant 1.10+ 已落地）。
  4. Agent Memory：向量库从”文档检索”扩展到 Agent 长期记忆（Mem0 / Letta），支持时间衰减与冲突合并。
  5. MCP 化：向量库以 MCP Server 形式暴露给 Agent 生态，检索即工具。
  6. 多模态检索：图像/音频 Embedding 同库混合检索（ColPali 类视觉检索）。
  7. 图 + 向量融合：GraphRAG 与向量库融合，复杂多跳问题用图遍历补足。

11. 常见误用与陷阱

坑 现象 解法
Embedding 模型与库内不匹配 换模型不重建，查询/入库向量处于不同语义空间，召回全乱 固定模型名+版本；换模型走双写新 collection → 全量重建 → 灰度切流
维度不一致 1024 维写入 768 列直接报错；Matryoshka 截断后未同步表结构 建表维度与模型输出强校验，截断维度两端一致
不带 metadata 过滤 跨租户全库扫描：又慢又泄密 tenant_id 必填，应用层封装强制注入 filter，业务代码不可自带
距离度量混用 向量用 L2 归一化却建 cosine 索引；查询度量与索引 ops 不一致 索引 ops、ORDER BY、归一化策略三者统一（归一化后优先 IP）
TopK 贪多 30 块全塞进 prompt，噪音稀释答案且 Token 超标 TopK 3~8，候选放大到 50 走 Rerank 精排
HNSW 参数从不调 默认 ef_search 召回不足却以为是模型不行 ef_search ≥ TopK 的 4~10 倍，按召回评测基线反推
过滤列不建索引 高选择性过滤逼 HNSW 迭代扫描/全表扫 过滤列建 B-tree 或用 Partition Key 裁剪
入库时每条记录重载模型 灌入百万文档耗时几天、CPU 打满 模型单例常驻、批量 encode + upsert，离线任务限流

附：术语速查

术语 说明
ANN Approximate Nearest Neighbor，近似最近邻检索
HNSW Hierarchical Navigable Small World，分层图索引，当前默认首选
DiskANN 微软提出的磁盘友好图索引（Vamana），亿级以上场景
PQ / SQ / BQ 乘积量化 / 标量量化 / 二值量化
RRF Reciprocal Rank Fusion，多路检索排名融合（k=60）
Rerank Cross-Encoder 精排，混合检索后最后一级
Matryoshka 套娃 Embedding，前缀维度可用，支持维度截断
Oversampling 二值量化检索时多取候选再用原向量重排
Partition Key Milvus 租户分区键，查询自动裁剪
GraphRAG 知识图谱增强 RAG，适合全局性/多跳问题
