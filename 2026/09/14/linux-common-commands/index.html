技术栈速查

类别 Ubuntu（Debian 系） Rocky Linux（RHEL 系）
包管理 apt / dpkg dnf / rpm
防火墙 ufw firewalld
系统日志 /var/log/syslog /var/log/messages
登录日志 /var/log/auth.log /var/log/secure
SELinux 无（AppArmor） 有（必须了解）
默认用户组 sudo wheel

通用命令（ps/top/ss/tar/find 等）两系统完全一样，不再重复标注。

4. 防火墙（重点差异）

SELinux（Rocky 特有，必须了解）

Rocky 排障铁律：服务起不来/连不上，先看 SELinux（getenforce + ausearch -m avc），再查 firewalld，最后看服务日志。Ubuntu 无此层，直接查日志。

15. 排障组合命令（场景速查）

症状 命令组合（差异已标注）
服务起不来 systemctl status 服务 → journalctl -u 服务 -n 50
Rocky 服务异常 先查 SELinux：getenforce → ausearch -m avc -ts recent
端口不通 ss -tlnp → 防火墙（Ubuntu ufw status / Rocky firewall-cmd --list-all）
磁盘满了 df -h → du -sh /* | sort -hr | head → 清日志
CPU 100% top -b -n1 | head → top -Hp <pid>
内存不足 free -h → ps aux --sort=-%mem | head
端口被占 ss -tlnp | grep :8080 → lsof -i :8080
网络不通 ping → mtr → ss -tan → tcpdump
域名解析失败 dig → cat /etc/resolv.conf
登录不了 journalctl -xe → 登录日志（Ubuntu auth.log / Rocky secure）
负载高但 CPU 低 iostat -x 1 → 磁盘 IO 瓶颈 → vmstat 1
文件删不掉 lsof | grep deleted → 找占用进程重启
