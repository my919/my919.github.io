1. 概念说明

数据结构是数据在计算机中的组织方式，算法是解决问题的步骤集合。二者的核心评价指标是时间复杂度（随输入规模 n 增大，操作次数增长量级，用大 O 表示）和空间复杂度（额外内存用量）。

由浅入深的掌握路线：

  1. 复杂度分析（一切的基础）
  2. 线性结构：数组、链表、栈、队列、哈希表
  3. 树与图：二叉树、二叉搜索树、堆、图遍历
  4. 经典算法思想：排序、二分、双指针、滑动窗口、递归回溯、动态规划
  5. 刷题巩固 → 工程落地

4. 复杂度分析速查

复杂度 典型算法
O(1) 数组随机访问、哈希查找

O(n) 线性遍历、多数排序
O(n log n) 归并排序、快速排序、堆排序
O(n²) 冒泡/选择/插入排序、双重循环
O(2ⁿ) 递归枚举、暴力组合
