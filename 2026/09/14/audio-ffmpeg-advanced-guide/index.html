1. 概念说明

入门篇掌握了 FFmpeg 基本转码。本篇解决生产环境的高频问题：

  • 滤镜（filter）：FFmpeg 最强大的部分——音频的 EQ、压缩、混音、降噪都由 -af 滤镜链实现。
  • 响度标准化：播客、视频平台的响度标准（-14 LUFS），直接影响平台推荐与听感。
  • 批处理：一次处理上千个文件（转码、加片头、统一格式）。
  • 流媒体：RTMP/RTSP 推流、HLS 切片直播。

滤镜图语法：-af filter1=参数,filter2=参数（逗号连接，从左到右依次处理）。

3. 响度标准化（LUFS）

标准：播客/视频平台一般要求 -14 LUFS（YouTube、Spotify）或 -16/-23（广播 ITU-R BS.1770）。

参数 含义
I 综合响度（目标 -14）
TP 真实峰值上限（防削波，-1.5dB 留余量）
LRA 响度范围（动态控制）

6. 性能优化

手段 效果
-threads N 指定线程数
-preset faster（编码时） 速度/体积权衡
-filter_threads 滤镜多线程
并行处理多个文件 比单文件多线程更有效
SSD + 临时目录 大文件 IO 瓶颈

7. 生产排错手册

现象 原因与解法
No such filter 版本旧，升级 FFmpeg 或检查滤镜名
输出音量过低/爆音 用 loudnorm 标准化 + alimiter
转码慢 并行 + 换 -preset + 检查 CPU
推流卡顿 -re（按真实速度读取）+ 编码速率匹配
时间戳错误 加 -copyts 或重新 -start_at_zero
中文文件名失败 Windows 下用 PowerShell 或设置 UTF-8
