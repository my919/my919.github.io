1. 概念说明

OpenAPI（原 Swagger）是描述 HTTP API 的语言无关规范：一个 yaml/json 文件完整描述”有哪些接口、参数、响应、鉴权方式”。作用：

  • 文档即契约：前后端、跨团队按同一份契约开发，杜绝”接口改了不知道”。
  • 可执行：从规范自动生成 SDK、Mock、测试、文档。
  • 工具链成熟：Swagger UI、Redoc、openapi-generator、Prism 全生态。
