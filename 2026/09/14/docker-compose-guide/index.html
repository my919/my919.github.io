1. 概念说明

Compose 用一份 compose.yaml 声明”一组容器如何运行”：镜像、端口、卷、环境、依赖、网络——一条命令 docker compose up 拉起整个应用栈。

Compose vs K8s：单机多容器 → Compose；集群/自动扩缩容/自愈 → K8s。生产小团队用 Compose 完全够用（单机高可用靠 Swarm 或外部负载均衡）。

核心概念：service（服务）、network（网络）、volume（数据卷）、dependency（依赖）、healthcheck（健康检查）。
