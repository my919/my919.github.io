1. 概念说明

接口安全四层防护，由浅入深：

层次 解决 手段
认证（Authentication） 你是谁 账号密码、JWT、OAuth2
授权（Authorization） 你能干什么 RBAC 角色权限
传输安全 数据不被窃听篡改 HTTPS + 签名
攻击防护 刷接口/重放/注入 限流、防重放、参数校验

JWT 优缺点：无状态（适合分布式，不用查库）；缺点是无法主动吊销（用 Redis 黑名单/短过期补偿）。

7. 安全基线清单

项 要求
传输 全站 HTTPS（TLS1.2+）
密码 BCrypt（cost≥10），禁止 MD5/SHA 明文
令牌 JWT 短过期 + Redis 黑名单（登出/改密失效）
越权 每接口校验资源归属
输入 参数化 SQL、白名单校验、长度限制
敏感数据 日志脱敏、Payload 不放敏感信息
重放 时间戳 + nonce 幂等
限流 核心接口全部接限流
