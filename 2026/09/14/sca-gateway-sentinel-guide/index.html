1. 概念说明

网关 = 系统的唯一入口，集中处理横切关注点：

职责 说明
路由转发 按路径/Header 路由到服务
统一鉴权 JWT 校验一次，后端不管
限流熔断 全局限流保护
灰度发布 按 Header/权重分流
日志审计 访问日志统一收集
跨域 CORS 统一配置

Spring Cloud Gateway 核心：Route（路由规则）+ Predicate（匹配条件）+ Filter（请求处理链）。

Sentinel：阿里开源的流量防护组件——限流（控制 QPS）、熔断（失败降级）、热点参数限流（防单 key 打爆）、系统保护（自适应）。

5. 熔断降级规则

Sentinel vs Resilience4j/Hystrix：

能力 Sentinel Resilience4j
限流 QPS ✅ 强 一般
热点参数限流 ✅ 独特 ❌
熔断 ✅ ✅
控制台可视化 ✅ ❌
规则持久化 ✅（Nacos） 代码配置

微服务生态内选 Sentinel（与 Nacos 集成好）；非 Spring 环境用 Resilience4j。
