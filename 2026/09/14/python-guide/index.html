1. 概念说明

Python 是解释型、动态类型、多范式语言：语法简洁、生态庞大（AI、数据分析、Web、自动化都是主场）。

动态类型 vs 静态类型：变量不声明类型，运行时推断；配合类型注解（Python 3.5+）可获静态检查能力，生产项目强烈建议使用。

执行模型：GIL（全局解释器锁）限制同一进程多线程并行计算；CPU 密集用多进程/原生库，IO 密集用 asyncio 协程。

2. 环境准备（uv 一键管理）

uv 为什么是首选：替代 pip+venv+poetry，单工具完成解释器管理、依赖解析、虚拟环境、打包发布，速度比 pip 快 10-100 倍。
