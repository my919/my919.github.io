1. 概念说明

Java 是面向对象、跨平台的编程语言：”一次编写，到处运行” 靠 JVM 实现 ——.java 编译为字节码 .class，由 JVM 解释 / 即时编译执行。

核心组成：

  • JDK（Java Development Kit）：开发工具包，含编译器、JVM、类库。

  • JRE（Java Runtime Environment）：运行环境（JDK 已包含）。

  • JVM（Java Virtual Machine）：字节码执行引擎，内存管理、垃圾回收。

为什么选 JDK 21 LTS：长期支持版本（支持至 2031），带来虚拟线程、记录类（Record）、模式匹配等现代特性。生产环境优先 LTS（21 或 25）。
