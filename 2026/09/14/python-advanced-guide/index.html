1. 概念说明

Python 进阶的核心是理解三个机制：

  1. 装饰器/生成器：函数式编程能力——代码复用与惰性求值。
  2. GIL（全局解释器锁）：同一进程同时只有一个线程执行 Python 字节码——多线程适合 IO 密集，多进程/异步适合 CPU 密集。
  3. asyncio：单线程事件循环处理海量 IO 并发——现代 Python 高并发的首选。

并发选型表：

场景 方案
IO 密集（网络/DB） asyncio（单线程异步）
CPU 密集 multiprocessing / C 扩展
简单脚本并发 线程池（ThreadPoolExecutor）
大规模服务 FastAPI（内置 asyncio）
