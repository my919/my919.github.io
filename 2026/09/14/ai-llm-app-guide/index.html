1. 概念说明

大模型应用的核心模式有三种，由浅入深：

  1. Prompt 工程：直接调用模型，靠提示词引导（成本最低）。
  2. RAG（检索增强生成）：先从知识库检索相关资料，再让模型基于资料回答——解决”模型不知道你的私有数据”和”幻觉”问题，是当前落地主流。
  3. Agent（智能体）：模型自主决策：拆解任务 → 调用工具（函数调用）→ 观察结果 → 继续执行。

为什么 RAG 而不是微调：RAG 改知识只需更新向量库，无需重新训练；微调适合改变”行为风格”（如领域话术），不适合注入大量事实。

完整 RAG 流程：文档加载 → 分块 → 向量化 → 存向量库 → 用户提问 → 语义检索 TopK → 拼入 Prompt → 模型生成（附来源）。
