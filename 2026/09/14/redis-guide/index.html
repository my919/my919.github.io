1. 概念说明

Redis 是基于内存的高性能键值数据库：单线程（6.x 前）事件循环 + IO 多路复用，吞吐可达 10 万+ QPS。定位是缓存与中间件，不是主存储（数据可丢失场景除外）。

五种核心数据结构：

结构 说明 典型场景
String 字符串/数字 缓存、计数器、分布式锁
Hash 字段-值映射 对象存储、购物车
List 双向链表 消息队列、时间线
Set 无序去重集合 标签、共同好友
ZSet 有序集合（分数排序） 排行榜、延迟队列

Redis 8 新增：Redis 8.0（2025 年发布）带来原生向量检索（Redis Vector Sets）、增强持久化等能力，是当前主推版本。

4. 持久化（RDB + AOF）

方案 原理 特点
RDB 定时生成全量快照 文件小、恢复快，可能丢最后一次快照后数据
AOF 追加写命令日志 数据更安全，文件大、恢复慢
混合（推荐） RDB 全量 + AOF 增量 兼顾两者

8. 缓存一致性方案

方案 做法 说明
Cache Aside（推荐） 读：先缓存后库；写：先更新库再删缓存 简单，靠过期兜底
延迟双删 删缓存 → 更新库 → 延迟 500ms 再删 缓解并发不一致
订阅 binlog Canal 监听 MySQL binlog 同步删除缓存 彻底解耦
