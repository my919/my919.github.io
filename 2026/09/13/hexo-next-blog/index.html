当前项目 · Hexo + NexT 博客搭建指南

本项目是基于 Hexo 8 + NexT 8 主题的技术博客，内置分类体系、站内搜索、字数统计、GitHub Pages 部署等能力。

技术栈速查

备用主题 Landscape 1.0.0 默认主题备选
站内搜索 hexo-generator-searchdb 生成搜索索引 JSON
字数统计 hexo-symbols-count-time 统计文章字数与阅读时长
部署 hexo-deployer-git → GitHub Pages 一键发布到 Git 分支
语言 简体中文（zh-CN） 站点界面语言

6. 写作流程

新建文章

按分类组织文章

将文章放入 source/_posts/<分类>/ 子目录，例如 source/_posts/springboot/自动配置.md。

Hexo 生成的 URL 会带上分类前缀：/springboot/自动配置/。

同步分类页文章列表

该脚本会：

  • 遍历 source/_posts/<分类>/ 下的 .md 文件
  • 提取 title，生成 - [标题](/<分类>/<文件名>/) 链接
  • 更新 source/<分类>/index.md 中的文章列表块（<!-- articles-start --> 标记包裹，可重复执行）
  • 文章被删除或子目录被移除时，同步清空对应分类页列表

新建分类页

  1. 创建 source/<分类>/index.md：
  1. 在 source/_posts/<分类>/ 下放 .gitkeep 占位
  2. 在 _config.next.yml 的 menu 添加菜单项（小写键名 + 合适图标）
  3. 在 zh-CN.yml 的 menu 添加中文翻译

7. 功能特性

站内搜索

  • 依赖 hexo-generator-searchdb，生成 public/search.json
  • source/search/index.md 设置 type: search 渲染搜索页
  • 菜单已加入搜索入口

字数统计

  • 依赖 hexo-symbols-count-time
  • 文章底部显示「本文字数」与「阅读时长」
  • 页脚显示「站点总字数」与「站点阅读时长」
  • awl: 2 适配中文

深色模式

  • _config.next.yml 中 darkmode: true

8. 部署到 GitHub Pages

部署目标：https://github.com/my919/my919.github.io.git 的 gh-pages 分支。

首次部署需确保本地 Git 已配置凭据，或使用 SSH/Token 认证。

10. 注意事项

  • 修改 _config.next.yml 或 zh-CN.yml 后，需重新执行 startup.sh（或手动复制到 node_modules）才生效
  • 文章放在 _posts/<分类>/ 子目录时，URL 自动带分类前缀，分类页链接需与之匹配
  • public/、node_modules/、.deploy_git/ 已在 .gitignore 中忽略，不纳入版本控制
