技术栈速查

类别 选型 用途
注册/配置中心 Nacos 服务注册发现与集中配置
限流熔断 Sentinel 流量控制与服务降级
网关 Spring Cloud Gateway 统一入口与请求路由
服务调用 OpenFeign 声明式 HTTP 客户端
分布式事务 Seata 跨服务事务一致性
基础 Spring Boot 4 + Spring Cloud 2025 微服务底座

Spring Boot 4.1.x 对应 Spring Cloud 2025.1.x、Spring Cloud Alibaba 2025.1.x。
