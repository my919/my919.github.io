第一章：Rust 入门与所有权系统

概念基础

  1. 系统级编程语言：Rust 定位与 C/C++ 相同，面向操作系统、数据库、网络服务等对性能与控制力要求极高的场景，编译为原生机器码，无虚拟机、无 GC。
  2. 所有权是核心：每个值有且仅有一个所有者，赋值即移动（Copy 类型除外），出作用域自动 drop，从源头消除悬垂引用、use-after-free、double free。
  3. 借用检查在编译期：同一时刻要么一个 &mut，要么多个 &，编译器在编译期拒绝数据竞争，不依赖运行时 GC 兜底。
  4. 零成本抽象：Option/Result、迭代器、泛型与 trait 等高层抽象编译后不引入额外运行时开销，安全与性能可以兼得。
  5. 现代化工程体验：官方工具 Cargo 集构建、测试、文档与依赖管理于一体，配合 crates.io 社区仓库，上手与协作成本远低于传统 C/C++。

本章聚焦所有权与基础语法。类型系统、trait 与生命周期见 第二章：Rust 类型系统与 trait；并发与错误处理见 第三章：Rust 并发与错误处理；工程实践与 Web 开发见 第四章：Rust 工程实践与 Web 开发。

一、所有权与借用

1. 三条规则

  1. 每个值有且仅有一个所有者。
  2. 所有者离开作用域，值被 drop。
  3. 同一时间只能有一个可变引用，或任意多个不可变引用（不能同时存在可变与不可变引用）。

常见避坑

场景 错误 正确做法
所有权移动后使用 let s2 = s1; println!("{s1}") → use after move 需保留原值用 s1.clone()，或只借 &s1
同时持有 & 与 &mut let r = &v; v.push(1) → 借用规则冲突 不可变引用结束（NLL）后再取 &mut
一个 &mut 被别名 let r1 = &mut v; let r2 = &mut v; 同一时刻只能一个 &mut，改用 & 或加锁
悬垂引用 fn dangle() -> &String { &s } → 离开作用域 drop 返回 String 转移所有权，或借被引用者
中文字符串切片 &"中国"[0..1] → panic（切到字符中间） 用 .chars() 按字符迭代再切
数组越界访问 v[10] 在长度不足时 panic 用 v.get(10) 返回 Option 安全访问
unwrap 遇 Err s.parse::<i32>().unwrap() panic 用 match/?/unwrap_or 处理失败
Copy 误判 String 赋值后仍用旧变量 → move 只有整/浮/bool/char/不可变引用是 Copy

本章小结

要点 结论
所有权 每个值一个所有者，赋值即移动（Copy 类型除外），出作用域自动 drop
借用规则 同一时刻要么一个 &mut，要么多个 &，编译期拒绝数据竞争
数据类型 标量（整/浮/bool/char）+ 复合（元组/数组）；String 堆可变、&str 切片引用
控制流 if 是表达式；loop/while/for；match 穷尽模式匹配
struct/enum struct+impl 组织数据与方法；enum 建模多态，Option<T> 取代 null
