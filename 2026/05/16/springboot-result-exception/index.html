第八章：SpringBoot 统一返回体与全局异常

概念基础

  1. 统一契约：成功与失败均使用同一 JSON 结构，便于前端统一解析；Result<T> 三字段 code / msg / data。
  2. 两层语义：HTTP 状态码表达协议层语义（400/409/500 等），code 字段表达业务语义（可与 HTTP 一致或自定义）。
  3. 异常即响应：业务错误抛 BusinessException，由 @RestControllerAdvice 的 GlobalExceptionHandler 全局捕获并转换为 Result.fail，Controller 免写 try-catch。
  4. 校验联动：@Valid / @Validated 触发的 MethodArgumentNotValidException 与 ConstraintViolationException 同样统一处理为 400。
  5. 模板复用：完整 GlobalExceptionHandler 源码模板见 第五章：Java 全局异常处理：@RestControllerAdvice 与统一 Result；本章描述 springboot 仓库中的落地方式与验证。

@RestControllerAdvice + GlobalExceptionHandler：

异常 处理
BusinessException Result.fail(code, msg)，HTTP 按 code 映射
MethodArgumentNotValidException 首个字段错误 → 400
ConstraintViolationException @Validated 参数校验 → 400
InvalidFormatException JSON/枚举格式错误 → 400
Exception 未捕获 → 500，日志记录

BusinessException HTTP 映射示例：401、403、404、409、429（与 第十一章：防重提交与接口幂等 中 429 一致）。

  1. 复制 controller/entity/Result.java
  2. 复制 exception/BusinessException.java、GlobalExceptionHandler.java
  3. 引入 spring-boot-starter-validation
  4. Controller 统一返回 Result<T>
