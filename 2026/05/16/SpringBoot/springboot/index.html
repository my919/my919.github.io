第一章：SpringBoot 工程概览与快速启动

概念基础

Spring Boot 是构建在 Spring 之上、遵循「约定优于配置」的快速开发框架：

  1. 自动配置：@SpringBootApplication 组合了 @Configuration、@EnableAutoConfiguration、@ComponentScan，依据依赖自动装配 Bean，免去大量手写配置；业务配置类通过 @ConfigurationProperties + @EnableConfigurationProperties 绑定 application.yaml 中的 app.* 前缀。
  2. 起步依赖（Starter）：一个 starter 聚合一组版本兼容的依赖（如 spring-boot-starter-data-redis），版本由 BOM 统一管理。
  3. 内嵌容器：内嵌 Tomcat，gradlew bootRun 一键启动；本项目默认端口 8082、默认 Profile dev（可通过 SPRING_PROFILES_ACTIVE 覆盖）。
  4. 生产级能力：Actuator 提供健康检查与指标，配合 Profile 多环境、application.yaml 外部化配置与 Spring Boot Admin 形成可观测能力。
  5. 本仓库定位：Spring Boot 4.0.6 + Java 21 + Gradle 后端示例，三层架构、统一 Result、多数据源、Redis、RustFS、监控与 AOP 基础设施均已就绪；本目录按功能模块拆分集成与搭建流程，单篇 md 已带 Hexo Front Matter（title / tags / categories / date），可直接复制到 Hexo _posts 发布。

Configuration Processor（配置提示）

spring-boot-configuration-processor 在编译期为 @ConfigurationProperties 生成元数据，使 IDE 对 application.yaml 中自定义键提供自动补全、高亮与字段注释；不参与运行时，不应使用 implementation 打入生产包。
