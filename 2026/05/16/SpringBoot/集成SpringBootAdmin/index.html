第六章：SpringBoot 集成 Spring Boot Admin 监控

概念基础

  1. 定位：Spring Boot Admin 用于集中查看应用健康、指标、日志等，是 Actuator 数据的可视化面板。
  2. Server / Client 模型：Client 读取 Actuator 端点并向 Server 注册实例，Server 提供 Web UI 汇总展示；版本需与 Spring Boot 匹配。
  3. 本仓库形态：在 同一进程 内同时启用 Admin Server 与 Client（适合本地演示）；生产建议拆分为独立 Admin 服务并加认证。
  4. 暴露面管控：dev 全量暴露端点便于调试；prod 收紧为 health,info,metrics,prometheus，健康详情 when_authorized，端点暴露即攻击面。
  5. 测试隔离：单测关闭 Client 注册（spring.boot.admin.client.enabled=false），避免测试进程向外注册实例。
