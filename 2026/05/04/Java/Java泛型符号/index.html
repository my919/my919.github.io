第四章：Java 泛型符号与通配符实战

概念基础

泛型（Generics） 是 JDK 5 引入的参数化类型机制，示例代码直接复制即可运行，覆盖常用泛型符号：

  1. 为什么需要泛型：避免 Object 强转与 ClassCastException 风险，让类型检查提前到编译期，集合存取更安全、可读性更好。
  2. 字母约定：T（Type 通用类型）、E（Element 集合元素）、K / V（Key / Value 键值对）、U（第二个泛型参数）。
  3. 通配符 ?：表示未知类型；? extends 限定上界（只读）、? super 限定下界（可写），对应 PECS 原则（Producer Extends, Consumer Super）。
  4. 泛型方法与多限定：<T> 声明方法级泛型；T extends A & B 用 & 要求同时满足多个接口约束。
  5. 类型擦除：泛型信息只在编译期存在，运行时统一擦除为 Object，因此不能 new T()、不能用 T.class。

本章小结

要点 结论
字母约定 T 通用类型、E 集合元素、K/V 键值对、U 第二泛型参数
无界通配符 ? 接收任意类型集合，只读
上界 ? extends 匹配本类及子类，只读（生产者），如 List<? extends Number>
下界 ? super 匹配本类及父类，可写（消费者），如 List<? super Integer>
