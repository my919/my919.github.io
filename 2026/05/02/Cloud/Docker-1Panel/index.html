第三章：Docker 部署 1Panel

概念基础

  1. 1Panel 是开源的 Linux 服务器运维管理面板：在网页上即可管理网站、数据库、容器、防火墙、定时任务等，替代繁琐的命令行运维。
  2. 为什么用 Docker 部署：面板本体与依赖全部封进镜像，一条 docker run 即可拉起，升级与重建都围绕镜像和数据卷进行，不污染宿主机。
  3. 两类典型环境：Windows + Docker Desktop + WSL（必须端口映射 -p，勿用 --network host）与 Linux Docker 主机（可直接 host 网络）。
  4. 管理宿主机的关键：面板通过挂载 /var/run/docker.sock 获得管理宿主机 Docker 的能力，通过 /opt 与 BASE_DIR 约定数据目录。
  5. 安全底线：改强 PASSWORD、设 ENTRANCE 安全入口、按需放行安全组端口，避免面板暴露在公网被扫描。

共用前提

  • docker version 客户端与 Server 均正常，能拉取 Docker Hub（或已配置镜像加速）。
  • 建议内存 ≥ 1GB；多架构以 Hub 页为准。
  • 将 PASSWORD、ENTRANCE 等换成自己的值；变量含义见文末 「常用环境变量」。

第一类：Windows + Docker Desktop + WSL

场景：宿主机为 Windows，容器由 Docker Desktop 提供引擎；你在 WSL 里打开终端（发行版可为 Rocky Linux 10、Ubuntu 等），docker version 的 Server 往往显示 Docker Desktop 或上下文为 desktop-linux。此时容器里的 host 网络与你在 WSL 里访问的 localhost 不是同一概念，不要使用 --network host，应使用 -p <PORT>:<PORT>。

若曾误用 host 建过同名容器，先 docker rm -f 1panel-v2 再按本节重建。

浏览器访问（本机）

多数情况：http://127.0.0.1:10086/<ENTRANCE>（与示例 ENTRANCE 一致时）。在 WSL 内若 localhost 仍不通，可试 http://$(grep -m1 '^nameserver' /etc/resolv.conf | awk '{print $2}'):10086/<ENTRANCE>（常为 WSL2 下可达的 Windows 主机 IP，以本机为准）。

可选：docker compose（端口映射）

将下文保存为同目录下的 compose.yaml 或 docker-compose.yml（二选一即可，Compose V2 默认会读取二者）。Docker Desktop / WSL 使用 ports，不要写 network_mode: host。

在同目录执行 docker compose up -d。

第二类：Linux Docker 主机

场景：Linux 云服务器、物理机或虚拟机内安装 Docker Engine（非 Docker Desktop 作为服务端）。可用 --network host，面板监听端口即宿主机端口，与安全组、防火墙规则一致。

多行 docker run（--network host）

-v /var/run/docker.sock：面板管理宿主机 Docker。
-v /opt:/opt 与 BASE_DIR=/opt：数据目录可改，须与挂载路径同步。
moelin/1panel:v2：跟踪 V2 最新构建；生产建议改为 Hub 具体版本号。

可选：docker compose（host 网络）

将下文保存为同目录下的 compose.yaml 或 docker-compose.yml。

在同目录执行 docker compose up -d。

常用环境变量（V2）

变量 默认值（未设置时） 说明
PORT 10086 Web 端口
USERNAME 1panel 管理员用户名
PASSWORD 随机或默认（见 Hub） 登录控制台密码，务必改为强密码或从日志读取随机值
ENTRANCE entrance 安全入口的 URL 路径前缀（非第二端口），访问 http://IP:PORT/ENTRANCE，用于降低默认路径被扫的概率
BASE_DIR /opt 数据目录，需与 /opt 挂载一致
TZ 常见 Asia/Shanghai 时区
RESET false 置 true 可强制重置配置（慎用）

完整说明与 V1、Global 标签见 Hub 文档。

本章小结

要点 结论
第一类（Windows + Docker Desktop + WSL） -p 10086:10086；WSL 内 Bash 或 Windows CMD 见上文；compose 用 ports，不用 network_mode: host
第二类（Linux Docker 主机） --network host 或 compose 的 network_mode: host；一条命令见上文
数据 /opt 与 BASE_DIR 一致；挂载 docker.sock 以便管 Docker
