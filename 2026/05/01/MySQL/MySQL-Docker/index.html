第二章：Docker 部署 MySQL 实践

概念基础

容器化是「把 MySQL 实例连同版本、配置、账号一次性描述清楚」的部署方式：

  1. 环境一致、随起随删：一条命令拉起带指定版本、字符集、账号密码的实例，不污染宿主机；卸载即删容器，重装零成本——这正是第一章建好表结构之后最需要的环境。
  2. 数据与容器分离：容器可随时销毁，数据必须落在卷（volume）；命名卷 mysql-data 持久化 /var/lib/mysql，删容器不丢数据，但删卷等于删库，这是容器数据库的第一铁律。
  3. 镜像即版本契约：优先官方 mysql 镜像并固定小版本标签（如 mysql:8.0.40）或 digest，避免 latest 漂移；8.0 起默认认证插件 caching_sha2_password，老客户端需升级或调整参数。
  4. 初始化只发生一次：/docker-entrypoint-initdb.d 下的 .sql / .sh 仅在首次空数据目录时执行；之后的表结构变更要走 SQL 迁移，不会自动重放。
  5. 部署形态递进：单容器（docker run）→ 编排（Docker Compose）→ 集群（Kubernetes）；开发环境用前者即可，生产还要叠加备份、监控、网络策略、TLS 与 Secret 管控。

二、MySQL 镜像选择

1. 官方镜像（推荐）

  • 仓库：mysql（Docker Hub 官方库，由 Oracle / MySQL 团队维护）。
  • 常用标签：
    • mysql:8.0：8.0 长期维护线，生态兼容面广（WordPress、旧驱动等多以 8.0 为基准）。
    • mysql:8.4 或 mysql:lts：较新的 LTS 线（以 Docker Hub mysql tags 为准）。
  • 生产建议：固定小版本标签（如 mysql:8.0.40）或记录 digest，避免 latest 漂移导致行为变化。

2. 变体说明

需求 说明
默认认证插件 8.0 起默认 caching_sha2_password；老客户端不支持时需调整 --default-authentication-plugin 或升级客户端（MySQL 8.4 已移除 mysql_native_password，迁移前查发行说明）。

容器内建议在 command 或 my.cnf 中显式指定 utf8mb4，与业务库一致，避免默认与连接串不一致。

1Panel（推荐）：在 Linux 宿主机上若希望少手写命令、仍以容器方式运行 MySQL，可先安装 1Panel（开源 Linux 运维面板），在 「应用商店」 中选择 MySQL 一键部署：由面板负责镜像版本、数据持久化、端口映射与（可选）计划备份，启停与日志可在界面查看。与下文 docker run / Compose / K8s 中的环境变量、卷与字符集语义对齐或排障时，自 # 三 起各节仍可作对照。适合单台 VPS、家庭服务器等「一台机子上稳态跑库」的场景。

参数 含义

-v mysql-data: 数据目录持久化到 Docker 命名卷 mysql-data

若要把 .sql 放进命名卷 mysql-init，可任选其一：① 临时容器拷入 docker run --rm -v mysql-init:/init ...；② 改用绑定挂载 -v /宿主机路径/mysql-init:/docker-entrypoint-initdb.d:ro，便于本机直接放文件。

六、小结

项 说明
前置 已安装 docker 与 docker compose（或 docker-compose）
镜像 优先官方 mysql:8.0 / 固定补丁标签；注意认证插件与客户端版本
单容器 docker run：mysql-dev、命名卷 mysql-data / mysql-init、库 app、用户 admin、utf8mb4（见 # 三）
Compose 保存 docker-compose.mysql.yml 后 docker compose -f ... up -d
Kubernetes 保存 mysql-k8s.yaml 后 kubectl apply -f ...

生产环境请配合备份、监控、网络策略与 TLS；Secret 建议对接 External Secrets / Sealed Secrets 等管控流程。

本章小结

要点 结论
镜像 官方 mysql:8.0 起步，固定小版本标签/digest 防 latest 漂移
数据持久化 命名卷 mysql-data 对应 /var/lib/mysql；删卷 = 删库
初始化脚本 /docker-entrypoint-initdb.d 仅首次空数据目录执行一次
Compose docker compose -f ... up -d；敏感项走 .env 且不提交仓库
Kubernetes Secret + PVC + Deployment（Recreate）+ Service；主从用 Operator / StatefulSet
