第三章：LLM 大语言模型基础

概念基础

  1. 大语言模型（LLM）是在海量文本语料上以自监督方式预训练的超大 Transformer 网络，能理解与生成自然语言。
  2. 训练三阶段：预训练（下一词预测，学通用语言与知识）→ 监督微调（SFT） 对齐「助手」行为 → RLHF / DPO 对齐人类偏好。
  3. 交互单位是 Token：模型受上下文窗口（Context Window）限制，一次只能处理有限的 Token；长文档需分块或 RAG。
  4. 幻觉与增强：模型可能一本正经地编造内容，用**检索增强生成（RAG）接入私有知识、用工具调用（Function Calling）**连接真实 API 来缓解。
  5. 落地三路线：Prompt 工程最轻量，微调（LoRA/QLoRA）注入领域知识，RAG + Agent 组合解决知识时效与工具执行。

生命周期

阶段 说明
预训练 下一词预测（Causal LM）或掩码语言模型，学通用语言与知识
监督微调（SFT） 指令数据上对齐「助手」行为
RLHF / DPO 等 人类偏好或偏好对优化安全性与有用性
推理部署 量化、批处理、KV Cache、投机解码

代表模型族：GPT、Llama、Qwen、DeepSeek 等（以各开源/商用许可为准）。

Prompt 与上下文窗口

  • System / User / Assistant 角色消息构成对话。
  • Few-shot：在 Prompt 中给示例引导格式。
  • Context Window：模型一次可处理的 Token 上限；长文档需分块或 RAG。
  • Temperature / Top-p：控制采样随机性。

RAG 与 Agent

1. RAG（检索增强生成）



flowchart LR
  Q[用户问题] --> E[Embedding]
  E --> V[(向量库)]
  V --> Ctx[相关文档片段]
  Ctx --> LLM[LLM + Prompt]
  Q --> LLM
  LLM --> A[回答]

降低幻觉、接入私有知识；向量库可与 第一章：Redis 概述、安装与 CLI 入门 向量检索、专用 DB 配合。

2. 工具调用（Function Calling）

模型输出结构化 JSON 调用 API（查天气、查订单），由应用执行后把结果回传模型。

微调方式

方式 说明
全量微调 更新全部参数，成本高
LoRA / QLoRA 低秩适配器，省显存
继续预训练 领域语料增强行业知识

训练栈常基于 第一章：PyTorch 入门与张量 + Hugging Face Transformers / PEFT。

评估与安全

  • 基准：MMLU、HumanEval（代码）等（仅作参考）。
  • 业务指标：任务成功率、人工抽检、延迟与成本。
  • 风险：幻觉、注入攻击、隐私泄漏；需权限控制、输出过滤与审计。

基础理论见 第一章：ML 机器学习基础、第二章：DL 深度学习基础。

本章小结

要点 结论
生命周期 预训练 → SFT → RLHF/DPO → 推理部署（量化、KV Cache、投机解码）
交互方式 System/User/Assistant 消息 + Few-shot；上下文窗口是 Token 上限
知识增强 RAG 检索私有知识降幻觉，Function Calling 让模型调用真实 API
定制路线 全量微调成本高，LoRA/QLoRA 低秩适配是主流，继续预训练注入领域知识
评估安全 公开基准仅作参考，看业务指标；防幻觉、注入攻击与隐私泄漏

至此语言模型主线完成：ML 打好数据与算法基础，DL 掌握神经网络与训练工程，LLM 把这些能力放大到语言智能与应用落地。RAG 的完整工程实现（切块、向量库、检索评估）见 第四章：RAG 与向量检索实战；动手实验配合本站 第一章：PyTorch 入门与张量 等章节。
