第一章：Netty 网络编程框架入门

概念基础

  1. Netty 是基于 Java NIO 的异步事件驱动网络应用框架：帮你快速开发高性能、高可维护性的协议服务器与客户端，而不必直面原生 NIO 的复杂 API。
  2. 为什么不用原生 NIO：Selector 空轮询、缓冲区切换、线程模型搭建等细节繁琐易错；Netty 把这些封装成事件驱动的组件，开发者只写 Handler。
  3. Reactor 模型：少量 EventLoop 线程通过 Selector 监视大量 Channel，以事件驱动取代「一条连接一条线程」，是高并发服务器的经典模型。
  4. 零拷贝与缓冲：ByteBuf 池化、CompositeByteBuf 等减少拷贝（具体依版本与平台），降低 GC 与内存开销。
  5. 协议栈与生态：内置或社区 Codec（HTTP、Redis、MQTT 等），也可自定义帧解码；典型用户：Dubbo、gRPC-Java（部分）、Elasticsearch、游戏网关、物联网接入。

核心组件

组件 说明
EventLoopGroup 线程池，每个 EventLoop 绑定 Selector
Channel 网络连接抽象（NioSocketChannel 等）
ChannelPipeline Handler 双向链表，入站/出站事件传播
ChannelHandler 编解码、业务逻辑、空闲检测等
Bootstrap / ServerBootstrap 客户端/服务端启动辅助类

Pipeline 示例（概念）

  • 入站：socket 读 → 解码 → 业务 Handler。
  • 出站：业务写 → 编码 → socket 写。
  • 共享 Handler：注意 @Sharable 与线程安全。

本章小结

要点 结论
定位 异步事件驱动的网络框架，封装原生 NIO 的复杂细节
线程模型 Reactor：少量 EventLoop 借 Selector 管大量 Channel
核心组件 EventLoopGroup / Channel / Pipeline / Handler / Bootstrap 五件套
编排方式 入站解码、出站编码，业务逻辑写成 Handler 挂进 Pipeline
上手路径 先跑通 ServerBootstrap 骨架，再深入多路复用与线程模型
