第三章：音视频编辑处理

发表于 2026-05-01 更新于 2026-09-01 分类于 FFmpeg 本文字数： 1.6k 阅读时长 ≈ 5 分钟

第三章：音视频编辑处理

概念基础

  1. 编辑操作多在「容器/时间」层：裁剪、截图、合并、抽取音轨，多数可 -c copy 不重编码，秒级完成；只有变速、加滤镜才需重编码。
  2. 时间精度取决于关键帧：-c copy 裁剪只能切在关键帧，可能比目标点晚几帧；要精确到帧需重编码或先对齐关键帧。
  3. 合并与拆分：同编码参数的多段用** concat 协议/滤镜**无损拼接；异构参数需重编码统一后再拼。
  4. GIF 是特殊输出：调色板优化是高质量 GIF 的关键，直接转 GIF 易有色带。
  5. 本章目标：覆盖日常编辑 90% 需求——裁剪、截图、GIF、提取/分离音轨、合并、变速、音量调整。

本章承接 第二章：编解码与转码，操作多可 -c copy，速度优先。

一、裁剪与切片

1. 按时间裁剪

  • -ss 在 -i 前：解封装快速跳转（推荐），可能不精确到帧。
  • -t：时长；-to：结束时间点。
  • -c copy：裁剪只能切在关键帧，开头可能略偏；要精确用重编码。

2. 等分切片

二、截图与序列帧

  • -frames:v 1：只输出 1 帧。
  • -vf "fps=N"：每秒 N 帧采样，用于连续截图/缩略图。

三、GIF 生成

直接转 GIF 易有色带，先生成调色板再引用是高质量做法：

  • fps=10：帧率（GIF 体积敏感，10–15 帧够用）。
  • scale=480:-1：宽度 480，高度按比例。
  • flags=lanczos：高质量缩放算法。
  • palettegen/paletteuse：生成与使用调色板，显著减少色带。

四、音频提取与分离

  • -vn：丢视频；-map 0:a:N：选第 N 路音轨（从 0 起）。
  • -c:a copy：原样抽出，不重编码（仅改封装）。

五、合并

1. concat 协议（同编码参数，无损最快）

-safe 0：允许 list.txt 用绝对路径或相对路径。

2. concat 滤镜（异构参数，需重编码）

n=2：段数；v=1:a=1：各段有 1 路视频 1 路音频。

3. 音视频合并（独立视频 + 独立音频）

-shortest：以最短流为准截断（防音频比视频长导致黑屏拖尾）。

六、变速

  • setpts=N*PTS：视频时间戳缩放，<1 加速、>1 慢放。
  • atempo=N：音频变速，范围 0.5–2.0；更大倍率需链式 atempo=2,atempo=2（4 倍）。

七、音量与静音处理

  • volume=N：线性增益，1.0 原音量。
  • loudnorm：EBU R128 响度归一化，适合多段混剪统一音量。

八、旋转与翻转

transpose：0=逆90、1=顺90、2=逆90+垂直翻转、3=顺90+垂直翻转。

九、常见陷阱

陷阱 说明
concat 协议参数不一 各段编码/分辨率/时间基不同会花屏或失败，需先用重编码统一
裁剪开头黑帧 -c copy 切在关键帧，开头可能有几帧偏差；精确需重编码
GIF 体积爆炸 不限帧率/尺寸 GIF 极大；用 fps+scale+调色板控制
变速没动音频 只 setpts 视频变速，音频仍原速，导致不同步；必须同步 atempo
合并音视频拖尾 音频比视频长，未加 -shortest 导致黑屏拖尾
截图无 -frames:v 1 不限制会输出该时间点后所有帧到文件序列
-map 选错流 多音轨源默认只取第一路；需用 -map 0:a:N 指定

本章小结

要点 结论
裁剪 -ss+-t/-to，-ss 在 -i 前快速；-c copy 切关键帧，精确需重编码
截图 -frames:v 1 单帧；fps=N 连续截图
GIF 先 palettegen 再 paletteuse，配 fps+scale+lanczos 控体积质量
音频提取 -vn 丢视频；-map 0:a:N 选音轨；-c:a copy 原样抽
合并 同参数用 concat 协议（无损）；异构用 concat 滤镜（重编码）
音视频合 -map 选流 + -shortest 防拖尾
变速 setpts 视频变速 + atempo 音频变速必须同步
音量 volume=N 线性增益；loudnorm 统一响度
