第四章：滤镜与滤镜图

概念基础

  1. 滤镜（filter）加工每一帧：在解码后、编码前对原始帧做变换——缩放、裁剪、水印、字幕、调色等，是 FFmpeg 表达力最强也最易出错的部分。
  2. 三类入口：-vf（简单视频滤镜链，单输入）、-af（简单音频滤镜链）、-filter_complex（复杂滤镜图，多输入/多输出/多流合成，画中画、多路拼接必用）。
  3. 链与图：滤镜链（chain） 用逗号串多个滤镜顺序执行；滤镜图（graph） 用分号串多条链并行/分支。[label] 标记流的去向。
  4. 简单 vs 复杂：单输入单输出用 -vf/-af 足够；多输入（如视频+水印图、视频+字幕）必须 -filter_complex。
  5. 本章目标：掌握滤镜图语法、常用视频/音频滤镜、典型复杂滤镜图（水印、画中画、字幕烧录），能看懂并自己拼装。

2. 复杂滤镜图（-filter_complex）

支持多输入、多链、标签路由。语法：

  • [0:v]：第 0 个输入的视频流；[1:v]：第 1 个输入的视频流；[0:a]：音频流。
  • [v]/[a]：自定义输出标签，供 -map 引用。
  • ; 分隔多条并行链，, 分隔链内顺序滤镜。

查可用滤镜：ffmpeg -filters；查某滤镜参数：ffmpeg -h filter=overlay。

五、滤镜链执行顺序与性能

  • 顺序敏感：scale,crop 与 crop,scale 结果不同——先放大再裁剪 vs 先裁剪再放大。
  • 性能：滤镜越多越慢；能用 -c copy 跳过的（如只换容器）别加滤镜。
  • 硬件滤镜：部分滤镜有 GPU 版（scale_cuda、overlay_cuda），需硬件编码配合。
  • -filter_complex 与 -vf 混用：同一输出流不能既用 -vf 又在 -filter_complex 处理；统一用 -filter_complex。

七、常见陷阱

陷阱 说明
逗号分号混用 , 串链内顺序滤镜，; 分隔多链；用错报「无标签」或语法错
标签未引用 -filter_complex 产出 [v] 但忘了 -map "[v]"，输出无视频
overlay 坐标越界 水印比主画面大会报错；先 scale 缩小水印
字幕路径含冒号 Windows 路径 C:\ 与字幕选项分隔符冲突，需转义 subtitles='C\:/path'
trim 不重置时间戳 裁剪后不加 setpts=PTS-STARTPTS，开头有空白时长
hstack 分辨率不一 拼接要求各路同高（hstack）/同宽（vstack），先 scale 统一
drawtext 中文乱码 需 fontfile 指定含中文字形的 ttf
