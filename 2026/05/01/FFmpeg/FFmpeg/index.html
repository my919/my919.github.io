第一章：FFmpeg 音视频处理入门

概念基础

  1. 音视频处理瑞士军刀：FFmpeg 是开源的转码、裁剪、截图、推流命令行工具集，几乎所有播放器、视频网站与转码服务背后都有它（Chrome、VLC、OBS 均基于或依赖其底层库）。
  2. 三大组件：ffmpeg（转码与处理）、ffprobe（查看媒体元信息）、ffplay（本地播放调试）。底层是四大库 libavcodec / libavformat / libavfilter / libavutil。
  3. 命令结构固定：ffmpeg [全局选项] -i 输入 [输出选项] 输出，理解「输入 → 滤镜 → 编码 → 封装」流水线即可举一反三。
  4. 容器与编解码分离：MP4/MKV 是封装容器，H.264/AAC 是编码格式；-c copy 只换容器不重编码，速度极快。
  5. 应用广泛：视频网站转码、HLS/RTMP 直播推流、GIF 生成、提取音频等日常需求一条命令搞定。

一、三大组件

组件 作用 典型用法
ffmpeg 转码、裁剪、滤镜、推流等一切处理 ffmpeg -i in.mp4 out.mp4
ffprobe 查看媒体元信息（容器、流、编码、时长、码率） ffprobe -show_format -show_streams in.mp4
ffplay 本地简易播放器，调试滤镜效果 ffplay -vf "scale=640:-2" in.mp4

先用 ffprobe 摸清输入再动手，是排查问题的第一步——它告诉你容器格式、有几路流、各路编码/分辨率/码率/时长。

二、命令结构与执行流水线

一条命令的内部流转：



flowchart LR
  IN[输入文件/流 -i] --> DEMUX[解封装 demux]
  DEMUX --> DEC[解码 decode]
  DEC --> FLT[滤镜 filter]
  FLT --> ENC[编码 encode]
  ENC --> MUX[封装 mux]
  MUX --> OUT[输出文件/流]

关键：滤镜与重编码都需先解码到原始帧再处理。-c copy 跳过「解码→编码」，直接拷贝原始码流到新容器，故秒级完成但无法改编码/分辨率/滤镜。

1. 全局选项（放在 -i 之前）

选项 作用
-y 覆盖输出文件不询问（脚本必备）
-n 输出已存在则报错退出（防误覆盖）
-hide_banner 隐藏启动 banner，输出更干净
-loglevel error 只打印错误（quiet/error/warning/info/verbose/debug）
-stats 打印进度（默认开，-nostats 关）
-progress url 输出机器可读进度（接管道或文件，监控用）

3. 输入与多输入

  • -i 可出现多次，多文件拼接（配合 -filter_complex 见第四章）。
  • -ss 放 -i 前：用输入解封装快速定位（快，但可能定位到最近关键帧，精度略低）。
  • -ss 放 -i 后：逐帧解码到目标点（精确，但慢）。

三、常用输出选项速查

选项 作用
-c:v / -c:a 视频/音频编码器（copy 不重编码）
-b:v / -b:a 视频/音频目标码率，如 -b:v 2M -b:a 128k
-f 强制输出格式，如 -f flv -f hls -f mp4
-t 输出时长（从起点计）
-to 输出到指定时间点（与 -t 二选一）
-ss（输出侧） 输出起始时间
-r 输出帧率
-s 输出分辨率，如 -s 1280x720
-vn / -an / -sn 丢弃视频/音频/字幕流
-map 手动选流（多路流时指定取哪几路）

本章小结

要点 结论
三大组件 ffmpeg 处理、ffprobe 看信息、ffplay 调试；动手前先 ffprobe 摸清输入
命令骨架 全局选项 → -i 输入 → 输出选项 → 输出，内部走「解封装→解码→滤镜→编码→封装」
容器 vs 编码 MP4/MKV 是容器，H.264/AAC 是编码；-c copy 跳过编解码、秒级换容器
时间定位 -ss 在 -i 前快速（关键帧）、在后精确（逐帧）；时间支持 HH:MM:SS 与秒数
全局选项 -y 覆盖、-hide_banner/-loglevel 控输出、-progress 监控进度
上手路径 先跑通转码与 -c copy 换容器，再进入第二章深入编解码质量控制
