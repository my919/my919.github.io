第十三章：gRPC 详解：Protobuf、HTTP/2 与 grpcurl / Python 示例

概念基础

gRPC 是构建在 HTTP/2 与 protobuf 之上的高性能 RPC 框架，用「强类型契约」生成多语言调用代码：

  1. 解决什么问题：手写 HTTP+JSON 接口缺契约、字段易错、序列化慢；gRPC 的 .proto 文件即契约，protoc 生成 stub，序列化体积小、编解码快。
  2. 为什么基于 HTTP/2：二进制分帧 + 单连接多路复用，一条连接并发多个调用，且天然支持流式。
  3. 四种调用类型：Unary 一问一答、Server streaming、Client streaming、Bidirectional streaming——流式是一等公民。
  4. 典型场景：微服务内部低延迟、强类型调用（同族范式见 第十四章：RPC 概念详解：原理、形态与 JSON-RPC / curl 示例）；浏览器直连受限，对外常配 gRPC-Web 或网关。
