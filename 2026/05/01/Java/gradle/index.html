第二章：Gradle 构建工具：安装、配置与常用命令

概念基础

Gradle 是基于 JVM 的现代构建工具，广泛用于 Java / Kotlin / Android 项目：

  1. 脚本即代码：构建脚本用 Groovy DSL（build.gradle）或 Kotlin DSL（build.gradle.kts）编写，比 XML 更简洁、可编程。
  2. 复用 Maven 仓库体系：依赖坐标与 Maven Central、google() 等仓库完全兼容，可配置阿里云镜像加速下载。
  3. 增量构建与缓存：通过任务图、增量构建与构建缓存避免重复工作，大型项目构建明显更快。
  4. Gradle Wrapper：项目内提交 gradlew 即可固定团队 Gradle 版本，新成员免手工安装，保证构建环境一致。
  5. 与 Maven 的取舍：Maven 约定优先、上手简单；Gradle 更灵活、性能更好，但脚本自由度高，团队需要统一规范。

理解了定位，再看如何安装：

官网与发行包

  • 项目官网：https://gradle.org/
  • 发行版列表与变更说明：https://gradle.org/releases/
  • 二进制包下载（-bin.zip，各平台通用）：https://services.gradle.org/distributions/gradle-<版本>-bin.zip
    例如：https://services.gradle.org/distributions/gradle-9.5.0-bin.zip（<版本> 请按官网当前稳定版替换）。

安装前需已安装 JDK 8+（建议 JDK 17 或 21 LTS），终端可执行 java -version 验证。
Linux 解压 .zip 需要 unzip（Rocky 可 sudo dnf install -y unzip）。

本章小结

要点 结论
官网 https://gradle.org/
Windows 默认解压到 **C:\app\**，配置 GRADLE_HOME 与 Path 中的 %GRADLE_HOME%\bin
Rocky Linux dnf install gradle（路径随包）或官方 gradle-*-bin.zip 解压到 /usr/local/ 并设 GRADLE_HOME=/usr/local/gradle
加速 ~/.gradle/init.gradle 配置阿里云等仓库；Wrapper 本体另看 gradle-wrapper.properties
验证 gradle -v

完成以上步骤后，本机即可稳定使用 Gradle 构建 Java 等项目。
