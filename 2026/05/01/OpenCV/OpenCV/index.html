第一章：OpenCV 计算机视觉入门

概念基础

  1. 计算机视觉基础库：OpenCV 提供图像读写、滤波、几何变换、特征提取、视频处理等数百个现成算法，是 CV 领域事实上的标准库，1999 年由 Intel 发起，现由 Itseez/OpenCV.org 维护。
  2. 图像即数组：图像在 Python 中以 NumPy 数组表示，注意 OpenCV 默认 BGR 通道顺序而非 RGB，所有处理本质上都是数组运算——理解这一点就抓住了 OpenCV 的本质。
  3. C++ 内核、多语言绑定：核心由 C++ 实现保证性能，Python 通过 cv2 绑定调用，兼顾开发效率与运行速度；亦有 Java/JS 绑定。
  4. 传统 CV 与深度学习的桥梁：自带 cv2.dnn 可加载 ONNX 等模型推理，更多时候负责深度模型前后的预处理与后处理。
  5. 跨平台易上手：桌面、移动、嵌入式均可运行，pip install opencv-python 即可开始。

一、安装与版本选择

contrib 与主包二选一，不要同时装（冲突）。需要 SIFT 旧实现或额外模块才用 contrib；4.x 后 SIFT 专利已到期、主包即可用。

二、图像即 NumPy 数组（核心心智模型）

OpenCV 读入的彩色图是 H×W×C 的 uint8 数组，通道顺序 BGR：

三个易错点：

  1. 坐标顺序：img[y, x] 是「行、列」，即先纵坐标 y 再横坐标 x，与 (x, y) 直觉相反。
  2. BGR 不是 RGB：matplotlib 显示需先 cv2.cvtColor(img, cv2.COLOR_BGR2RGB)，否则红蓝颠倒。
  3. shape 顺序：shape = (H, W, C)，高在前；cv2.resize(img, (W, H)) 传参是「宽、高」，两处顺序相反。

三、最小读写示例

  • imread 失败返回 None 而非抛异常——务必判空，否则后续 img.shape 报 AttributeError 让人困惑。
  • imread 第二参：cv2.IMREAD_GRAYSCALE（灰度）、cv2.IMREAD_UNCHANGED（含 alpha 通道）。
  • waitKey：返回按键 ASCII；& 0xFF 是跨平台惯例；1 表示等 1ms（视频循环用）。

四、视频读写骨架

视频本质是逐帧图像循环——掌握单图处理，视频就只是加层 while。摄像头传设备号 0/1；写视频用 cv2.VideoWriter（见第五章）。

本章小结

要点 结论
本质 图像即 NumPy 数组，OpenCV 是高效的数组运算库
安装 opencv-python 日常够用；需额外模块用 contrib；服务器用 headless
通道顺序 默认 BGR，matplotlib/PIL 交互需转 RGB
坐标顺序 img[y, x] 先行后列；shape=(H,W,C)；resize(img,(W,H)) 先宽后高——两套相反
imread 失败返回 None 不报错，务必判空
视频 逐帧 read() 循环，waitKey(1) 控制节奏与退出
模块 core/imgproc/video/features2d/dnn/calib3d 各司其职
