第二章：OpenSSL 功能全景与自建局域网 CA 实战

概念基础

  1. OpenSSL 有两层身份：一是命令行工具（生成证书、密钥、加解密、签名等日常操作）；二是底层密码库（libcrypto / libssl，几乎所有软件的加密都靠它：Nginx、Python、Java、curl、安卓、iOS 等）。
  2. 事实标准：90% 的互联网加密通信，底层都在用 OpenSSL；HTTPS、TLS、QUIC、VPN、SSH 全覆盖。
  3. 命令行能做什么：证书体系（生成/查看/转换）、文件加解密、哈希校验、随机密码/密钥、测试 HTTPS 连接、模拟 HTTPS 服务器、签名验签——本章逐条给出命令。
  4. 为什么需要自建 CA：局域网/内网服务（如 https://192.168.1.22）无法从公网 CA 获取证书；自己做根 CA 签发服务器证书并导入设备信任，即可实现浏览器绿标、无不安全警告。
  5. 本章定位：先给出功能全景，再用一条条可复制的命令完成局域网全套可信证书实战。

命令行生成证书、CSR、格式转换等逐步操作见 第一章：OpenSSL 命令行入门与常用操作总览。

  • Nginx / Apache（HTTPS 加密）
  • curl / wget
  • Python / PHP / Node.js
  • Android / iOS 系统加密
  • Docker / Kubernetes
  • Wi-Fi 加密、VPN、SSH
  • 你的浏览器底层密码库

一句话：互联网加密的基石。
