第十章：Jupyter 入门：经典 Notebook、安装与内核

概念基础

Jupyter 是交互式计算生态的名字（源自 Julia / Python / R 三大语言），核心产品就是「浏览器里的笔记本」：

  1. 代码-输出-说明同页共存：在浏览器里写代码、立即看结果、随手记 Markdown 笔记，一个 .ipynb 文件同时是草稿、报告与教学讲义。
  2. 前端与内核解耦：Notebook / JupyterLab 只是「前端界面」，真正执行代码的是独立的**内核（Kernel）**进程，二者通过协议通信——所以一个环境可注册多个内核，前端也可互换。
  3. .ipynb 文件格式：本质是 JSON，保存单元格代码、输出与元数据；是数据分析与算法实验的「可复现草稿纸」。
  4. 为什么需要它：探索性数据分析需要「改一行、马上看结果」的反馈回路，传统「写脚本 → 运行 → 看日志」的循环太慢，Notebook 正是为这类探索而生。
  5. 学习路径：本章掌握经典 Notebook；需要多标签工作台升级 第十一章：JupyterLab 入门：安装、工作区与扩展，团队多用户上 第十二章：JupyterHub 入门：多用户架构与部署要点。

官网与组成

  • Jupyter 项目主页：https://jupyter.org/
  • Notebook 文档（经典界面）：https://jupyter-notebook.readthedocs.io/
  • .ipynb 格式说明：以当前 nbformat 文档为准（Notebook 文件为 JSON，含代码单元、输出与元数据）。

Jupyter 与具体「前端」解耦：Notebook 与 JupyterLab 都能打开同一 .ipynb；底层常由 jupyter_server 提供 HTTP 与 WebSocket 服务。团队若只需单用户本机或单容器写分析，Notebook 或 JupyterLab 二选一即可。

环境准备

  1. 安装 Python 3.10+，终端可执行 python --version（或 python3，下文统一写 python，请按本机替换）。
  2. 建议使用虚拟环境（venv、conda 或站内 uv 工具），避免把 Jupyter 装进全局 site-packages 难以清理。

内核与 .ipynb 要点

1. 内核（Kernel）

内核是执行代码的进程；Python 环境装了 ipykernel 并注册后，Notebook 右上角可选该内核。

2. 单元格类型

常见为 Code（运行代码）与 Markdown（写说明）；Shift+Enter 执行当前单元并跳到下一单元（具体快捷键以界面 Help 为准）。

3. 保存与版本

.ipynb 含输出时体积会变大；纳入 Git 前团队可约定是否清空输出再提交，或使用 nbstripout 等工具（按需查阅文档）。

与 JupyterLab 的取舍

需求 建议
习惯经典菜单、轻量界面 继续用 jupyter notebook
多文件标签、内置终端、扩展生态 使用 第十一章：JupyterLab 入门：安装、工作区与扩展（jupyter lab）
多用户、登录与配额 使用 第十二章：JupyterHub 入门：多用户架构与部署要点

二者可同一虚拟环境内并存：同时安装 notebook 与 jupyterlab 并不冲突。
