第三章：PL/SQL 程序设计

发表于 2026-05-01 更新于 2026-09-01 分类于 Oracle 本文字数： 3k 阅读时长 ≈ 10 分钟

第三章：PL/SQL 程序设计

概念基础

  1. 过程化 SQL 扩展：PL/SQL 在 SQL 之上加入变量、流程控制、游标、异常、过程/函数/包/触发器，把多步 SQL 与业务逻辑封装成库内可复用的程序单元。
  2. 块结构是基础：所有 PL/SQL 程序都由「声明 - 执行 - 异常」三段式块构成，执行段是唯一必需——这是理解一切存储过程的根基。
  3. 服务端执行减少往返：复杂逻辑下沉库内执行，避免应用与数据库多次网络往返，对批量、循环更新场景提速显著，但也带来「业务与库耦合」的代价。
  4. 静态 SQL + 强类型：PL/SQL 中的 SQL 在编译期校验表/列，变量强类型绑定，比拼接动态 SQL 更安全高效。
  5. 本章目标：掌握块结构、流程控制、游标、异常处理，以及过程/函数/包/触发器四大程序单元，写出可维护的库内逻辑。

本章承接 第二章：SQL 查询与内置函数 的 SQL 能力。PL/SQL 是 Oracle 生态的强项，掌握后能把零散 SQL 组织成工程化模块。

七、包（Package）

包把规范（spec，公共声明）与体（body，实现）分离，是组织大型 PL/SQL 代码的最佳实践：

调用：

包的优势：

  1. 封装：公共/私有分离，私有过程只在 body 内可见。
  2. 会话状态：包级变量在会话内持久，可做缓存。
  3. 重载：同名过程不同参数签名（仅包内支持）。
  4. 首次调用初始化：BEGIN ... END 段在首次访问时执行一次。
  5. 依赖管理：改 body 不影响 spec 依赖者，减少失效。

生产 PL/SQL 必然走向包——单文件存储过程难以维护，包是 Oracle 生态的工程化基石。

八、触发器

触发器在事件发生时自动执行，常用于审计、约束补全、级联：

要素 说明
时机 BEFORE / AFTER / INSTEAD OF（视图）
级别 语句级（每语句一次）/ 行级（FOR EACH ROW 每行一次）
事件 INSERT/UPDATE/DELETE，可组合
: :OLD 旧值、:NEW 新值（行级可用）

系统触发器

触发器要克制使用：每行触发一次易引发性能问题、隐式逻辑难调试、级联触发器死循环难排查。能用约束/过程/应用层逻辑替代的就别用触发器。COMPOUND 触发器（11g+）可缓解行级触发器性能瓶颈。

九、动态 SQL

静态 SQL 无法满足运行时拼表名/列名时，用动态 SQL：

1. EXECUTE IMMEDIATE（单条）

2. DBMS_SQL / EXECUTE IMMEDIATE USING（绑定变量）

必须用绑定变量：拼接字符串既危险（SQL 注入）又伤性能（每条新 SQL 硬解析）。用 DBMS_ASSERT 校验动态对象名。动态查询多行结果用 DBMS_SQL 或 OPEN FOR 游标变量。

十、批量绑定（BULK COLLECT / FORALL）

批量绑定是 PL/SQL 性能优化的核心——一次往返处理多行，避免循环内逐行 SQL：

语句 作用
BULK COLLECT INTO 一次取多行到集合
FORALL 一次提交多行 DML（非循环，单次往返）
SAVE EXCEPTIONS FORALL ... SAVE EXCEPTIONS 允许个别失败不中断

行级循环 DML 是性能杀手：FOR r IN cursor LOOP UPDATE ... 每行一次往返。改用 BULK COLLECT + FORALL 可提速数十倍。详见 第六章：性能调优与运维。

十一、常见陷阱

陷阱 说明
SELECT INTO 多行/0行 多行抛 TOO_MANY_ROWS、0行抛 NO_DATA_FOUND，用游标或聚合兜底
未 COMMIT 断连 过程内 DML 默认不自动提交，断连回滚
OTHERS 吞错误 兜底不记日志会掩盖问题，应记 FORMAT_ERROR_BACKTRACE
触发器滥用 行级触发器性能差、隐式逻辑难调试，优先用约束/过程
动态 SQL 拼接 拼表名用 DBMS_ASSERT，传值用绑定变量防注入
逐行 DML 循环内 UPDATE 慢，改 FORALL 批量
包状态丢失 包级变量在会话级，重新编译包体可能丢失会话状态
函数中 DML 在 SQL 中调用的函数不能做 DML，否则报 ORA-14551

本章小结

要点 结论
块结构 DECLARE/BEGIN/EXCEPTION 三段式，BEGIN 段唯一必需
变量 %TYPE/%ROWTYPE 解耦；CONSTANT 常量；关联数组/嵌套表/VARRAY
流程 IF/ELSIF/ELSE、LOOP/WHILE/FOR，FOR 变量只读
游标 显式四步（OPEN/FETCH/判断/CLOSE）或 FOR r IN SELECT 自动
异常 NO_DATA_FOUND/TOO_MANY_ROWS 等；RAISE_APPLICATION_ERROR 自定义
过程/函数 函数有 RETURN 可入 SQL，过程靠 OUT 参数；按是否需 SQL 调用选型
包 spec+body 分离，封装/重载/会话状态/初始化，大型代码必用
触发器 自动执行，审计/级联用，克制使用
动态 SQL EXECUTE IMMEDIATE + 绑定变量 + DBMS_ASSERT
批量绑定 BULK COLLECT + FORALL 单次往返多行，性能核心
