第四章：集成 Swagger：springdoc 接口文档

概念基础

  1. OpenAPI 是 REST API 的描述规范（结构化 JSON/YAML），Swagger UI 把规范渲染成可交互文档：在线查看接口与参数，并直接发起调试请求。
  2. springdoc-openapi 是 Spring Boot 生态的规范实现：启动时扫描 Controller 与注解自动生成 /v3/api-docs，文档与代码同源，不靠手写维护；本工程用 springdoc 3.0.1 配 Spring Boot 4。
  3. 注解驱动：@Schema 描述字段含义，@ExampleObject 提供可复现请求示例（下单成功 / 触发回滚两种），配合常量类避免魔法字符串。
  4. 为什么重要：微服务接口多、调用方多，文档即契约——示例与仓库文件一致，联调效率与前后端/服务间一致性显著提升。
  5. 边界：网关不聚合各服务 OpenAPI，日常走服务直连端口打开 UI；生产环境应关闭文档或加访问控制，避免接口信息泄露。

概述

API 文档使用 springdoc-openapi（父 POM springdoc.version 3.0.1），与 Spring Boot 4 / Spring MVC 兼容。公共路径在 cloud-common 的 application-shared.yml；带 UI 的模块在各自 pom.xml 引入 springdoc-openapi-starter-webmvc-ui。

常用注解速查

注解 位置 作用
@Tag(name = "订单") Controller 类 文档分组标题
@Operation(summary = "下单") 方法 接口摘要与描述
@Parameter(description = "订单ID") 单个参数 参数说明
@Schema(description = "数量", example = "2") DTO 字段/参数 字段含义与示例值
@ExampleObject @RequestBody 内 完整请求体示例
@ApiResponse(responseCode = "200") 方法 补充响应说明

DTO 字段用 @Schema 描述后，Swagger UI 的 Schema 面板会直接显示中文含义与示例，联调方不必再猜字段语义。

接口分组（GroupedOpenApi）

接口多起来后按业务域分组，Swagger UI 右上角下拉切换：

每组对应独立 JSON：/v3/api-docs/order、/v3/api-docs/stock；未匹配任何分组的路径归入默认组。分组也便于只把某组 JSON 导入 Apifox/Postman 做集合维护。

生产安全

接口文档暴露路径、参数与示例，生产必须收口，三种做法按严到宽排序：

方案 做法 适用
依赖隔离 springdoc-openapi-starter-webmvc-ui 仅打进 dev/test 制品 最彻底，生产包里根本没有 UI
开关关闭 springdoc.api-docs.enabled: false + springdoc.swagger-ui.enabled: false 保留依赖，需要时临时开启排障
访问控制 网关/Nginx 对 /v3/api-docs/**、/swagger-ui/** 做 IP 白名单或 Basic Auth 文档需对合作方开放的场景

注意只关 swagger-ui.enabled 而留着 api-docs.enabled，JSON 规范仍可被匿名抓取——两个开关要一起关。

网关聚合文档（可选）

默认各服务 UI 走直连端口；若要在网关统一看文档：

  1. 网关引入 springdoc-openapi-starter-webflux-ui（WebFlux 版，与业务模块的 webmvc 版不同）。
  2. 为每个下游服务配置一条 /v3/api-docs/{服务} 的路由转发。
  3. 网关 springdoc.swagger-ui.urls 中登记各服务的 JSON 地址。

注意：webflux 版与 webmvc 版 starter 不能出现在同一模块；聚合方案额外引入的路由也是攻击面，生产同样要收口。本仓库未开启聚合，联调期直连各服务端口即可。

常见问题

Q：gateway 上打不开 swagger-ui？
A：未配置聚合路由；请用 8003 等直连端口，或自行增加 Gateway 路由到 /v3/api-docs。

Q：springdoc 2.x 升级到 3.x 要注意什么？
A：包名仍为 org.springdoc；需与 Spring Boot 4 对齐，勿混用 Boot 3 的旧 starter 版本。

Q：生产环境要关文档吗？
A：可通过 profile 排除 springdoc-openapi-starter-webmvc-ui 依赖，或 springdoc.api-docs.enabled=false / swagger-ui.enabled=false。

Q：分组后 /v3/api-docs 默认组还在吗？
A：在。未匹配任何分组的路径归入默认组；想彻底拆分可把 springdoc.api-docs.path 保持不变，仅通过 pathsToMatch 覆盖全部路径。

Q：示例 JSON 改了但 UI 里没变？
A：@ExampleObject 引用的常量改动需重启服务生效；springdoc 在启动期生成规范，不会热加载注解内容。
