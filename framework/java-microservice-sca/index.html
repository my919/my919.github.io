14. 常见误用与陷阱

坑 现象 解法
Feign 调用 404 / 找不到实例 @FeignClient(name="user-service") 调用报 404 或负载均衡报无可用实例 name 必须等于提供方 spring.application.name（区分大小写/连字符）；确认提供方已注册到 Nacos 且 namespace 一致
Feign 不透传请求头 下游拿不到 Authorization/traceId，鉴权失败、链路追踪断 Feign 默认不传上游 header；实现 RequestInterceptor 把需要的头塞进 RequestTemplate
Gateway lb:// 报 503 路由 uri: lb://user-service 返回 503 Service Unavailable 缺 spring-cloud-starter-loadbalancer 依赖；Spring Cloud 2021+ 不再默认带，需显式引入才能解析 lb://
Sentinel fallback 不生效 调用失败不进降级类、直接抛异常 feign.sentinel.enabled: true 必须开；fallback 类要注册为 Bean 且 @FeignClient(fallback=...) 指定；fallback 方法签名须与接口一致
@GlobalTransactional 不回滚 远程调用失败但本地写入未回滚 tx-service-group 必须与 Seata 服务端 vgroup-mapping 一致；业务库需建 undo_log 表；AT 模式下所有分支须用支持本地事务的数据源
Nacos 服务注册了但发现不到 消费方报 “No instances available” 注册中心与消费方的 namespace/group 不一致；dev/prod 命名空间隔离，跨 namespace 不可见，须对齐
bootstrap.yml 不生效 Nacos 配置没加载、@Value 取不到值 Spring Cloud 2020+ 默认停用 bootstrap；加 spring-cloud-starter-bootstrap，或改用 spring.config.import=nacos:...
@RefreshScope 改配置不刷新 Nacos 改了配置但接口返回旧值 data-id 须为 服务名-环境.后缀（如 user-service-dev.yaml）；Bean 须加 @RefreshScope；检查 namespace/group 与配置一致
