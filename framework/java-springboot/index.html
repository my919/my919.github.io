15. 常见误用与陷阱

坑 现象 解法
未加分页插件 Page 不生效 userService.page(...) 返回全表数据、无 LIMIT 必须注册 PaginationInnerInterceptor（见第 11 节）；否则 Page 只是个普通对象，不会拼 LIMIT
@Valid 不生效 校验注解（@NotBlank 等）被忽略，非法参数照常进入 类上需 @Validated 或参数前加 @Valid；并引入 spring-boot-starter-validation（Boot 2.3 后不再默认包含）
@Transactional 自调用失效 同类内 methodA() 调 methodB()（后者有 @Transactional）事务不生效 Spring AOP 基于代理，自调用绕过代理；拆到另一个 Bean，或注入自身代理（self）/用 AopContext.currentProxy()
map-underscore-to-camel-case 没开 实体 userId 查不到值（列 user_id） application.yml 设 mybatis-plus.configuration.map-underscore-to-camel-case: true，或字段加 @TableField("user_id")
Druid/HikariCP 连接池未限流 高并发下 DB 连接打满、超时 spring.datasource.hikari.maximum-pool-size 显式设值；MyBatis-Plus 的 page 大分页用 maxLimit 防止 pageSize=Integer.MAX_VALUE
@RequestParam 收到日期字符串 String → Date 转换报 TypeMismatchException 用 @DateTimeFormat(pattern="yyyy-MM-dd") 注解参数；或直接用 LocalDate + @JsonFormat
