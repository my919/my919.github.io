15. 常见误用与陷阱

坑 现象 解法
Pydantic v1 写法在 v2 失效 .dict() / orm_mode 报弃用或报错 v2 改用 .model_dump()；Config.orm_mode 改为 Config.from_attributes = True（或 model_config = ConfigDict(from_attributes=True)）
response_model=UserOut 返回 ORM 对象报错 序列化抛 ValidationException，提示缺属性 UserOut 未开 from_attributes；设 from_attributes=True 才能从 ORM 对象取属性
异步会话用 db.query(...) 报 MissingGreenlet 或阻塞事件循环 AsyncSession 没有 query API；改用 await db.execute(select(...)) 再 .scalars().all()，按主键用 await db.get(Model, id)
Alembic autogenerate 生成空迁移 模型改了但迁移脚本里 upgrade() 是空的 alembic/env.py 必须 from app.models.user import Base（及所有模型），target_metadata = Base.metadata，否则 autogenerate 看不到表
EmailStr 导入即报错 ImportError: email-validator is not installed EmailStr 依赖 email-validator 包；uv add email-validator 后才可用
异步迁移同步执行 run_sync 用错或 async_engine_from_config 未配置 env.py 用 connectable.run_sync(do_run_migrations)，引擎须 create_async_engine；同步 engine 跑异步模型会卡死
