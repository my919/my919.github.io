15. 常见误用与陷阱

坑 现象 解法
Zod.parse 抛错返回 500 校验失败时接口返回 500 而非 400 Fastify 不会自动处理 ZodError；用 app.setErrorHandler 判断 err.name === 'ZodError' 转 400，或路由内用 safeParse 手动返回 400
db.query.*.findFirst 报 undefined 关系查询 API 不可用、报 Cannot read properties of undefined drizzle(client) 默认不加载 schema；改为 drizzle(client, { schema }) 传入 schema 对象后 db.query 才可用
静态路由被参数路由吞掉 /users/me 命中 /users/:id，Number('me') 得 NaN Fastify 按注册顺序匹配，静态路由（/users/me）必须先于 /users/:id 注册
env.parse 在 import 时执行 单测无法注入环境变量、启动即抛错 config.ts 在模块加载即 parse(process.env)；测试用 setup 文件提前 process.env.DATABASE_URL=...，或用 vi.stubEnv 注入
postgres 驱动跑在边缘运行时 Hono 部署到 Cloudflare Workers 报 tcp sockets not supported 边缘场景换用 @neondatabase/serverless + drizzle-orm/neon-http，长连接驱动只在 Node 适用
改了 schema.ts 运行时表没变 tsx watch 只重启进程、不执行迁移 改 schema 后必须手动 pnpm db:generate && pnpm db:migrate，热重载不会跑迁移
