第三章：Docker 部署 1Panel

发表于 2026-05-02 更新于 2026-10-25 分类于 Docker 容器化 本文字数： 7.4k 阅读时长 ≈ 7 分钟

第三章：Docker 部署 1Panel

概念基础

  1. 1Panel 是开源的 Linux 服务器运维管理面板：在网页上即可管理网站、数据库、容器、防火墙、定时任务等，替代繁琐的命令行运维。
  2. 为什么用 Docker 部署：面板本体与依赖全部封进镜像，一条 docker run 即可拉起，升级与重建都围绕镜像和数据卷进行，不污染宿主机。
  3. 两类典型环境：Windows + Docker Desktop + WSL（必须端口映射 -p，勿用 --network host）与 Linux Docker 主机（可直接 host 网络）。
  4. 管理宿主机的关键：面板通过挂载 /var/run/docker.sock 获得管理宿主机 Docker 的能力，通过 /opt 与 BASE_DIR 约定数据目录。
  5. 安全底线：改强 PASSWORD、设 ENTRANCE 安全入口、按需放行安全组端口，避免面板暴露在公网被扫描。

共用前提

  • docker version 客户端与 Server 均正常，能拉取 Docker Hub（或已配置镜像加速）。
  • 建议内存 ≥ 1GB；多架构以 Hub 页为准。
  • 将 PASSWORD、ENTRANCE 等换成自己的值；变量含义见文末 「常用环境变量」。

第一类：Windows + Docker Desktop + WSL

场景：宿主机为 Windows，容器由 Docker Desktop 提供引擎；你在 WSL 里打开终端（发行版可为 Rocky Linux 10、Ubuntu 等），docker version 的 Server 往往显示 Docker Desktop 或上下文为 desktop-linux。此时容器里的 host 网络与你在 WSL 里访问的 localhost 不是同一概念，不要使用 --network host，应使用 -p <PORT>:<PORT>。

若曾误用 host 建过同名容器，先 docker rm -f 1panel-v2 再按本节重建。

浏览器访问（本机）

多数情况：http://127.0.0.1:10086/<ENTRANCE>（与示例 ENTRANCE 一致时）。在 WSL 内若 localhost 仍不通，可试 http://$(grep -m1 '^nameserver' /etc/resolv.conf | awk '{print $2}'):10086/<ENTRANCE>（常为 WSL2 下可达的 Windows 主机 IP，以本机为准）。

可选：docker compose（端口映射）

将下文保存为同目录下的 compose.yaml 或 docker-compose.yml（二选一即可，Compose V2 默认会读取二者）。Docker Desktop / WSL 使用 ports，不要写 network_mode: host。

在同目录执行 docker compose up -d。

第二类：Linux Docker 主机

场景：Linux 云服务器、物理机或虚拟机内安装 Docker Engine（非 Docker Desktop 作为服务端）。可用 --network host，面板监听端口即宿主机端口，与安全组、防火墙规则一致。

多行 docker run（--network host）

-v /var/run/docker.sock：面板管理宿主机 Docker。
-v /opt:/opt 与 BASE_DIR=/opt：数据目录可改，须与挂载路径同步。
moelin/1panel:v2：跟踪 V2 最新构建；生产建议改为 Hub 具体版本号。

可选：docker compose（host 网络）

将下文保存为同目录下的 compose.yaml 或 docker-compose.yml。

在同目录执行 docker compose up -d。

常用环境变量（V2）

变量 默认值（未设置时） 说明
PORT 10086 Web 端口
USERNAME 1panel 管理员用户名
PASSWORD 随机或默认（见 Hub） 登录控制台密码，务必改为强密码或从日志读取随机值
ENTRANCE entrance 安全入口的 URL 路径前缀（非第二端口），访问 http://IP:PORT/ENTRANCE，用于降低默认路径被扫的概率
BASE_DIR /opt 数据目录，需与 /opt 挂载一致
TZ 常见 Asia/Shanghai 时区
RESET false 置 true 可强制重置配置（慎用）

完整说明与 V1、Global 标签见 Hub 文档。

面板核心功能速览

部署完成后，1Panel 的能力远不止”装个面板”：

应用商店

内置 OpenResty（Nginx）、MySQL、PostgreSQL、Redis、MongoDB、Halo、WordPress、Memos、Vaultwarden 等百余款应用，一键安装即自动完成容器编排、端口映射与反向代理挂载；支持自定义应用仓库（Git 仓库形式的第三方应用集）与本地应用（上传自有 docker-compose 模板），团队内部标准化交付常用中间件非常方便。安装时可选端口外部访问开关，默认仅本机暴露，安全默认做得比多数面板好。

网站管理

  • 一键建站：静态站点 / 反向代理 / PHP 运行环境三类，自动生成 OpenResty 配置；
  • SSL 证书：集成 Let’s Encrypt / ZeroSSL，支持 DNS 自动验证（泛域名）与自动续签，对接阿里云、腾讯云、Cloudflare 等 DNS 厂商；
  • WAF：基于 OpenResty 的 CC 防护、IP 黑白名单、UA 拦截，免费版可用基础规则；
  • 防盗链、访问日志、错误日志 面板直查，省去上机 tail。

备份与计划任务

  • 备份账号：支持本地磁盘、S3 兼容对象存储、阿里云 OSS、腾讯 COS、七牛、WebDAV、SFTP，备份先落本地再推远端；
  • 计划任务：按 cron 周期备份网站、数据库、目录、面板快照，保留份数可配，失败邮件/Webhook 通知；
  • 快照：升级前一键打面板快照，异常时整体回滚。

数据库与文件管理

数据库页支持 MySQL/PostgreSQL/Redis 的建库、授权、远程访问开关与 phpMyAdmin/Adminer 直达；文件管理器支持在线编辑、压缩解压、权限修改与批量上传，临时改个配置不必再开 SFTP 客户端。

容器与镜像管理

容器页可直接创建/启停/重建容器、看日志、进终端、改 compose；镜像页支持拉取、清理 dangling、构建镜像；编排页以 docker-compose 文件管理整套栈，改动即 docker compose up -d，与命令行操作完全一致、互不冲突。

本地应用示例：把团队的 docker-compose.yml + .env 模板放到 /opt/1panel/resource/apps/local/<name>/ 下按约定组织，商店即出现”本地应用”，新同事装机从十分钟命令行变一分钟点选。

监控与审计

概览页实时展示 CPU/内存/磁盘/网络与负载趋势；进程守护（Supervisor）、防火墙（iptables/firewalld 规则图形化）、SSH 登录日志与面板操作审计一应俱全，多人共用时可回溯”谁在什么时间改了什么”。

安全加固清单

  1. 改强密码 + 开双因素（面板设置 → 安全 → 2FA）；
  2. ENTRANCE 安全入口 设为难猜路径，并开启授权 IP 白名单（仅公司/家庭出口 IP 可访问）；
  3. 面板端口不进公网：云安全组只放行必要业务端口（80/443），面板端口走白名单或 VPN/跳板；
  4. 关闭面板默认的未使用服务端口（如 phpMyAdmin 用完即关）；
  5. 定期升级镜像并备份快照，升级前看 CHANGELOG 与社区反馈。

升级与日常维护

数据位置：面板数据在 BASE_DIR/1panel（默认 /opt/1panel）下，含 apps/（应用）、www/sites/（网站）、backup/（本地备份）、db/（面板自身 SQLite）；迁移机器时整目录打包 + 面板快照即可。

常见端口约定：面板默认 10086，应用商店装的 MySQL/Redis 默认不对外暴露，需远程访问时在应用设置里显式开启并在安全组放行。

常见问题排查

问题 排查路径
面板打不开 docker logs 1panel-v2 看启动日志；确认 PORT 与安全组放行；检查 ENTRANCE 路径是否带错
忘记密码/入口 docker exec -it 1panel-v2 1pctl user-info 查看；1pctl reset password 重置
应用装完访问不通 应用设置里是否开启”端口外部访问”；容器间走 172.x 内网 IP 而非 127.0.0.1
证书签发失败 DNS 验证需 API Token 权限正确；HTTP 验证需 80 端口可达且无 CDN 回源拦截
备份失败 备份账号”测试连接”先过；本地磁盘水位 > 90% 时先清理旧备份
容器列表为空 确认挂载了宿主机 /var/run/docker.sock 且无权限 SELinux 拦截

1pctl 是镜像内置的运维命令集（status/restart/update/restore 等），docker exec -it 1panel-v2 1pctl --help 查看全集，多数面板异常都能用它自助恢复。
