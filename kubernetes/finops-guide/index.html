8. 典型案例：云成本账单治理

8.1 问题背景

某 SaaS 月账单环比 +40%，CFO 追问却没人说得清哪个团队花的：30% 资源没有标签、三个团队的环境值拼写各不相同、还有一批无人认领的资源。成本失控的根因是”分摊不了”。

8.2 解决方案

先立标签合规（team/service/env/cost-center 四强制标签，IaC 校验拦截不合规资源）→ Cost Explorer 按标签出分摊账单 → 无主资源挂共享成本池限期认领 → RI/SP 覆盖率分析与闲置资源清理 → 月度成本周报固化。

8.3 关键实现

8.4 踩坑点

  • 标签值五花八门（Prod/prod/production），分摊口径对不上；改为白名单值 + IaC 强制校验
  • 为省钱抢购 1 年期 RI，两个月后架构迁移换实例族，RI 全部沉没；先看 90 天稳态基线再购买
  • 只盯 EC2，S3 快照 + 未挂载 EBS + 闲置 EIP 每月白烧 8%；闲置清单纳入每日巡检
  • 预算告警设在 100%，月底才发现超支；改为 forecast > 80% 即告警

9. 常见误用与陷阱

坑 现象/后果 解法
标签缺失/拼写不一 成本无法分摊，治理无从下手 强制标签 + IaC 校验 + 白名单值
预留实例误购 实例族/机型不匹配，RI 沉没 先看 90 天稳态负载再购买
忽视闲置资源 EIP/EBS/快照长期白烧 定期巡检清单自动清理
只优化计算忽略存储 S3/快照占账单两成 生命周期策略 + 分层存储
预算告警阈值 100% 月底才知道超支 forecast 80% 提前告警
月账单后置分析 发现问题时已过期一个月 实时看板 + 成本周报
