9. 典型案例：边缘函数落地

9.1 问题背景

图片 CDN 频繁被盗链，第三方站白嫖流量每月多花 2 万元。方案是在边缘做防盗链校验 + 动态签名：单请求开销 <5ms、冷启动不可感知，传统容器网关 200ms 冷启动扛不住全球分布要求。

9.2 解决方案

用 Rust 编写 Wasm 边缘函数部署到 Cloudflare Workers：请求到达边缘即校验 Referer/签名，非法请求直接 403 不回源，合法请求重写签名 URL 透传；黑白名单进 KV 缓存；按 Country 头灰度放量。

9.3 关键实现

9.4 踩坑点

  • 未做 wasm-opt 裁剪，二进制 8MB 导致 Worker 加载超时；-Oz + 去掉 regex crate 压到 400KB
  • 在边缘做重量级 JWT 验证和大 JSON 解析，P99 超 CPU 限额被 kill；重活移到 KV 预计算
  • 缓存键漏了图片变体参数（w/h），用户拿到 100px 缩略图当原图；键补齐变体 + 分级 TTL
  • 直接 unwrap panic 触发 500 瀑布；全部 Result 化并加降级放行兜底（防盗链挂了不能影响正常出图）

10. 常见误用与陷阱

坑 现象/后果 解法
wasm 二进制过大 加载慢，冷启动优势归零 wasm-opt -Oz + 精简依赖
边缘做重计算 超 CPU 限额被 kill 重活预计算，边缘只做轻校验
缓存键缺变体参数 用户拿到错误规格资源 键含全部变体 + 分级 TTL
panic 未捕获 边缘函数 500 瀑布 Result 化 + 降级兜底路径
假设完整 WASI 可用 宿主差异运行时报错 面向宿主抽象层，本地测试对齐
无灰度直接全量 边缘故障全球放大 按 Country/百分比灰度放量
